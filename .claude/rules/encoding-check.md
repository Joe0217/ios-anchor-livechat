# 中文编码完整性

## 预防策略（降低乱码发生概率）

### 1. 大段中文优先 Write 而非 Edit
- 中文 .md 文件的大范围修改（超过 10 行），优先用 Write 重写整个文件
- Edit 需要 old_string 和 new_string 两个参数都正确传递中文，出错概率翻倍

### 2. Edit 操作尽量短小
- 一次 Edit 只改几行，避免长字符串跨越过多 token 边界
- 需要改多处时，拆成多次独立的小 Edit

### 3. Edit 边界锚定在 ASCII 字符上
- old_string 的起止位置选在 markdown 语法（`##`、`-`、`` ``` ``）或空行处
- 避免在中文字符中间切割匹配边界

## 事后验证（兜底机制）

- 每次 Edit/Write 完成后，必须用 Read 回读修改区域，确认中文字符完整无损
- 特别关注中文标点和 3 字节 UTF-8 汉字的截断
- 发现乱码立即修复并再次 Read 验证，不要等用户指出

## 常见乱码模式
- `标注��已` 应为 `标注「已`（中文引号截断）
- `改���时` 应为 `改动时`（汉字截断）
- `文���标题` 应为 `文档标题`（汉字截断）
- `可���择` 应为 `可选择`（汉字截断）
