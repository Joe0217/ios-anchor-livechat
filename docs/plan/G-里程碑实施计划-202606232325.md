### 10.2 与 H 里程碑的接口预留

- `PKStoreObserver.pkStore(_:didEndPK:scores:)` 协议钩子：G 空实现，H 接入礼物 PK 期降序重排时填实
- `pkGiftsQueueLengthMax=15`：G 不实现队列；H 实现时不依赖 PK 状态机变更（仅监听 observer）

### 10.3 与 LiveStore 的接口锁定

- `LiveStore.setCallState(_)` [LiveStore.swift:318](Sources/Live/LiveStore.swift#L318)：G 直接调用，无需新 API

### 10.4 与 AgoraManager 的接口锁定

- `applyEncoderQuality` 新增 `.pkActive` / `.pkLow`：B 的弱网 `.normal/.low` 不破；NetworkQualityMonitor 触发 `.low` 在 PK 期被 PKStore 拦截转 `.pkLow`
