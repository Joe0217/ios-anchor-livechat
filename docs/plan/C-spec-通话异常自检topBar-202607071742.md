### 0.4 H5 / iOS 源码二次校验
| H5 行为 | iOS 等价 | 依据 |
|---|---|---|

## §1 数据契约 · State · Store 接口

### 1.1 无新接口

### 1.2 CallAbnormalReason enum（新增）

放 `Sources/Call/CallConstants.swift`（与 CallState 同层）：

```swift
enum CallAbnormalReason: String, Identifiable, CaseIterable {
    /// H5 tenSecondsCB checkRemoteIsJoined 失败：远端未加入 RTC channel（远端设备/网络问题）
    case userOffline
    /// H5 tenSecondsCB connectionStateIsConnected 失败：本端 AgoraManager.state != .joined（本端网络问题）
    case networkUnstable
    /// H5 secondsToZero：通话 >120s 且收入仍 0（服务端计费异常）
    case incomeZero

    var id: String { rawValue }
}
```

### 1.3 CallStore 新增字段 + 方法

```swift
// 字段（放 lastJoinCallSource 之后 / C-1 reset region 附近）
@Published private(set) var callAbnormalReason: CallAbnormalReason?
private var alertedAbnormalReasons: Set<CallAbnormalReason> = []

// 方法
/// 每秒 tick hook（在 startElapsedTask 内 self.callElapsed += 1 后调）
private func checkAbnormalIfNeeded() {
    guard state == .connected, callAbnormalReason == nil else { return }
    if callElapsed >= 10 && callElapsed % 10 == 0 {
        // H5 tenSecondsCB 每 10s check（10s/20s/30s/... 时点）
        if agora.remoteUid == 0, !alertedAbnormalReasons.contains(.userOffline) {
            triggerAbnormal(.userOffline)
            return
        }
        if agora.state != .joined, !alertedAbnormalReasons.contains(.networkUnstable) {
            triggerAbnormal(.networkUnstable)
            return
        }
    }
    if callElapsed >= 120, current.callIncome == 0, !alertedAbnormalReasons.contains(.incomeZero) {
        triggerAbnormal(.incomeZero)
    }
}

private func triggerAbnormal(_ reason: CallAbnormalReason) {
    alertedAbnormalReasons.insert(reason)
    callAbnormalReason = reason
}

func dismissAbnormalReason() {
    callAbnormalReason = nil
}
```

**契约**：
- checkAbnormalIfNeeded 仅 `.connected` 态生效（`.calling`/`.connecting` 未接通不算异常）
- `alertedAbnormalReasons` 一次通话内 Set 累加，**同 reason 触发过就不再触发**
- endLocally 时清 `callAbnormalReason` + `alertedAbnormalReasons`（下次通话干净开始）

### 1.4 startElapsedTask hook 挂点

现有 `startElapsedTask`（Line 1036）：
```swift
while !Task.isCancelled {
    try? await Task.sleep(nanoseconds: 1_000_000_000)
    guard !Task.isCancelled, let self else { return }
    self.callElapsed += 1
    // 新增：
    self.checkAbnormalIfNeeded()
}
```

### 1.5 endLocally reset 追加

`state = .ended` 前追加 2 行：
```swift
callAbnormalReason = nil
alertedAbnormalReasons.removeAll()
```

## §2 View 结构 & PreviewProvider

### 2.1 CallFaceTimeView.body 加 `.alert`

挂在 body 末尾（onDisappear 之后），使用 iOS 15+ `.alert(_:isPresented:presenting:actions:message:)`：

```swift
.alert(
    reasonTitle(for: store.callAbnormalReason),
    isPresented: Binding(
        get: { store.callAbnormalReason != nil },
        set: { if !$0 { store.dismissAbnormalReason() } }
    ),
    presenting: store.callAbnormalReason
) { reason in
    Button(L10n.callAbnormalEndCall, role: .destructive) {
        Task { await store.hangup() }
    }
    Button(L10n.callAbnormalContinue, role: .cancel) {
        // no-op：默认 dismiss，isPresented.set(false) → dismissAbnormalReason()
    }
} message: { reason in
    Text(reasonMessage(for: reason))
}
```

配套 helper：
```swift
private func reasonTitle(for reason: CallAbnormalReason?) -> String {
    guard let reason else { return "" }
    switch reason {
    case .userOffline:      return L10n.callAbnormalUserOfflineTitle
    case .networkUnstable:  return L10n.callAbnormalNetworkUnstableTitle
    case .incomeZero:       return L10n.callAbnormalIncomeZeroTitle
    }
}

private func reasonMessage(for reason: CallAbnormalReason) -> String {
    switch reason {
    case .userOffline:      return L10n.callAbnormalUserOfflineMessage
    case .networkUnstable:  return L10n.callAbnormalNetworkUnstableMessage
    case .incomeZero:       return L10n.callAbnormalIncomeZeroMessage
    }
}
```

## §3 验收清单

### F 正向
- **F1**（userOffline）：通话中远端设备断网 → 10s 内 iOS 主播端弹 alert "User Offline" + 副标题 + 2 按钮
- **F2**（networkUnstable）：本端主动断 Wi-Fi → 10s 内弹 "Unstable Network"
- **F3**（incomeZero）：拨打后 >120s 未收到 attachType=15 收入推送 → 弹 "No Income"
- **F4**：点 End Call → CallStore.hangup 触发挂断链路（endLocally → agora.leave → state = .ended）
- **F5**：点 Continue → alert dismiss，callAbnormalReason 变 nil，通话继续
- **F6**：Continue 后同一 reason 不再重弹（一次通话只弹一次）
- **F7**：End Call 后重拨新通话 → alertedAbnormalReasons 已清空 → 异常仍可正常触发

### R 反向 (critical 3-5 条)
- **R1**（state guard）：`.calling`/`.connecting` 态即使 remoteUid==0 也不触发（未接通不算异常）
- **R2**（elapsed guard）：通话 <10s 时 remoteUid 短暂 0 不触发（避免误报）
- **R3**（alert 展示期间）：alert 已挂 (`callAbnormalReason != nil`) 不重复检测同 tick 内其他 reason
- **R4**（endLocally reset）：挂断后重拨新通话，`alertedAbnormalReasons` 清空、`callAbnormalReason` 归 nil
- **R5**（切后台）：切后台期间 `Task.sleep` 挂起 startElapsedTask，回前台 callElapsed 一次性 catch up 但 checkAbnormalIfNeeded 内 `elapsed % 10 == 0` 门控 + `alertedAbnormalReasons` 防连触发
