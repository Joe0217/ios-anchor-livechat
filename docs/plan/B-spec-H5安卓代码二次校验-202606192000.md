## 1.2 冲突项（已决策）

| 维度 | 决策 | 理由 |
|---|---|---|
| 心跳间隔（6s vs 10s） | **10s** | 路线图已锁定对齐安卓 `liveHeartBeatV2`/`liveHeartBeat` 双接口已分流；H5 6s 是 Web 端遗产，三端走 10s 减少服务端分支 |
| 心跳失败阈值（>6 vs >3） | **>3 次** | 配 10s 间隔，30s 内识别断连优于 36s（H5）；与安卓一致便于服务端埋点复用 |
| endType 形态（字符串 vs 数字） | **数字 1-7** | H5 字符串编码 `'99'/'61'/'62'` 语义错位混入 IM attachType 命名空间，安卓数字 1-7 契约更清洁 |
| 弱网强制下播阈值（10 vs 30） | ~~**≥10 次**（v4 与安卓一致）~~ **v5 反悔为分层 10/30/5（连续语义）** | v4：安卓 10 次（≈20s）更贴近体验。**v5 用户反馈"突然下播体验差"**：改为**连续** ≥10 次降帧率 30→15fps + toast / **连续** ≥30 次下播 endType=7 / 降级期间**连续** ≥5 次质量好恢复 normal（中间任一次质量 ≤4 即清零重计）——保留下播兜底同时加缓冲层（详见 B-LiveStore §4.5） |
| 采集失败映射（H5 `'99'` vs 安卓 5） | **endType=5（数字）** | 废弃 H5 错位的字符串 `'99'`（与 IM 数字 attachType 99 命名空间冲突），统一到"采集失败 >20s = 5" |
| attachType 50/61/63 在 Parser 的角色 | **从 GiftMessageParser 移除**：50 不识别 / 61 入 ComplianceMessageParser 警告 / 63 入 LiveControlMessageParser 折扣池 | 61=合规警告（不下播）、63=进折扣池（非礼物语义）双端一致；50 双端均无 file:line 证据，B 阶段不识别，待派对房/虚拟道具专档落实 |

## 1.3 死代码/废弃项规避清单

- **H5 `'99'` 相机错误字符串编码**：与安卓数字 endType 命名空间冲突，**禁止照搬**，改用数字 5（采集失败）
- **H5 `'61'`/`'62'` 在 liveSetting 仅消费 UI 文案**（`index.vue:51-55,68-70`）：真正触发在 message.js 收 IM 后 set `isCompelLiveEnd`；iOS 直接在 IM 解析器分流，不在 LiveStore 设字符串中间态
- **`'61'` 仅警告不下播**（`index.vue:54 return`）：iOS 必须分清"61=警告 toast 但不调 endLiveRoom" vs "62=封禁 endType=2 立即下播"
- **H5 networkMonitor 30 次阈值 + 60s 倒计时**（`networkMonitor.js:63,64,287`）：倒计时实际为 0 立即触发，废弃；**30 次本身被 v5 重新启用作为下播阈值**（≈60s）；H5 的"10 报点 / 30 下播"双阈值合并为 v5"10 降帧率 / 30 下播"语义重定义
- **H5 networkMonitor `showWarning=false` 默认关**（`networkMonitor.js:60,189-193`）：警告对话框分支死代码，不复刻
- **liveStore（用户端）的 attachType 分支**（chatroomLiveChatRecordMsg 等）：本批输入已确认是用户端 store，主播端无此路径，**不要照抄 50/52/56/71/80/97-100/140/144/195/1030-1033** 任一分支到 iOS 主播端
- **H5 用户端 `LIVE_FRONT_STATUS_NUMBER.CALLING`**：用户端感知主播状态字段，**不是** callState，禁止误抄入 iOS LiveStore
- **message.js L113-126 私聊礼物 svga/MP4 特效注释段**：状态为"待需求确认"，B 里程碑不实现
- **H5 `keepLiving` "10秒" 注释**（CLAUDE.md 已记录为过时）：源码事实是 6000ms；既不抄 6s 也不信注释，直接落安卓 10s
- **liveSetting 内的 PK store 引用**（callState 2/3 分支）：阶段一恒为 0，PK store 不在 B 里程碑落地，避免引入 `pkStore.isJoiningPk/isInPk/isMatching` 依赖

## 1.4 iOS 现状 P0 缺口（B 里程碑必补）

- ❌ **LiveStore 抽离**：心跳/endType/forceLeave/网络监控/相机错误均散落 `LiveRoomView` 内的 `@State`，需新建 `LiveStore: ObservableObject` 集中副作用（CLAUDE.md 实现纪律）
- ❌ **心跳 10s + 失败 >3 次计数**：`LiveRoomView.swift:65-72` 改为 LiveStore 拥有的 Timer；`LiveService.heartbeat` (`LiveService.swift:81-84`) 必须读 response code 并返回，禁止 `try?` 吞错
- ❌ **心跳响应码分流**：APIClient 层之上为 LiveService 加 code 解析，1992 → endType=2、2001 → endType=6、连续失败 >3 → endType=4
- ❌ **`JSONSerialization` 对 `result:null` 守卫**：`LiveService.heartbeat` 序列化前 `isValidJSONObject` 检查（CLAUDE.md 已知坑）
- ❌ **endLiveRoom 携带 endType**：`LiveService.swift:87-89` body 增加 `endType: Int` 参数；调用点全部传值（用户主动=1、强制下播按 2/4/5/6/7 分流）
- ✅ **NetworkQualityMonitor**（v5 已实现）：订阅 Agora `networkQuality` 回调；**v5 三阈值分层（全部"连续"语义，中间任一次质量 ≤4 即清零重计）**——连续 ≥10 次质量 5/6 → 降帧率 30→15fps + toast；连续 ≥30 次 → forceEnd endType=7；降级期连续 ≥5 次质量好 → 恢复 normal；PK 期间 pause/resume 钩子（详见 B-LiveStore §4.5）
- ❌ **CameraManager 错误回调链**：`CameraManager.swift` 增加 `onError: (CameraError) -> Void`，监听 `AVCaptureSessionRuntimeError` / `WasInterrupted` / `InterruptionEnded`，权限拒绝不再静默 `try?`；持续失败 >20s 触发 endType=5
- ❌ **BeautyRenderer fallback**：`FUBeautyRenderer.init` 改为 throws；setup 失败时 `CameraManager` 自动降级到 `PassthroughRenderer`，上报埋点不阻塞开播
- ❌ **Agora token 续期**：`AgoraManager.swift:157-161` 的 `tokenPrivilegeWillExpire` 改为调 `/api/index/getAgoraRtmToken`（uid 绑定）拿新 token → `engine.renewToken(_:)`；error code 109/110 同链路
- ✅ **开播链 rtcToken 取数**：~~原列为缺口~~ → B-spec review v2 纠错：`LiveService.swift:42-69` 已正确调 `getAgoraRtmToken()` 并写入 `LiveRoomInfo.rtcToken`，无 bug。**token 续期**路径（B-LiveStore spec §7）仍是缺口
- ❌ **开播前置校验**：`LivePrepareView` 补"描述非空 / 封面非空 / 距上次下播 ≥60s / IM 在线检查"，对齐 H5 `checkCanLive`
- ❌ **NIMChatroomManager 三处**：
  - `connectionStateChanged` L136-138 实现重连 + UI 反馈
  - `leave` L81-88 复位 `onlineCount = 0`
  - `.custom` 消息接入 **ComplianceMessageParser**（处理 44 强制下播 → endType=4、61 警告 toast、62 封禁 → endType=2）+ **GiftMessageParser**（识别 `SEND_GIFT` 字符串 + 数字 1/4/15/18，先解析后展示留 C 复用），50 不识别
- ❌ **统一日志**：`LiveService.swift:60,98,103,106` 的裸 `print` 收敛为 `os.Logger`
- ❌ **endLive 抢跑修复**：`LiveRoomView:178` `Task { try? ... }` 改为 await + 错误提示，否则 `agora.leave()` / `dismiss()` 抢跑导致下播接口失败无感知
