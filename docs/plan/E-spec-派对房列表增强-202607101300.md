### 搜索契约

- 输入框实时搜（`throttle` 300ms）
- 空 query → 显示空态提示 "Enter keywords to search rooms"
- 非空 query → `PartyAPI.roomList(queryParam: q, languageCode: nil)`
- 结果 empty → 显示 "No rooms found"
- 结果 non-empty → `PartyRoomCardView` 列表；点击进房走现有 `PartyTabRootView.enterRoom` 路径

### 语言 pill 契约

- 数据：`[PartyLanguage(id: -1, languageCode: nil, languageName: "All")] + PartyAPI.languageList()` 结果
- 首次进 Party tab 拉一次；失败保留只 "All" 单项
- 切换 → `PartyListStore.setLanguage(index:)` → 内部 `refreshInitial()` 重新拉
