### 1.3 状态机（6 态）

```
initial → loading → loaded ↔ sending → sent
                       ↓        ↓         ↓
                   loadFailed sendFailed dismissed
```

| 态 | 触发 | UI |
|---|---|---|
| initial | Panel present | 立即转 loading |
| loading | task load() | ProgressView |
| loadFailed(msg) | dataSource throw | 错误 + Retry |
| loaded | 数据到 | grid + footer active |
| **sending** | tap Send/Confirm 且 footer=.send（**本轮骨架**，模拟 300ms sleep 触发 sent）| 主按钮 spinner + UI locked |
| sendFailed(msg) | sending 失败（本轮不触发）| 主按钮恢复 + toast/inline |
| sent | 成功（本轮 mock 直接进）| onSend/onConfirm 回调 → 内部 dismiss |

**sending / sent 骨架**：本轮 `.confirm` footer tap → 直接 onConfirm 回调 + dismiss（跳过 sending）；`.send` footer 因本轮不 wire，触发时**只走 sending → sent** mock（默认 dismiss）；`.instantSelect` 同 `.confirm` 但 tap cell 即触发（无按钮）。

**不变量**：
- selectedId != nil → visibleGifts.contains(id)（switchTab 前 clear）
- interaction=readonly → selectedId 恒 nil；tap no-op
- sending 期间 tap gift / switchTab / stepper → 全 disabled
- count ∈ config.countStepper.range（clamp）；stepper.hidden 时 count 恒 1

### 1.4 交互契约

| 动作 | 行为 |
|---|---|
| tap cell（selectable + 非 sending）| 切换 selectedId（同 id 反选）；`.instantSelect` footer 直触发回调 + dismiss |
| tap cell（readonly / sending）| no-op |
| switch tab | 若 selectedId 属于目标 tab 保留；否则 clear |
| stepper - / + | 按 range clamp；边界 disable |
| tab bar tap | 切 tab；sending 期间 disabled |
| receivers row | 单选 tap 切换；多选 tap 累加；All tap 全选/全反选 |
| Backpack icon tap | config.backpack=.visible(handler) 时调 handler |
| Send / Confirm 按钮 tap | canTrigger 时触发 store.triggerAction() |
| × / swipe-down dismiss | 不触发 onConfirm/onSend；IM 场景触发 onCancel（保留旧语义）|

**canTriggerAction** 公式：
```
footer=.none                → 不渲染按钮
footer=.instantSelect       → 不渲染按钮（tap cell 即触发）
footer=.confirm             → selectedId != nil && !sending
footer=.send                → selectedId != nil && !sending
                              && (receivers=nil || receivers.selection.nonEmpty)
                              && (balance=hidden || balance.value >= gift.price*count)
footer=.askFor              → selectedId != nil && !sending
footer=.custom(_, action)   → 由 action 内部判断（Store 只透传）
```

### 1.5 minPrice / maxPrice 过滤 · Group 映射 · 数据源

- **过滤**：展示层（对齐 H5 语义）；被过滤后 selectedId 若不在 visible → clear
- **Group 名映射**（v3 后端 group name → panel tab，v2 补 Lucky Gift）：
  ```swift
  case "popular": .popular
  case "exclusive", "exclusive gift", "luxury": .exclusiveGift
  case "lucky", "lucky gift", "luckygift": .luckyGift
  default: drop  // 未知 group 记 log + 忽略
  ```
- **DataSource**：
  ```swift
  protocol GiftPanelDataSource {
      func loadGifts() async throws -> [GiftPanelGroup]  // 一次拉全部 tabs
  }
  struct GiftPanelGroup { let tab: GiftPanelTab; let gifts: [GiftListData] }
  ```
  实现：
  - `DefaultGiftDataSource(scene:)`：调 `getGroupedGiftList(scene:)`（新加，保留分组）+ Group 映射 → panel groups
  - `IMGiftDataSource(service:)`：包 `GiftMessageServiceProtocol.fetchGifts()` → 单 popular group + `GiftMessageItem → GiftListData` adapter
- **GiftService 新方法**：`getGroupedGiftList(scene:) -> [String: [GiftListData]]`（保留 dict）；`getGiftList` flatten 版**保留**（2 处非 picker 调用点仍在用）

### 2.2 Config

```swift
struct CommonGiftPanelConfig {
    var tabs: [GiftPanelTab] = [.popular]
    var initialTab: GiftPanelTab?  // 默认 tabs.first；不合法时降级到 first
    var footer: FooterMode
    var countStepper: CountStepperConfig = .hidden
    var balance: BalancePolicy = .hidden
    var backpack: BackpackEntryPolicy = .hidden
    var receivers: ReceiversConfig?  // nil = 隐藏
    var minPrice: Int64?
    var maxPrice: Int64?
    var initialSelection: GiftListData?
    var interaction: InteractionMode = .selectable
    var title: String?  // sheet header title
    var dataSource: GiftPanelDataSource
    var onDismiss: (() -> Void)?  // ×/swipe 触发；IM cancel 借这个
}

enum GiftPanelTab: String, Hashable, CaseIterable {
    case popular, exclusiveGift
}

enum FooterMode {
    case none                                                     // 直播中纯展示
    case confirm(labelKey: L10nKey, onConfirm: (GiftListData, Int) -> Void)
    case instantSelect(onSelect: (GiftListData) -> Void)          // IM tap 即触发
    case send(onSend: (GiftListData, Int, [String]) -> Void)      // 派对房（H+ mock）
    case askFor(onAsk: (GiftListData) -> Void)                    // 1v1（H+ 占位）
}

enum InteractionMode { case selectable, readonly }
enum CountStepperConfig { case hidden; case visible(range: ClosedRange<Int>) }
enum BalancePolicy { case hidden; case visible(source: GiftPanelBalanceSource) }
enum BackpackEntryPolicy { case hidden; case visible(onTap: () -> Void) }

struct ReceiversConfig {
    var items: [ReceiverItem]
    var allowMultiSelect: Bool
    var initialSelection: Set<String>
    var showAllButton: Bool
}
struct ReceiverItem: Identifiable { let id: String; let avatarURL: URL?; let seatIndex: Int? }

protocol GiftPanelBalanceSource {
    func currentBalance() async -> Int64?  // 本轮 stub 返 nil
}
```

### 3.1 关键 UI 参数
- Grid：4 列，cell 宽 ≈ (screenWidth - 32 - 3*8) / 4 ≈ 78pt；image 56×56；每 cell 加 `contentShape(Rectangle())`
- Tab bar：仅 `config.tabs.count > 1` 才渲染；underline pill（pink）
- **Sheet detent（v3 决策）**：Panel 内**不**挂 detent；由调用方在 `.sheet` 内层挂：
  - 直播中 `.liveDisplayOnly` → `[.fraction(0.4), .large]`（保持视频画面顶部可见 + 可拖大）
  - 开播设置 `.callGate` / 心愿单 `.wishGift` → `[.fraction(0.5), .large]`（选礼物 + 底部 stepper）
  - IM `.imBind` → `[.large]`（对齐旧 GiftMessagePickerSheet 全屏体验）
  - 派对房 `.partySend` H+ 待定
- 全部挂 `.presentationDragIndicator(.hidden)`（对齐设计稿）
- 切图：`ic_backpack`, `充值货币`（balance icon）导入 Assets.xcassets
- 其他 icon：SF Symbol `xmark` / `plus.circle.fill` / `minus.circle.fill` / `diamond.fill`（sf-symbol-usage-preflight 已知有效）
- background: `Theme.Palette.liveBottomDark` 或新加 `giftPanelBackground` gradient token

### 3.2 SwiftUI 陷阱清单
