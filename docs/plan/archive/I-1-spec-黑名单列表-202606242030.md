## §3 状态机草图

### 3.1 视图主状态
```
┌──────┐  enter   ┌──────────────────┐   success    ┌────────┐
│ idle │ ──────▶  │ loadingFirstPage │ ──────────▶ │ loaded │
└──────┘          └──────────────────┘             └────┬───┘
                          │                              │ scroll-bottom
                          │ error                        ▼
                          ▼                       ┌─────────────┐
                      ┌──────┐                    │ loadingMore │
                      │error │ ◀── retry ──────── └─────┬───────┘
                      └──────┘                          │ append / error / hasMore=false
                                                        ▼
                                                    ┌────────┐
                                                    │ loaded │
                                                    └────────┘
```
- 下拉刷新（refreshable）= reset 到 `loadingFirstPage`（loadGeneration +1）；users 数组本地暂存到 refresh 完成
- 触底加载状态独立于首次加载；UI 渲染区分（首页占满屏 spinner / footer 行内 spinner）

### 3.2 单条目子状态
```
normal ──tap delete──▶ confirming ──confirm──▶ removingOptimistic ──success──▶ removed
                          │                            │
                          │ cancel                     │ error
                          ▼                            ▼
                       normal                   restoreCheck (token 对比)
                                                  │              │
                                              token 一致      token 失效
                                                  │              │
                                                  ▼              ▼
                                          回原 index + toast   弃回滚 + warn 日志
```

### 3.3 关键不变量
1. **loadState 单一态**：任一时刻 ∈ {idle, loadingFirstPage, loadingMore, loaded, error}，单一确定值
2. **乐观删除原子性**：本地 list 立刻 -1 行 + 行 view dismantle，pending set 含 userId 期间按钮 disabled
3. **失败回滚位置稳定**：除非 token 失效，必须插回**原 index**（不是末尾）
4. **删除并发隔离（loadGeneration）**：删除请求记录发起时 token；接口回错后**对比当前 loadGeneration**，不一致直接弃回滚 + warn 日志（避免把已被刷新掉的过期数据插回）
5. **删除守卫**：`items.isEmpty` 时禁止响应 delete 事件（接口异常或竞态导致空 list 仍持有引用时的兜底）
6. **`transientError` 生命周期**：设置后 2s 自动清空（`.task(id: msg) { sleep 2s; clear }`，与 FollowList 一致）；同一时刻只显示一条
7. **触底 + 刷新隔离**：下拉刷新会 reset users + token +1；如有触底加载正在飞，回包时通过 token 判定是否丢弃
8. **session 失效跨场景**：删除接口途中触发 1004/1005 → APIClient 已自动 `NotificationCenter.post .apiSessionInvalidated`，SessionStore 触发 logout，RootView 切到 LoginView；本页**无须 dismiss** 逻辑（pop 由 root 切换自动完成）

## §4 接口契约 + 数据层映射

### 4.1 接口清单 + 解码兜底

| 接口 | 路径 | 入参 | 响应 |
|---|---|---|---|
| 拉取黑名单 | `POST /api/user/blackList` | `{currentPage: Int, pageSize: Int}` | `result` = `[BlocklistItem]`（数组直接 root） |
| 移除黑名单 | `POST /api/user/removeBlockUser` | `{type: 1, userId: Int, yxAccid: String}` | `result` = null（envelope code=0000 即成功） |

> APIClient 已处理 envelope `{code, message, result}` + 1004/1005 分流 + AES 上下行不对称编码（上 Base64 / 下 Hex）。

**解码 5 路 fallback（Service 必须实现，参考 FollowListService）**：
```swift
static func decodeBlocklist(from data: Data) -> [BlocklistItem] {
    // 1. APIClient 在 result=null 时返回 Data("null".utf8)（实测）
    //    Swift JSONDecoder.decode([T], from: Data("null")) 抛 valueNotFound — 必须先检测
    if String(data: data, encoding: .utf8) == "null" { return [] }

    let decoder = JSONDecoder()

    // 2. 顶层数组（H5 标准响应）
    if let arr = try? decoder.decode([BlocklistItem].self, from: data) {
        return arr
    }

    // 3. {list/rows/data/items: [...]} 包裹
    if let wrapped = try? decoder.decode([String: [BlocklistItem]].self, from: data),
       let list = wrapped["list"] ?? wrapped["rows"] ?? wrapped["data"] ?? wrapped["items"] {
        return list
    }

    // 4. 顶层字典误返（非数组）→ 空数组 + warn 日志，触发 step 3 反悔
    if let _ = try? JSONSerialization.jsonObject(with: data) as? [String: Any] {
        logger.warning("decodeBlocklist: got dict not array, data=\(String(data: data, encoding: .utf8) ?? "")")
        return []
    }

    // 5. 完全无法解析 → 抛 APIError，向 ViewModel 暴露真实失败
    throw APIError(code: "-2", message: "黑名单数据解析失败")
}
```

### 4.2 BlocklistItem 数据模型（严格 + fail-fast）

```swift
struct BlocklistItem: Identifiable, Codable, Equatable {
    let userId: String          // ⚠️ 严格 String，与 H5 type.ts 对齐；类型偏移 → decode 抛错
    let nickname: String
    let icon: String?           // 可能空串；UI 兜底用默认头像
    let countryId: String?      // 国家 code（如 "US"），UI 显示国旗 emoji + ID
    let age: Int?               // 0 / nil 时不显示
    let yxAccid: String         // 移除接口必传
    let gender: Int?            // 1/2，UI 暂不展示但保留
    let userType: Int?          // 1-4 主播/用户类型，UI 暂不展示
    let createTimeMs: Int64?    // ms timestamp（Int64 避免 Double 精度风险）

    enum CodingKeys: String, CodingKey {
        case userId, nickname, icon, countryId, age, yxAccid, gender, userType
        case createTimeMs = "createTime"     // H5 字段 createTime
    }

    var id: String { userId }
    var createdAt: Date? {
        guard let ms = createTimeMs, ms > 0 else { return nil }
        return Date(timeIntervalSince1970: TimeInterval(ms) / 1000)
    }
}
```

**反序列化反向用例**：
- `userId` 缺失或为 `Int` → decode 抛 `typeMismatch` → service 抛 APIError → ViewModel error 态（**目的：暴露契约偏移，不静默兼容**）
- `icon/countryId/age/gender/userType/createTimeMs` 缺失 → optional 兜底，UI 显示占位
- `status` 字段（H5 永远 null）→ 不解码、不存储

### 4.4 乐观更新 + 失败回滚（v2 重写）

```swift
@MainActor
final class BlocklistViewModel: ObservableObject {
    @Published private(set) var items: [BlocklistItem] = []
    @Published private(set) var loadState: LoadState = .idle
    @Published var transientError: String?
    @Published private(set) var pendingRemoveIds: Set<String> = []

    private var loadGeneration: Int = 0
    private let pageSize = 20
    private var currentPage = 0
    private var hasMore = true

    func unblock(_ item: BlocklistItem) async {
        // 1. 类型转换在最外层守卫，避免任何 mutation
        guard let uidInt = Int(item.userId) else {
            transientError = L10n.blocklistRemoveBadUserId
            return
        }
        // 2. items 非空守卫（不变量 §3.3 #5）
        guard !items.isEmpty else { return }
        // 3. 同 userId 并发守卫
        guard !pendingRemoveIds.contains(item.userId) else { return }
        // 4. 找到原 index；找不到（异步刷新已删除该项）→ 不做任何事
        guard let originalIdx = items.firstIndex(where: { $0.id == item.id }) else { return }

        // 5. pending 标记 + 记录代际 token
        pendingRemoveIds.insert(item.userId)
        let myGeneration = loadGeneration
        defer { pendingRemoveIds.remove(item.userId) }   // 兜底释放

        // 6. 乐观删除
        let removed = items.remove(at: originalIdx)

        do {
            try await BlocklistService.removeBlock(
                request: BlockOptRequest(type: 1, userId: uidInt, yxAccid: item.yxAccid)
            )
            // 成功，乐观删除已生效，不做处理
            logger.info("unblock uid=\(item.userId) ok")
        } catch {
            // 7. 回滚前检测代际 token
            guard myGeneration == loadGeneration else {
                logger.warning("unblock uid=\(item.userId) failed but generation drifted, drop rollback")
                return
            }
            // 8. 失败回滚：插回原 index（边界裁剪到当前 items.count）
            let insertAt = min(originalIdx, items.count)
            items.insert(removed, at: insertAt)
            // 9. 文案：APIError 用接口 message，其他用通用网络错误
            if let e = error as? APIError {
                transientError = e.message
            } else {
                transientError = L10n.blocklistRemoveNetworkError
            }
            logger.error("unblock uid=\(item.userId) error: \(String(describing: error))")
        }
    }

    func loadFirstPage() async { await load(reset: true) }
    func loadMore() async { await load(reset: false) }

    private func load(reset: Bool) async {
        guard !loadState.isLoading else { return }
        if reset {
            loadGeneration += 1
            loadState = .loadingFirstPage
        } else {
            guard hasMore else { return }
            loadState = .loadingMore
        }
        let nextPage = reset ? 1 : currentPage + 1
        let snapshotGen = loadGeneration

        do {
            let page = try await BlocklistService.fetchActive(page: nextPage, size: pageSize)
            guard snapshotGen == loadGeneration else { return }   // 代际过期，弃结果

            // 真分页 fallback 检测：本批与上批 id 集合完全相同 → 服务端不支持真分页
            if !reset && page.map(\.id) == items.suffix(page.count).map(\.id) && !page.isEmpty {
                logger.warning("blocklist: paging returned same items, assume server doesn't support paging")
                hasMore = false
                loadState = .loaded
                return
            }
            if reset { items = page } else { items.append(contentsOf: page) }
            currentPage = nextPage
            hasMore = page.count >= pageSize
            loadState = .loaded
        } catch let e as APIError {
            guard snapshotGen == loadGeneration else { return }
            loadState = .error(e.message)
        } catch {
            guard snapshotGen == loadGeneration else { return }
            loadState = .error(error.localizedDescription)
        }
    }
}
```

### 4.5 真分页 fallback 检测（§4.4 内嵌）

服务端不支持真分页（currentPage>1 仍返第 1 页）时，spec §4.4 `load(reset: false)` 内**比对本批末尾 N 条与已加载 items 末尾 N 条 id 集合**，完全相同 → set hasMore=false + warn 日志，不进死循环。

**真集成期**该路径触发即归类 step 3 反悔——"通用知识缺失" 沉淀 `.claude/rules/真分页协商.md`。
