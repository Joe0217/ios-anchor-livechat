### 0.4 H5/iOS 二次校验
| H5 行为 | iOS 等价 | 依据 |
|---|---|---|
| streamerCountdown 300s decr | CallStore `@Published var liveCallCountdown: Int = 0` + startElapsedTask hook 每秒 -1 | 复用 elapsed task 避免独立 Task 生命周期 |
| switchShowAll toggle | CallFaceTimeView `@State private var isChromeVisible = true` + `.onTapGesture` toggle | 纯 view state，不进 store |
| CFullScreenClose 二次确认 | `@State showHangupConfirm: Bool` + `.confirmationDialog` iOS 15+ | destructive 挂断按钮 + cancel |
| topBar 头像卡 | `AvatarView(size: 40, urlString: store.current.remoteIcon)` + VStack(nickname + countryId?) | 复用现有 AvatarView |
| 5s loading | `state == .connecting && agora.remoteUid == 0` 时 ProgressView | 无需独立 timer，SwiftUI 派生 |
| haptic | `UIImpactFeedbackGenerator(.medium).impactOccurred()` iOS 10+ | iOS 16 target 不能用 iOS 17 `.sensoryFeedback` |

**冲突排除**：
- H5 `CFullScreenClose` 在 `!privateCallTips` 时显示（倒计时期间隐藏）—— iOS 沿用（`showHangupConfirm` 只在非倒计时期可触发，或干脆全期可用简化）。本轮取**简化路径全期可用**（用户随时可挂）
- gap-018 X 按钮与 gap-001 chrome toggle 联动：X 按钮点击时**先阻断 tap 冒泡**（用 Button 天然阻断），不触发 chrome toggle

### 1.2 CallStore 新增/修改

```swift
// 字段：私 call 300s 收益倒计时
@Published private(set) var liveCallCountdown: Int = 0

// startElapsedTask 每秒 tick 内 hook
private func tickLiveCallCountdownIfNeeded() {
    guard state == .connected, current.frontGameType == .live, liveCallCountdown > 0 else { return }
    liveCallCountdown -= 1
}

// state didSet 或 handleRemoteRtcChange 转 .connected 时初始化 300：
if newState == .connected, current.frontGameType == .live {
    liveCallCountdown = 300
}

// endLocally reset
liveCallCountdown = 0
```

- `@State private var isChromeVisible: Bool = true`（gap-001）

### 1.4 haptic helper（gap-critic-011）

新增 `CallHaptics` enum in CallView.swift 或 Sources/Core/：
```swift
enum CallHaptics {
    static func impact(_ style: UIImpactFeedbackGenerator.FeedbackStyle = .medium) {
        UIImpactFeedbackGenerator(style: style).impactOccurred()
    }
    static func warning() {
        UINotificationFeedbackGenerator().notificationOccurred(.warning)
    }
    static func error() {
        UINotificationFeedbackGenerator().notificationOccurred(.error)
    }
}
```

挂点：
- CircleButton action wrapper（所有按钮点击 → `.impact(.medium)`）
- weakNetworkToastToken sink → `.warning()`
- callAbnormalReason non-nil → `.warning()`
- alert End Call → `.impact(.heavy)`

ZStack {
    RemoteVideoView(manager: store.agora).ignoresSafeArea()

    // gap-020: 5s loading（state=.connecting && remoteUid=0）
    if store.state == .connecting, store.agora.remoteUid == 0 {
        ProgressView()
            .progressViewStyle(.circular)
            .tint(.white)
            .scaleEffect(1.4)
    }

    // gap-001: chrome 层挂 opacity 由 isChromeVisible 控制

            liveCallBanner.padding(.top, 12).padding(.horizontal, 16)
        }

        Spacer()
        bottomBar.padding(.bottom, 36)
    }
    .opacity(isChromeVisible ? 1 : 0)
    .animation(.easeInOut(duration: 0.2), value: isChromeVisible)
    .allowsHitTesting(isChromeVisible)   // 隐时不响应 tap（chrome 层不阻挡 root tap）

    // 本地 PIP（保持不动）
    CameraPreview(camera: camera, agora: store.agora)
        .frame(width: 110, height: 160)
        // ...
}
.contentShape(Rectangle())
.onTapGesture {
    // gap-001 + critic-001: 弹窗打开时守卫

}

    L10n.callHangupConfirmTitle,
    isPresented: $showHangupConfirm,
    titleVisibility: .visible

        CallHaptics.impact(.heavy)
        Task { await store.hangup() }
    }
    Button(L10n.callHangupConfirmCancel, role: .cancel) {}
}
// 原有 .alert(callAbnormalReason)

private var liveCallBanner: some View {
    HStack(spacing: 6) {
        Image(systemName: "dot.radiowaves.left.and.right").font(.caption)
            .accessibilityHidden(true)
        Text(liveCallBannerText).font(.caption).bold()

## §3 验收清单

### F 正向
- **F1 gap-009**：直播私 call 接通后顶部胶囊显示 "After about 300 seconds..." 每秒 -1；归 0 后显示 "Private call · Hang up to return to live"
- **F2 gap-001**：通话中点远端画面区域 chrome (topBar + bottomBar + liveCallBanner) 淡出/淡入 200ms 动画
- **F3 gap-001-a**：chrome 隐时点 root 恢复；点本地 PIP 区域不 toggle chrome（本地 PIP 是独立 view）
- **F4 gap-critic-001**：hangup 确认 dialog 打开时点 root 不 toggle chrome（guard 生效）
- **F5 gap-018**：topBar 右上 X 按钮 tap → `.confirmationDialog` 弹出 "End Call?"，End Call/Cancel 两选
- **F5-b**：点 End Call → hangup + heavy haptic；点 Cancel → dialog dismiss
- **F6 gap-023**：topBar 左侧显示 Avatar 40 + nickname；(countryId TODO 本轮不显示)
- **F7 gap-020**：state=.connecting + agora.remoteUid=0 时中央显示 ProgressView；remote uid 到达自动消失（切 .connected）
- **F8 gap-critic-011**：按静音/切摄像头/挂断按钮 → medium haptic；弱网 toast/异常 alert 触发 → warning haptic；End Call 按钮 → heavy haptic

### R 反向（critical 5-7 条）
- **R1**（state guard）：非 .connected 或 frontGameType != .live 时 liveCallCountdown 不递减
- **R2**（endLocally reset）：挂断后重拨 → liveCallCountdown 回 0，下次通话 .connected 时重新初始化 300
- **R3**（chrome toggle guard）：`.alert(callAbnormalReason)` 或 `.confirmationDialog(showHangupConfirm)` 打开时 root tap 不 toggle chrome
- **R4**（chrome allowsHitTesting）：chrome 隐藏 (opacity=0) 时按钮 hitTest 被 `.allowsHitTesting(false)` 阻断，root tap 直穿到 root onTapGesture
- **R5**（confirmationDialog dismiss）：Cancel 后 showHangupConfirm 回 false；再点 X 可重新弹出
- **R6**（loading state）：state != .connecting 时 ProgressView 不显示；agora.remoteUid > 0 时立即隐（不等 state 转变）
- **R7**（haptic in background）：切后台时 haptic 不误触发（UIKit 内部自处理，无需守卫）
