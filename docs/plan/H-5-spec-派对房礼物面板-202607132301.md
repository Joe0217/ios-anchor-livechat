### 2.2 状态迁移（红队 P1-7/P1-8/P1-10 补漏）

```
[initial]
    │ .task loadInitial()  ← 并行拉 gift list + balance；仅 gift list gate .loaded
    ▼
[loading] ──gift ok──▶ [loaded] ◀────────────────────────┐
    │                    │                                │
    │ gift fail          │ tap Send                       │ retry / recharge complete
    ▼                    ▼                                │
[loadFailed]         [sending] ← R10 guard 期间冻结所有交互（tap/stepper/receivers change）
                       │                                  │
              ┌────────┼─────────┬───────────────────────┤
              │        │         │                       │
              ▼        ▼         ▼                       │
           [sent] ─300ms─▶ [loaded] （余额从 response.userDiamond 更新，若非 nil）
           [sendFailed] ── tap "Retry" ─▶ [sending]      │
                        └── 3s auto ────▶ [loaded]       │
           [insufficientBalance]                          │
              ├─ tap "Recharge" → toast "充值功能开发中"（本轮）
              └─ 保留 phase；下次关面板重开走 initial 重拉 balance
```

**关键补漏**：
- **R10 sending 冻结**：sending 期间 seatList 变化（有人上/下麦）→ **不更新** selectedYxAccids；sending 结束 phase → loaded 时**一次性重算** `isAllSelected` computed 值（原 R12 语义修订）
- **sendFailed UI**：底部按钮 label 变 `Retry`，保留 selection/count；tap Retry → sending 重发同 payload；或 3s 自动回 loaded 让用户手动
- **balance 不阻塞 loaded**：`loading → loaded` 只 gate gift list；balance 独立回来即渲染胶囊

### 2.4 API Model 扩展（红队 P0-2 · CodingKeys 多别名）

```swift
// Sources/Party/Models/PartyEvents.swift 改造
struct PartySendGiftResult: Decodable {
    let success: Bool
    let giftId: Int64
    let num: Int
    let totalValue: Int64?
    let userDiamond: Int64?      // 新增：sendGift 后新余额

    enum CodingKeys: String, CodingKey {
        case success, giftId, num, totalValue
        case userDiamond, userDiamonds, newDiamond, remainDiamond  // 多别名 fallback
    }

    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        success = try c.decode(Bool.self, forKey: .success)
        giftId = try c.decode(Int64.self, forKey: .giftId)
        num = try c.decode(Int.self, forKey: .num)
        totalValue = try? c.decode(Int64.self, forKey: .totalValue)
        // 多字段名兜底（红队 P0-2 · 对齐 agent-recon-field-names-unverified rule）
        userDiamond = (try? c.decode(Int64.self, forKey: .userDiamond))
                   ?? (try? c.decode(Int64.self, forKey: .userDiamonds))
                   ?? (try? c.decode(Int64.self, forKey: .newDiamond))
                   ?? (try? c.decode(Int64.self, forKey: .remainDiamond))
    }
}
```

### 2.6 R9 生命周期（红队 P0-4）

红队指出：`@StateObject` 面板销毁后 sending Task 会被 cancel 传播。**决策**：
- **A. 关面板 = 取消 sending Task**（简单幂等 · 推荐）
  - 服务端幂等：若已扣款 → 用户开 panel 时 balance API 重拉兜底
  - sending 已发 HTTP 若网络 in-flight → 取消无实际用（HTTP 已在链路上），成功依然扣款；服务端会 IM 广播礼物特效；用户下次开 panel 看到扣款结果
- B. Task.detached 顶层承接（复杂 · 本轮不做）

**采用 A**。R9 修订：见 §3.2。

## §3 验收清单

### 3.1 正向 F

- **F1** 首次打开面板 → phase: initial → loading → loaded；**balance 独立不阻塞 loaded**（红队 P2-12）；礼物 grid 显示 4 列 popular
- **F2** 接受者头像行按 seatIndex 显示占位座位（过滤自己 + yxAccid 非空）；默认单选（owner 优先，否则第一个有效 yxAccid）
- **F3** tap 头像 → 切换 yxAccid 选中态（多选）
- **F4** 右侧滑块 → 全选/清空；手动改单个头像 → isAllSelected computed 自动 off
- **F5** tap 礼物 cell → 选中态视觉；再 tap 同礼物 → 保持
- **F6** 步进器 -/+ → count ∈ [1, 99]；边界灰化
- **F7** tap Send（选礼物 + 接受者 + count + balance ≥ giftPrice × count）→ sending → PartyAPI.sendGift → 成功 → sent → 300ms 关面板 + toast + 余额从 response.userDiamond 更新（若 nil 则重拉 balance API 兜底）
- **F8** 余额胶囊显示当前 balance（`--` 若 nil）；tap 胶囊 → toast "充值功能开发中"（本轮不做真充值页）
- **F9** 关闭面板（下拉/drag indicator）→ Store reset selection + count + phase = initial
- **F10** phase = sendFailed → 底部按钮 label 变 "Retry" · 保留 selection/count；tap Retry → sending 重发（红队 P1-7）
- **F11** phase = insufficientBalance → 底部按钮 label 变 "Recharge" · tap → toast + 保持 phase；关面板重开走 initial 重拉 balance（红队 P1-8）

### 3.2 反向/边界 R

- **R1** 未选礼物 tap Send → 本地 `canTriggerAction=false` 静默拦截（现 UI 灰态）
- **R2** 无接受者 tap Send → 同上
- **R3** balance < giftPrice × count → `canTriggerAction=false` + phase 切 insufficientBalance
- **R4** sendGift 后端返回 **`code == "1019"` 精确判定**（红队 P1-9 · 删 substring match）→ phase: insufficientBalance
- **R5** sendGift 网络失败 / 其他错误码 → phase: sendFailed(msg) · toast msg · 不关面板
- **R6** balance API 失败 → 余额显示 `--` · **不阻塞** sendGift 本地校验（服务端会兜底校验，若真不够走 R4）
- **R7** gift list API 失败 → phase: loadFailed · error banner + retry
- **R8** seatList 空 / 全是自己 / 全 yxAccid 空 → 接受者行 empty state "暂无可送礼对象" · Send 禁用
- **R9** sendGift 期间关闭面板 → **Task 被 cancel 传播**（红队 P0-4）· 服务端幂等 · 若已扣款下次开 panel balance API 重拉兜底
- **R10** 快速连击 Send → `isBusy` guard 拦截第 2 次
- **R11** 步进器边界（1/99）→ 按钮 guard
- **R12** sending 期间 seatList 变化 → **冻结 selectedYxAccids 变更**（红队 P1-10）；sending 结束 phase → loaded 时**一次性重算** isAllSelected
- **R13** 面板打开中 PartyStore.currentRoom = nil → Panel 由 PartyRoomView 底层 dismiss 兜底
- **R14** seat.yxAccid nil / 空串 → **该头像不进 recipients 列表**（红队 P1-6 补漏）
