# 用户权限管理系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地一套账户级硬性权限系统：根据登录用户 `userType`（101-106 六种黑名单值）在 UI + Store + RTM 三层同步阻断 通话/匹配/直播/Party 四大功能入口。

**Architecture:** 单一 shared `SelfPermissionBridge`（双 API：@MainActor @Published + nonisolated snapshot）订阅 `SessionStore.$user.userType` 派生 3 个 Bool（canCall/canLive/canParty，`.call` bit 同时代表匹配）。UI 层用 @Published 声明式订阅；Store async method 用 snapshot 原子读；RTM `videoCall` handler 前置 auto-reject。段位 `CallAuthBridge` 保留不动，仅参与 LiveList/UserProfile/ChatDetail 3 处 UI 显示的 AND 组合。

**Tech Stack:** Swift 5 · SwiftUI · Combine · XCTest（HilyTests 白名单 target）· iOS 16 target

**Spec reference:** [docs/plan/P-spec-用户权限管理系统-202607151908.md](P-spec-用户权限管理系统-202607151908.md)

**TDD 约定**：Task 2/3 严格 test-first（写 test 先失败 → impl → pass → commit）。View / Store gate 的行为验证靠真机 QA（SwiftUI 不好单测），代码质量靠 build + sanity check + peer review。

```swift
// MARK: - SelfPermissionBridge

/// 权限判定 Bridge（对齐 spec §2.3 双 API）：
/// - UI @MainActor 上下文用 `$canX @Published`
/// - Store async 非 @MainActor method 用 `canXSnapshot` nonisolated 原子读
///
/// 单例约束：全项目一律用 `SelfPermissionBridge.shared`（+Shared.swift 定义）。
/// 禁止 `@StateObject SelfPermissionBridge()` new 独立实例。
final class SelfPermissionBridge: ObservableObject, @unchecked Sendable {

    // MARK: UI 层（@MainActor + @Published）
    @MainActor @Published private(set) var canCall: Bool = false
    @MainActor @Published private(set) var canLive: Bool = false
    @MainActor @Published private(set) var canParty: Bool = false
    @MainActor @Published private(set) var isLoaded: Bool = false

    // MARK: Store 层 nonisolated snapshot
    private let snapshotLock = NSLock()
    private var _snapshot: BlockedFeatures = []
    private var _isLoaded: Bool = false

    nonisolated var canCallSnapshot: Bool {
        snapshotLock.lock(); defer { snapshotLock.unlock() }
        return _isLoaded && !_snapshot.contains(.call)
    }
    nonisolated var canLiveSnapshot: Bool {
        snapshotLock.lock(); defer { snapshotLock.unlock() }
        return _isLoaded && !_snapshot.contains(.live)
    }
    nonisolated var canPartySnapshot: Bool {
        snapshotLock.lock(); defer { snapshotLock.unlock() }
        return _isLoaded && !_snapshot.contains(.party)
    }

    private var cancellables = Set<AnyCancellable>()

    /// Publisher-inject 构造（无 SessionStore 编译依赖，白名单可测）。
    /// 生产装配见 `SelfPermissionBridge+Shared.swift`。
    init(
        userTypePublisher: AnyPublisher<Int?, Never>,
        loadedPublisher: AnyPublisher<Bool, Never>
    ) {
        // 单流双元组减少上游 fire 次数（回应 review Finding 9）
        userTypePublisher.removeDuplicates()
            .combineLatest(loadedPublisher.removeDuplicates())
            .map { (userType, loaded) -> (BlockedFeatures, Bool) in
                (UserPermissionMapping.blocked(for: userType), loaded)
            }
            .removeDuplicates(by: { $0.0 == $1.0 && $0.1 == $1.1 })
            .sink { [weak self] blocked, loaded in
                guard let self else { return }
                // Step 1: 同步更新 snapshot（Store 层立即可见）
                self.snapshotLock.lock()
                self._snapshot = blocked
                self._isLoaded = loaded
                self.snapshotLock.unlock()
                // Step 2: 异步派发到 MainActor 更新 @Published（UI 订阅响应）
                Task { @MainActor [weak self] in
                    guard let self else { return }
                    self.canCall  = loaded && !blocked.contains(.call)
                    self.canLive  = loaded && !blocked.contains(.live)
                    self.canParty = loaded && !blocked.contains(.party)
                    self.isLoaded = loaded
                }
            }
            .store(in: &cancellables)
    }
}
```
