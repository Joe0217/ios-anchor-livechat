# 社交 / 内容 业务域(圈子/关注/亲密度/邀请)— 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T2-11

## 1. 业务目标与定位
本域是主播端"社交内容 + 增长"双引擎,服务内容运营、关系沉淀、拉新变现:
- **圈子(朋友圈/动态)**:主播发布图文动态(可获积分),浏览官方圈/全站/自己的动态,点赞/评论/关注建立轻互动。
- **关注/粉丝/好友关系**:维护关注/粉丝/相互好友/拉黑,是私聊、亲密度、收益归属的关系底座。
- **亲密度(CP/Close Partner)**:量化主播与单个用户关系深度,通过等级/特权/经验值引导持续聊天送礼通话"养成",提升付费粘性。
- **邀请拉新**:邀请码/海报拉新「用户」「主播」两条线,按充值/收益比例分成获钻石,辅以跑马灯/排行/收益看板/明细,人脸申诉对接惩罚。

## 2. 核心业务流程

### 2.1 圈子
**Web**(`views/circle/`):入口三 Tab+Swiper:official(官方圈)/moment(全站)/me(我的),共用 `list.vue`+`circleContent.vue`;以 `officalType`(1官方/2全站/3我的)区分,me 额外传 `keyword=userId`,统一 `getQueryList` 分页(首页覆盖、后续追加)。发布 `posts/index.vue` 校验"内容非空+至少1张图(仅图禁视频)"→ 上传 → `postCreate({displayRange:1,textContent,imgUrls})`(1全部/2私密/3朋友);点赞 `postLike({id,optionType})` 乐观更新;评论 `postComment` 蒙版输入 + `provide/inject` 跨层刷新;删除仅"我的圈"二次确认 `postDelete`;视频预览用透明占位图替换 `<video>`;翻译 `CTranslate`。
**安卓**(`CircleFragment.kt`+`CircleMainFragment`/`CircleHomeFragment`):同 `officalType` 区分,`CircleFragment.newInstance(type)` 复用;`HttpHelper.queryList` + SmartRefresh + BRVAH loadMore;发布 `CreateCircleActivity` 九宫格选图(≤9 张)→ OSS → `createCircle`(返回积分,弹"获得 xx 积分",`LiveEventBus(EVENT_REFRESH_CIRCLE)`);关注 `follow()` 成功后**全列表同步同一 userId 的 followFlag** + `LiveEventBus(REFRESH_FOLLOWING_LIST)`;点赞 `circleLike` 乐观更新(官方圈禁赞/评);评论 `CircleAddCommentDialog`;举报 `ReportDialog`。

### 2.2 关注/粉丝/好友
**Web**(`followList/index.vue`+`news/follow/list.vue`):`query.type`(Following/Followers/Friends)→ type 3/2/1,`apiGetFriendList('/api/user/v2/userFriend',{pageSize:20,currentPage,type})`。
**安卓**(`FollowFragment`/`LikeFragment`/`ContactsFragment`/`FriendActivity`/`NewFriendsFragment`):关注统一 `follow({followUserId,followType})`(1关注/2取消/3拉黑);依赖 NIM `FriendDataCache` 本地缓存,`LiveEventBus(REFRESH_FOLLOWING_LIST)` 跨页同步。

### 2.3 亲密度
**开关**:远程配置 `intimacy_enable` 控制启用(关则不展示入口)。
**Web**:轻量集成,`apiGetAnchorIntimacy('/api/intimacy/getAnchorIntimacy',{yxIdList})` 按云信 ID 批量查等级,用于头像角标/会话列表,**无完整详情/特权/提升页**。
**安卓**:完整养成体系。`IntimacyHelper`(单例,ConcurrentHashMap 缓存 + loadingMap 防并发重复请求)调 `getAnchorIntimacyList`;详情弹窗 `IntimacyDetailDialog(userId)` → `getIntimacyDetail` 双 Tab:**Privileges**(当前等级特权列表)、**Increase**(三途径加经验:聊天type1/通话type2/送礼type3,各有单次加成 `experienceAdd`、每日上限 `experienceLimit`、礼物 `needSpendCount`);状态渲染 `level<1` 未绑定/上锁,`>=1` 显等级+绑定时长+经验进度(BigDecimal 精确百分比),满级置 100;`LiveEventBus(EVENT_INCREASE_INTIMACY)` 实时刷新。

### 2.4 邀请拉新
**Web**(`views/invite/`):主页双 Tab(inviteUser/inviteAnchor),`onMounted` 并发拉:邀请统计/规则(`getConfigByKey('distribution_Invitation')`)/用户分享码(`getAnchorShareUrl`)/主播邀请信息(`getInviteInfo`)/收益跑马灯/用户主播收益比例配置/海报分享链接(`poster/floor`);组件群 marquee/rewarcCard/rankContent/rulePopup/invitePopup;明细页(`queryAnchorInviteUserDetail`/`queryAnchorInviteAwardRecord`);看板 `dashboard/`(今日/上周/上月,前端算起止戳,`inviteAnchorList`);惩罚申诉 `getPunishmentAppeal('/api/face/appeal')`。
**安卓**(mine):`MyInviteActivity` 双 Tab(各承载 `InviteUserMainFragment` 以 userType 区分);顶部 `getInviteAnchorAwardList` 跑马灯;`InviteUserMainFragment` 按 userType 切 UI,`anchorInvitePosterFloor` 拉码+海报,奖励比例(用户 `invite_user_award`;主播 `invite_anchor_award`+`anchor_invite_reward_percentage`+`gift_gems_percent`,party room 抽成=后两者相乘),内部双 Tab(我的奖励/收益排行),分享 `InviteShareDialog`;明细 `UserInviteDetailsActivity`/`InviteAwardsActivity`/`InviteAnchorFragment`。

## 3. 关键接口/SDK 分组
**圈子**:列表 `friendsCircle/v2/queryList`(circle)/`queryAnchorFriendsCircleList`(moments)、发布 `create`、点赞 `like`、评论 `comment`、评论列表 `getComments`、删除 `del`、详情 `v2/detail`。
**关系**:`/api/user/v2/userFriend`(type 1好友/2粉丝/3关注);`follow({followUserId,followType})`。
**亲密度**:`/api/intimacy/getAnchorIntimacy`(yxIdList);安卓 `getIntimacyDetail`;缓存层 `IntimacyHelper`/`IntimacyConfigHelper`。
**邀请**:邀请统计 `getAnchorInviteUserStat`、分享码 `getAnchorShareUrl`、邀请信息 `inviteInfo`、海报 `poster/floor`、跑马灯 `invite/user/award/list`、用户列表 `queryAnchorInviteUserDetail`、奖励详情 `queryAnchorInviteAwardRecord`、主播列表 `inviteAnchorListV2`/`inviteAnchorDetail`、配置 `getConfigByKey`(distribution_Invitation/invite_user_award/invite_anchor_award/anchor_invite_reward_percentage/gift_gems_percent)、申诉 `/api/face/appeal`。

## 4. 状态与数据流
- **动态分页**:`currentPage/page` 从 1,首页覆盖后续追加,返回数<pageSize 判到底;Web Swiper 三 Tab 各维护 listData,安卓 BRVAH loadMore+SmartRefresh+`EVENT_REFRESH_CIRCLE`。
- **关系状态**:`followFlag`/`likeFlag` **前端乐观更新**;安卓关注成功后**全列表同步同一用户 followFlag** + LiveEventBus 广播。
- **亲密度计算**:经验=聊天/通话/送礼三途径累加(各有单次加成与每日上限);进度=`experienceValue/upNeddExperienceValue`(BigDecimal);`level<1` 未绑定,满级 `upNeddExperienceValue<=0`;安卓 ConcurrentHashMap 缓存 + Deferred 去重。
- **邀请绑定与结算**:用户/主播两条独立线(userType);奖励比例来自配置中心;主播 party room 抽成=`anchor_invite_reward_percentage × gift_gems_percent`;看板按时间窗聚合 totalIncome/rewardIncome;明细按 `keyword=userId` 拉单用户记录。

## 5. 边界与异常
- **发布鉴黄**:前端**无显式鉴黄**,图片先传 OSS,鉴黄由后端在 `create` 接口完成;iOS 需注意"提交成功但待审核/被拒"异步态。
- **发布校验**:内容非空+至少 1 图,安卓限 9 张**仅图不可视频**,文本 500 字上限。
- **重复关注/点赞**:乐观更新+optionType 翻转;Web 失败多未回滚 UI(catch 仅 closeToast),存在短暂不一致。
- **亲密度并发**:`IntimacyHelper` loadingMap 防重复请求,异常返回 null 不缓存。
- **邀请防刷/申诉**:防刷在后端;前端提供 `/api/face/appeal` 人脸申诉。
- **复制兼容**:`navigator.clipboard` 不可用降级 `execCommand('copy')`。

## 6. Web vs 安卓差异提示
| 维度 | Web | 安卓 |
|---|---|---|
| **亲密度完整度** | 仅查等级用于角标,无详情/特权/提升页 | **完整**:CP 详情+Privileges/Increase 双 Tab+经验进度+绑定时长+升级礼物+缓存 |
| **邀请体系** | 看板/明细/跑马灯/规则/海报较完整,奖励比例计算较简单 | 双 Tab+我的奖励/收益排行子 Tab+party room 抽成复合计算+分享弹窗 |
| **圈子能力** | 三 Tab/发布(仅图)/点赞评论删除/视频预览/翻译 | 三 Tab/发布返积分/关注点赞评论举报/列表内关注状态全局同步 |
| **状态同步** | provide/inject + sessionStorage | LiveEventBus 全局事件总线 |

## 7. iOS 实现注意点
1. **接口完全复用 Web/安卓后端**(`friendsCircle/*`、`/api/anchor/*`、`/api/intimacy/*`、`userFriend`),注意请求体加密/公共头/Token 刷新对齐。
2. **参数枚举对齐**:`officalType`(1官方/2动态/3我的)、`displayRange`(1全部/2私密/3朋友)、`followType`(1关注/2取消/3拉黑)、`optionType`(1赞/0取消)、关系 `type`(1好友/2粉丝/3关注)、邀请 `userType`(1/USER、2/ANCHOR)必须严格一致。
3. **发布**:仅图不可视频,9 张上限,文本 500 字;图片先传 OSS;鉴黄在后端,处理"返积分"与"审核中/被拒"异步态。
4. **亲密度对齐安卓**:实现 CP 详情(特权+三途径加经验配置+经验进度+绑定时长),本地缓存+请求去重,受 `intimacy_enable` 开关控制。
5. **乐观更新+失败回滚**:点赞/关注乐观更新并在失败时回滚(Web 当前未回滚,iOS 应补齐);关注成功同步同一用户多条动态状态。
6. **配置中心**:邀请规则/奖励比例走 `getConfigByKey`/`getConfigMapByKey`,缓存远程配置;party room 抽成复合计算。
7. **跨页刷新**:用 NotificationCenter(对应 LiveEventBus/sessionStorage)实现发布后刷新/关注后同步。
8. **申诉入口**:`/api/face/appeal` 惩罚申诉,与人脸/账号合规相关。
