# 任务 / 成长 / 工作台 业务域 — 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T1-7

## 1. 业务目标与定位
该域是主播端"日常运营驱动中枢",三条主线把主播留在平台并提升产出:
- **工作台(Work/HomeWork)**:主播二级首页/控制台,聚合所有运营入口(开播/匹配/任务/美颜/积分/礼物消息/资料/邀请/背包/数据/新人任务/大R),展示等级/进度、今日收入分项、在线时长/接通数/好评率 KPI,承载 IM 在线/离线开关。
- **任务体系**:每日任务(限时/全天)、每周任务(积分制)、新人/新主播任务(任务组闯关+排行)、平台机器人任务(robotTask),配排行榜与领奖。
- **等级成长**:基于周均通话时长、接通率、通话数自动升降级(D/C/NEW/B/A/S/SS 七档),对应不同权益;另有亲密任务(新好友/好友活跃)。

定位差异:**Web 是 webview 内嵌轻量运营页,任务拆分细、以页面跳转为主;安卓是原生宿主,承担在线时长真正的计时上报、新手引导等重逻辑。**

## 2. 核心业务流程

### 2.1 Web 端
**工作台** `views/work/index.vue`(`/work`):`onMounted` 并行拉「新主播任务」「大R名单」入口显隐(后端控制)过滤 13 项工具网格;拉主播信息渲染等级徽章/进度条/今日收入 6 分项/在线时长接通好评卡片/系统信息;**IM 在线离线** `appStore.IMOnline` 双向绑定,下线先二次确认;新手任务浮层由 `qAnchorTaskStore.isShowTaskEntry()`(倒计时未结束+后台开关 `anchor_call_task_open`)控制。
**任务中心** `views/task/index.vue`(`/task`):顶部 rank progress + task progress;Tabs daily(`/api/task/v2/get` 返回限时+全天)/weekly(`taskInfo` 返回 taskVos+myIntegral,叠加活跃大R 任务面板);`provide('submitReward')` 下发刷新函数,领奖后全量刷新。
**领奖** `taskItem.vue`:仅 `rewardStatus===1`(可领)可点 → `getReward({taskId})` → 刷新;`===3` 显示 Claimed 禁用。
**每日任务** `views/dailyTask/`:复用 task 组件只展示 daily,顶部 `serverTime.vue` 本地东八区时钟。
**新主播任务** `views/newBie/`(`/newBie`):`list` 返回 taskGroups[初级/高级](tasks/rewards/completedCount/rewardClaimed)+countdown+canComplete;`rankList`(本/上周)拆 top3+其它+我的排名;点任务按 `taskType` 路由,开播类先 `checkLiveBroadcastPermission`(2001 无权限/1992 封禁拦截);领奖 `claimReward({groupId})`。

### 2.2 安卓端
**工作台** `HomeWorkFragment.kt`(LazyFragment):`onResume` → `setHide`(同步在线离线图标)→ `loadAnchorInfo`(等级进度 cpbLevel/收入分项/在线时长)→ `loadBalanceInfo`→`checkBigRVisible`→`startTimeTiming`(本地东八区时钟显示);**IM 离线**点击弹确认且每日下线次数 `>2` 限制;**新人任务嵌入** `setNewbieTask` 判断后台开关+`newAnchorEndTime` 动态 add/remove `RobotTaskListFragment`。
**新主播任务** `NewStreamerTasksMainActivity`/`LiveNewStreamerTasksMainActivity`(直播间内)→ `NewStreamerTasksMainFragment`;直播间内三快捷弹窗 `DailyTasksDialog`/`OnlineTasksDialog`/`NewStreamerTasksMainDialog`。
**机器人/平台任务** `RobotTaskListFragment.kt`:`robotTaskList` 填列表;`Flowable.interval(1s)` 倒计时到 `newAnchorEndTime` 归零自动移除;领奖经 `LiveEventBus(NEW_ANCHOR_TASK_NOTICE)` → `robotTaskClaim`;首项 `RobotTaskHelper.showGuide` 新手引导。
**等级成长** `LevelDetailsActivity.kt`:`anchorAutoLevelUpInfo`(本/上期 接通率/均时长/通话数+进度)、`getLevelConfig`(`gradeEquityHave`/`gradeEquityNone` 权益)、`dataPreview`(赞/踩/差评率);差评抵扣 `OffsetDislikeDialog`。`LevelTaskActivity`/`TaskDetailsActivity` 等级任务明细。
**亲密任务** `IntimateTaskActivity.kt`:两 Tab(新好友/好友活跃),`getIntimacyTaskExpireTime` + 倒计时。

### 2.3 在线时长计时与上报(安卓核心,Web 不实现)
由 `ActivityLifecycleCallbacksForOnlineStatistics.kt` 全局监听驱动,**双轨制**:
- 触发:`isAnchor && MainActivity 存在 && 前台 Activity>0`,`Observable.interval(1s)`。
- **轨道A 收益上报**:每 5 分钟 `addUpOnlineTime(300)`(`{dayDate,daySeconds,monDate,monSeconds}`);跨天边界结算当天剩余;退后台 >60s 补传。
- **轨道B 任务在线时长**:每分钟 `OnlineTaskHelper.cumulativeOnlineTimeInTask()` 按各任务 `beginTime/endTime`(支持跨天)定位命中段,`onlineTimeMin+=1`,以 `taskId+年月日` 存 SP,经 `LiveEventBus(UPDATE_ONLINE_TIME)` 推给弹窗。**此轨只本地累计/展示,不直接上报,切段清零。**

## 3. 关键接口/SDK 分组
**Web 任务** `api/task`:`getAnchorRanking`(排行进度)、`getAnchorRankingV2`(`/api/task/v2/get` 每日)、`getTaskInfo`(每周+积分)、`getReward`(领奖)、`getActiveTycoonTaskPanel`(活跃大R)。
**Web 新人** `api/newBie`:`checkEntryVisible`/`list`/`rankList`/`updateProgress`/`claimReward`/`rewardRecords`/`robotTask{list,claim,ruleConfig}`。
**安卓**(Base64 URL):工作台 `requestAnchorInfo`/`addUpOnlineTime`;等级 `getLevelConfig`/`anchorAutoLevelUpInfo`/`dataPreview`;亲密 `getIntimacyTaskExpireTime`;机器人 `robotTaskList`/`ruleConfig`;大R `bigRanchorEntryVisible`;新人 `checkEntryVisible`。统一 `HttpResult`(code==200)+`RxObserver`。

## 4. 状态与数据流
- **任务进度**:`(curScore/targetScore)`;`rewardStatus`(1 可领/3 已领)决定按钮态;任务组 `completedCount/totalCount`+`rewardClaimed`。
- **倒计时与服务器时间**:Web `van-count-down`+`qAnchorTaskStore.getRemainingTime()`;`serverTime.vue` 用 `getTimezoneOffset()+480min` **本地算东八区**(API 方案注释保留未启用)。安卓同样 `GMT+8` 本地算时钟,倒计时用 `newAnchorEndTime-now`。
- **在线时长**:安卓 `onlineTimeMin` 单例+SP 持久化(key=`taskId+YMD`);收益上报以 timeEnd 锚点累加秒。
- **领奖结算**:Web `provide/inject` 回调全量刷新;安卓 `LiveEventBus` 事件解耦刷新。
- **持久化**:`qAnchorTaskStore` 仅持久化 `isFirstWork`;`todayShowNewbieEndPopup` 控结束弹窗每日只弹一次。

## 5. 边界与异常
- **任务过期/活动结束**:Web newBie `canComplete=false` Toast "Activity has ended",当天弹一次结束弹窗;安卓倒计时归零自动 remove。
- **重复领奖**:Web `rewardStatus===3` 禁用 Claimed;规则弹窗 `rulePopupLock` 防抖;后端最终校验。
- **服务器时间偏移**:两端均本地推算东八区**未对时**,改系统时间会致倒计时/在线段判断偏差(已知技术债)。
- **在线计时中断**:安卓退后台计数归零即停,>60s 才补一段;任务在线切段 `onlineTimeMin` 清零(`onlineTaskEntityList!!` 强解包有空指针风险)。
- **入口显隐兜底**:大R/新人入口接口失败时主动隐藏。

## 6. Web vs 安卓差异提示
| 维度 | Web | 安卓 |
|---|---|---|
| 工作台 | `work/index.vue` 13 项固定网格+动态过滤 | `HomeWorkFragment`+`MyToolsFragment` 工具 Tab |
| 任务拆分粒度 | 细(task/dailyTask/newBie/work 内嵌四套页) | 粗(统一容器+直播间三弹窗) |
| 等级/亲密任务 | 仅 work/dataStatistics 展示,无独立亲密页 | 独立 `LevelDetails`/`IntimateTask`/`LevelTask` |
| 在线时长 | **不实现计时上报**,仅本地时钟 | **核心**:双轨(5min 收益+1min 任务)+SP 持久化 |
| 在线/离线开关 | `appStore.IMOnline` 纯前端 | `LibApp.isHide`+每日下线次数限制 |
| 刷新机制 | Pinia + provide/inject | RxJava + LiveEventBus |

## 7. iOS 实现注意点
1. **在线时长是 iOS 硬骨头**:复刻安卓双轨——App 级前后台+主页存在判断起 1s 定时器;5 分钟上报 `addUpOnlineTime`,跨天与退后台 >60s 补传;任务在线按段命中以 `taskId+年月日` 本地累计(UserDefaults)。**iOS 后台会被挂起,定时器不可靠,建议用进入后台时间戳差值补算**而非持续 timer。
2. **服务器时间**:建议改为以服务器下发时间戳为基准做倒计时,规避用户改系统时间。
3. **入口显隐与降级**:工具入口先查 `checkEntryVisible`/`bigR…EntryVisible` 失败兜底隐藏;新人任务叠加后台开关+`newAnchorEndTime` 双条件。
4. **领奖防重复**:UI 禁用+防抖,后端最终校验。
5. **任务跳转权限拦截**:开播类任务跳转前 `checkLiveBroadcastPermission`,处理 2001/1992。
6. **解耦刷新**:用通知中心(对应 LiveEventBus)驱动局部刷新。
7. **等级体系**:七档 D/C/NEW/B/A/S/SS 固定配色与进度映射(i/7),升降级依据 `anchorAutoLevelUpInfo` 本/上期对比,如实展示而非客户端计算。
