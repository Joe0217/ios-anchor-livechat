# 数据 / 排行榜 业务域 — 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T1-8

## 1. 业务目标与定位
面向主播端的"数据可视化 + 激励"复合域,四条子线:
- **直播数据看板**:按周/月、本/上周期,展示总时长、总收益(直播钻石+私call钻石),倒计时驱动冲量;常驻"钱袋子"浮标展示任务待领钻石。
- **数据统计/等级面板**:好评/不喜欢及不喜欢率、每周自动升降级三指标(接听率/平均时长/通话数)本/上周对比、当前等级权益清单(有/无)、用积分"抵扣一次不喜欢"的扣分纠偏。
- **排行榜矩阵**:主播榜(魅力/财富)、CP 榜、积分榜,按日/周/月切换,Top3 特殊展示、周榜奖励标签、CP 双人奖励弹窗、我的排名吸底。
- **高价值用户运营**:Web "大R名单"(本/上周大R榜+钻石明细+私聊直达),安卓对应"违规记录"(合规约束)。

两端共用同一后端契约(直播数据 `api/anchor/live/authorLiveData`、排行榜 `api/ranking/getRankingList`、积分榜 `api/ranking/anchorIntegralRankingList` 地址完全一致),iOS 应复用。

## 2. 核心业务流程

### Web 端
**直播数据看板** `liveData/index.vue`:一级 Tab weekly/monthly + 二级 this/last(月份多 twoMonthsAgo)→ 组合映射 `queryType` 0-4 → `getLiveData({dateType})`;渲染总时长(秒→HH:MM:SS)/总收益/可折叠明细;仅"本周期"显倒计时;并行拉 `getAnchorRankingV2` 取 `sureGetAward` 填钱袋子浮标点击跳 `/task`。
**数据统计/等级面板** `dataStatistics/index.vue`:并行三接口 `getDataPreview`(好评/不喜欢/率)、`getAnchorAutoLevelUpInfo`(周升降级,`levelDataConfVos` 含 Preview/Last 双列:接听率/平均时长/通话数/更新时间)、`getGetLevelConfig`(权益 `gradeEquityHave`/`gradeEquityNone`);"Offset Dislike"流程:`getCheckCondition` 取当前积分/本周剩余次数(`isDeduction===0` 禁用)→ `getDeduction` 抵扣,积分不足提示。
**排行榜** `rank/index.vue`:三态 魅力/财富主播榜 + CP 榜;`from=gameTask` 进游戏任务榜模式;nav×period 9 组合映射 rankType(`ANCHOR_/USER_ + DAY/WEEK/MON`)→ `getGetRankingList` 取 `rankingMembers`+`rankingMineVo`,Top3 重排 [2,1,3] 居中;周榜才显奖励标签;CP 榜独立组件 `cp-rank-list.vue`(Day/Week 切换,`getRankingListV2({rankType:'ANCHOR_USER_COUPLE'})`,双人头像卡+我的 CP 吸底,Top 奖励触发 `CpRewardPopup`,无 userId 为 Mystery);进出埋点 `h_rank_view`/`h_rank_leave`。
**积分榜** `pointsRank/index.vue`:`anchorIntegralRankingList({searchValue:'week'})`,我的积分+周结算重置说明+Top3+列表。
**大R名单** `bigr/index.vue`:本/上周 Tab `getBigRListApi({week})`,头部汇总卡(周起止+总钻石+明细入口),卡片列表每个大R含钻石与明细;**私聊须先 `getUserDetail` 换 `yxAccid` 再跳 `/chat`**(防抖,直传 userId 会致 p2p 发送失败);入口可见性 `getBigREntryVisibleApi` 探针控制。

### 安卓端
**直播数据** `LiveStreamDataActivity.kt`:RadioGroup 周/月+`SelectTimeAreaDialog` 二级时段;`getAuthorLiveData` 同 Web 字段;明细 Adapter 展开/收起;本周/本月才显倒计时(`Flowable.interval` 每秒手算并 `runOnUiThread`,finishing 时 `stopTimeTiming`);钱袋子 `getTaskProgress().sureGetAward` 跳 `TaskDetailsActivity`;规则 `LiveStreamDataRuleActivity`。
**排行榜**(双套并存):旧 `RankActivity`+`RankPagerAdapter`(三 Tab+ViewPager2,刷新走 `LiveEventBus(RANK_REFRESH)`);新 `RankTypeActivity`(魅力 ANCHOR/荣耀 USER 外层)→`RankTypeFragment`(周期内层)→`RankListFragment`(`getGetNewRankList({rankType,currentPage,pageSize:30})`,手填金/银/铜位再 `subList(3,...)`,`rankingMineVo` 吸底,仅 `ANCHOR_WEEK` 显奖励);积分榜 `IntegralRankActivity`(`fill1to3` 金银铜,规则文案 `getConfigByKey('integral_ranking_rule')` 远程下发首次进入弹出)。
**推荐/星座** `RecommendActivity`/`ConstellationActivity`(星座本地静态 12 项单选,无接口,服务于推荐打招呼,**非榜单**)。
**违规记录** `ViolationRecordActivity.kt`(mine):两段式 `callViolationRecordOne`(汇总)+`callViolationRecordTwo`(列表,按 week/month、status All/Violation/Processing/Rejected 过滤);PopupWindow 筛选;每条可"申诉",经 ARouter `checkAppeal` 校验。

## 4. 状态与数据流
- **数据口径(周期切换)**:直播数据用整数 `dateType/queryType`(0本周/1上周/2本月/3上月/4上上月);排行榜用字符串枚举 `ANCHOR_/USER_+DAY/WEEK/MON`;积分/CP 用 `searchValue`/`dailyType`;大R 用 `week=current|last`。切周期一律清空旧列表再请求,避免串档。
- **等级自动升降级**:以 `anchorAutoLevelUpInfo.levelDataConfVos` 三指标本/上周对照呈现,`levelUpdateTime` 生效时间;面板只读,实际升降级后端按周计算;权益分 have/none 两组。
- **扣分/达标**:不喜欢率超标可用积分抵扣(`checkCondition` 返回积分/本周剩余次数+isDeduction 开关),`deduction` 扣减一次不喜欢,积分不足前端拦截。
- **榜单周期与刷新**:Web 切 nav/period `watch` 重拉;安卓 SmartRefreshLayout 下拉+刷新按钮;Top3 两端都做"居中重排/固定金银铜位";仅周榜显奖励。

## 5. 边界与异常
- **数据延迟**:依赖后端周期统计,存在结算延迟;倒计时只在"本周期"显示,`remainingTime==0` 归零静态展示。
- **周期边界**:安卓倒计时客户端逐秒手算,跨周时刻可能与服务端结算瞬间不同步;切 Tab 先 `stopTimeTiming` 再按 dateType 决定重启。
- **空/异常态**:列表均有 empty view;CP 榜接口返回数组/对象/异常三态兜底为空。
- **私聊直达陷阱(大R)**:必须经 `getUserDetail` 取 `yxAccid`,直传 userId 致云信 p2p 发送失败;防抖避免重复换取。

## 6. Web vs 安卓差异提示
- **大R专页**:Web 独有完整页面(榜+钻石明细+私聊+入口探针);安卓无对应专页,"大R可见"仅作等级权益项。
- **违规记录**:安卓独有(mine 模块,含申诉流 `checkAppeal`);Web 以"好评/不喜欢率+扣分抵扣"承载合规激励,无违规明细页。
- **等级面板集中 vs 分散**:Web 在 `dataStatistics` 单页集中(好评率+三指标升降级+权益+扣分);安卓分散到直播数据页+各榜单+违规记录,**升降级/权益接口安卓未调**。
- **星座榜**:安卓 `ConstellationActivity` 本地静态 12 星座单选(无接口,服务于推荐打招呼),Web 无此页,不应误当榜单。
- **榜单实现**:安卓新旧两套(RankActivity 旧/RankTypeActivity 新),Web 单一 `rank/index.vue` 三态切换;规则文案安卓远程下发,Web 多为静态多语言。

## 7. iOS 实现注意点
1. **直接复用现有后端契约**:直播数据/主播榜/积分榜三接口两端地址一致,iOS 沿用;请求体口径(dateType 整数/rankType 字符串/searchValue/week)务必对齐。
2. **周期映射表落地为常量**:weekly/monthly×this/last/twoMonthsAgo→dateType 0-4、nav×period→枚举,固化避免散落。
3. **倒计时**:以服务端 `remainingTime` 为基准客户端计时,仅本周期显示,到 0 归零并停止;页面隐藏/销毁释放计时器。
4. **Top3 居中布局**:复用 [第2,第1,第3] 重排,周榜才显奖励标签。
5. **CP 榜双人模型**:Top1/2/3 双头像卡+双方奖励弹窗+Mystery(无 userId)兜底+我的 CP 吸底。
6. **大R私聊**:务必先换 `yxAccid` 再发起 IM,入口可见性探针+防抖。
7. **等级面板**:若对齐 Web 需补 `anchorAutoLevelUpInfo`/`getLevelConfig`/`checkCondition`/`deduction` 四接口及"积分抵扣不喜欢";若对齐安卓则仅做榜单+违规记录。
8. **埋点对齐**:进出榜单上报 view/leave(type=diamond/point、path、停留时长、主播等级)。
9. **规则文案**:积分榜规则走 `getConfigByKey('integral_ranking_rule')` 远程下发(与安卓一致),避免硬编码。
