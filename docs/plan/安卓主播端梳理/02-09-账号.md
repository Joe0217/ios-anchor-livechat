# 账号 业务域(登录注册/资料/设置/认证/审核态)— 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T2-9

## 1. 业务目标与定位
账号域是主播端"入口与身份治理层",把匿名设备转化为已认证可开播的主播身份,并维护其生命周期状态与降级体验:
1. **登录鉴权**:多渠道(邮箱密码为主,一键/Google/iOS/Facebook 为辅)产出 token 并建立 IM 连接。
2. **注册入驻**:补全资料(头像/相册/招呼语/对话视频/审核视频/国家/语言)并提交审核。
3. **资料与设置**:编辑个人主页、黑名单/语言/反馈/政策、私密付费内容、退出。
4. **认证与审核态治理**:人脸实名核验;按"审核中/驳回/封禁/通过"四态对 UI 与功能**降级**——本域最关键设计点,Web 与安卓实现路径完全不同。

身份判定两个核心字段:`userType`(2=审核通过主播,9=代理,其余=待审核);`valid`(1 正常/0 封禁),配合 `onReview`/`refusalReason` 区分审核中与驳回。

## 2. 核心业务流程

### Web 端
**登录**(`views/login/index.vue`,邮箱密码唯一线上入口):邮箱校验+密码≥8 位 → 密码 `MD5(密码+AppId)` 两次**转大写**(对齐安卓)→ `hostlLogin`(`/api/login/v4/login`);`code==='1005'` 未注册跳 `/register`;成功按 `userType` 分流 → `forcePageReload()` 触发 `App.vue` 重新初始化。忘记密码仅 WhatsApp 客服弹窗。
**注册入驻**(`views/register/`,两步):Step0 填表(国家 `getCountryList`/头像相册/招呼语/语言)→ Step1 上传审核视频 → 按 `userId` 是否存在区分首次 `hostRegisterV2`(`/api/login/register`) vs 重提交 `hostReSubmitView`;成功 reload 进降级页等审核。
**资料编辑**:`mine/index.vue`(主播主页)、`profile/index.vue`(头像/封面/图片视频/招呼语/对话视频,`checkUserInfo`+`updateUserInfo`)、`userProfile`(查看他人)、`secretSettings`(私密付费内容)。
**设置**(`views/settings/`,配置驱动):语言/黑名单(`getBlockList`)/主播政策/反馈;退出 `appStore.logOut()`。
**审核态/受限态降级(Web 特色:降级页非独立壳)**:分流在 `App.vue` `isLogin()`:`isHost===true` → `/`,否则 → `/newsRestricted`;受限主页 `mineRestricted/index.vue` 按 `valid`/`type`/`onReview` 渲染四态文案配色(封禁 #CC6600 引导提现/审核中 #CC6600/驳回 #8B0000 显 Resubmit 跳注册/通过 #24A600 提示重启)。

### 安卓端
**登录**(`LoginActivity.java`+`EmailLoginActivity.java`,基类 `LoginUI`):现仅邮箱登录(Facebook/Google SDK 全注释);首启弹用户协议 `AgreeDialog`;校验后 `MD5(密码,APP_ID)` 两次 → `loginEmailV4`;返回 null 未注册跳 `CompletionOneActivity`。
**登录后分流(核心:独立审核态壳)** `LoginUI.next()`:`!isAnchor || valid==FORBID` → `navigation(TO_AUDIT_STATUS_MAIN_ACTIVITY)` 进 `AuditStatusMainActivity`;审核通过 → `MainActivity`。
**注册入驻**:`CompletionOneActivity`→`CompletionTwoActivity`→`CompletionPhotoPreview`/`VideoPreview` → 提交后 `RegisterStatuWaitActivity`/`ReviewFailedAvtivity`。
**审核态壳** `AuditStatusMainActivity.kt`:精简双 Tab(消息 `AuditStatusMsgFragment`+我的 `AuditStatusMeFragment`),onCreate finish 掉 Welcome/Login/Completion;独立审核态 WebSocket(`VptWebSocketManager`,AES);监听 `EVENT_ANCHOR_AUDIT_RESULT_NOTICE` 实时刷新;`requestAnchorInfo` 失败码 `1006`(封禁)用缓存渲染;`AuditStatusMeFragment` 四态渲染**与 Web mineRestricted 文案/配色完全一致**。
**资料/设置/认证**:mine 模块 `EditProfileActivity`/`ProfileUpdate`/`EditAvatar`/`EditAlbum`/`EditVideo`/`EditGreet`;`SettingsActivity`/`SelectLanguage`/`Blacklist`/`Feedback`/`AnchorPolicy`;`ReportActivity`。
**人脸实名** `FaceRecognitionActivity.kt`:Agora 本地预览 → 三步动作(左右转头→上下点头→正脸,每步 5s 阈值,`trackingId` 防换人,达标自动截图)→ MLKit 检测 → Luban 压缩 → OSS 上传 → `getFaceRecognitionResult`;失败码 `FACE_RECOGNITION_UPPER_LIMIT` 次数上限。

## 3. 关键接口/SDK
**Web `api/user`**:`hostlLogin`(`/v4/login`)/`quickLogin`/`googleLogin`/`iosLogin`/`facebookLogin`/`testLogin`;注册资料 `hostRegisterV2`/`hostReSubmitView`/`getAnchorInfo`/`getCountryList`/`getBlockList`;`api/profile` `checkUserInfo`/`updateUserInfo`。
**安卓 `login/http/ApiService`**(Base64 URL):`loginVisit`/`loginQuick`/`loginWithGoogle/FacebookInfo`/`loginEmail`/`loginEmailV4`/`requestCode`/`verifyCode`/`resetPassWord`/`saveUserInfo`;审核态 `common HttpHelper.requestAnchorInfo`;人脸 `mine HttpHelper.getFaceRecognitionResult`。
**SDK**:登录渠道安卓现仅邮箱(FB/Google 注释),Web 保留 google/ios/facebook 待 webview 宿主回填;实名 Agora RtcEngine(取景)+ MLKit Face(动作检测)+ OSS(上传)。

## 4. 状态与数据流
**Web token** `utils/tokenManager.ts`:webview 由宿主在 URL 注入 `openParams`(AES Hex 加密 `{token,timestamp,loginUuid}`)+ `appId`;token 变化则 `localStorage.clear()`。
**Web 资料态** `stores/modules/user.js`:`loginSuccess`→setWebParams→`setMineInfo`(按 userType 算 isHost/isAgency)→`setIMAccount` 连云信→`loginAfter()`。
**安卓登录态**:`LoginHelper.saveLoginEntity` 持久化,`TokenInterceptor`(401 同步刷新)注入,`LibApp.logining` 防重复。
**审核态判定**(两端语义一致):`isAnchor`/`userType==2` + `valid` + `isOnReview` + `refusalReason` 四维组合,Web 在 `App.vue` 路由分流、安卓在 `LoginUI.next()` Activity 分流。

## 5. 边界与异常
- **登录失败**:Web toast+关 loading;安卓 `onFail` toast+复位 `LibApp.logining`。
- **未注册**:Web `code==='1005'`跳注册;安卓 `loginEntity==null` 跳 Completion。
- **代理账号**(userType==9):安卓非代理包拦截;Web `isAgency` 不进降级页。
- **封禁**(valid==0/码 1006/1002):安卓缓存渲染+露提现;Web mineRestricted 封禁文案+提现引导。
- **审核中/驳回**:按 onReview/refusalReason 切文案颜色,驳回露"重新提交"回注册流。
- **人脸**:5s 超时重试、trackingId 突变判失败、次数上限拦截。
- **获取资料失败**:Web `getMineInfoData` 弹 Retry 重试。

## 6. Web vs 安卓差异提示
| 维度 | Web | 安卓 |
|---|---|---|
| 登录方式 | 仅邮箱密码线上;google/ios/facebook 接口预留 | 仅邮箱密码;FB/Google SDK 已注释 |
| token 来源 | webview 宿主注入 openParams(AES) | 原生接口 + LoginHelper 持久化 |
| **审核态实现** | **降级"页面"** mineRestricted/newsRestricted,`App.vue` 路由分流 | **独立 Activity 壳** AuditStatusMainActivity(双 Tab+专用 WS),`LoginUI.next` 分流 |
| 密码加密 | `MD5(pwd+AppId)` 两次转大写 | `MD5(pwd,APP_ID)` 两次(默认大写,刻意对齐) |
| 私密付费内容 | `secretSettings` 页 | `SecretMessagesActivity` |

## 7. iOS 实现注意点
1. **Sign in with Apple**:后端 `iosLogin`(`/api/login/ios`)已就绪,接 AuthenticationServices 提交 identityToken;**保留邮箱密码登录**(复刻 `MD5(pwd+AppId)` 两次+大写,否则跨端账号互通失败)。
2. **一键登录**:`quickLogin` 预留;iOS 无运营商一键则以 Apple 登录为"一键"主路径。
3. **审核态/降级**:**强烈建议沿用安卓"独立审核态壳"范式**——精简审核态根控制器(消息+我的双 Tab),按四维渲染同款四态(配色对齐:#CC6600 审核中/封禁、#8B0000 驳回带重提交、#24A600 通过),通过后引导重启/切主 TabBar;封禁露提现入口。
4. **人脸实名**:复刻三步动作+5s 阈值+防换人+次数上限;iOS 用 Vision/ARKit 替代 MLKit,AVCapture 取景,产物走 OSS 后调 `getFaceRecognitionResult`。
5. **审核结果实时性**:对齐安卓监听审核结果通知刷新(iOS 用 WebSocket/推送)。
6. **App Store 合规**:私密付费内容、提现涉敏感与 IAP 政策;预留审核包灰度开关(对齐安卓 `CommonApp.isReview`)。
