# 其他 / 长尾 业务域(启动 / 首页框架 / H5容器 / 平台特性)— 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T3-12

## 1. 业务目标与定位
本域是主播端 App 的"骨架层":把主播从冷启动送进可工作的首页,并承载运营活动与平台保活能力。
- **启动初始化**:SDK 序列初始化、登录态校验、角色判定(主播/代理/未过审),决定首屏落点。
- **首页框架**:底部主 Tab(安卓)/路由壳(Web)+ 顶部业务 Tab(直播/用户列表/匹配/圈子),按主播等级(S/A)与渠道(普通/代理)差异化排布。
- **H5/活动容器**:通用 iframe/WebView 容器,承载抽奖/PK/邀请/攻略活动页,通过 postMessage 握手鉴权。
- **平台特性**:安卓前台保活、版本强更、深链路由分发——iOS 需重点重新设计。

## 2. 核心业务流程

### 2.1 Web 端
**启动初始化**(`App.vue` onMounted→checkLogin):全屏 loading → `tokenManager.getOpenParams()` 解析宿主注入开放参数:有参 → `isLogin()` 拉 `getMineInfoData()`,`isHost` 走 `loginedFun()` + `router.replace('/')`,未过审跳 `/newsRestricted`;无参 → 白名单(login/register/landingPage)外 `logOut`+跳登录。`loginedFun()` 用 `loadStep`(0→1→2)渐进挂载全局浮层(美颜相机/音频/通话弹窗),延迟 5s 关 loading,拉配置(`max_no_use_app_reminder_time` 无操作离线阈值)。**活动检测计时器** `useDynamicInactivityTimer` 无操作弹"活动验证"+置 IM 离线。**前后台** `visibilitychange` 后台断 NIM、前台重连。
**首页框架**(`views/index.vue`+`home/content.vue`+`homeConfig.ts`):顶部 Tab 按等级 `isSLevelAnchor?topTabList:aLevelTopTabList`(S 级首项 live,A 级首项 list);四 Tab live/list(含 online/prime)/match/circle,重组件异步加载;`content.vue` 用 `v-swiper` 滑动联动(`isInternalChange` 防回环);右上角按钮随 tab 变(circle→积分榜,其余→rank);`floatButtons.vue` 浮动按钮(在线开关/开播/匹配/新手任务),底部挂 `<GBoosting/>` 折扣池。
**H5/活动容器**(`views/iframePage/index.vue`,重点):URL 来源 `appStore.iframeUrl`;**仅 lottery 抽奖**做通信化改造(剥离 roomId/roomType/reportParams 转 `pendingRuntime` 避免结构化克隆失败)。**postMessage 握手**(双向):活动页发 `getAppParams`(≤10×300ms 重试)→ 容器回 `buildAppParamsPayload`(token/appId/clientType='anchor'/platform='web'/roomId/reportParams);3500ms 兜底主动推;安全:仅处理 `event.source===iframe.contentWindow`,token 严格按 origin 下发**拒绝 `*`**;入向 type:`SET_NAV`/`CLOSE`(history≤1 兜底回首页)/`JUMP_WALLET`/`JUMP_RANKING`/`REPORT_SHUSHU`,未知 type `c_log` 留痕。`h5link/index.vue` 是更轻量旧式外链容器(URL 拼参 + localStorage SET/GET 桥接)。
**落地页** `landingPage`:随机 base64 loading 图占位屏。

### 2.2 安卓端
**启动初始化**(`SimpleApplication`→`App.kt`→`Initialization.init()`→`WelcomeActivity`):`init()` 固定顺序 `initMlKit`→`getConfigMapByKey`(批量拉配置落 SP)→`initBugly`→`initTDAnalytics`→`initARouter`→`initBridge`→`initSmartRefreshLayout`→`initCountryData`→`initNimSdk`(**禁止自动登录**保证踢人)→`register`(生命周期监听在线态)→`setAgora`(先取 RTM Token 再 initYunXinRtc)。`WelcomeActivity`(LAUNCHER):防重入 → `delayToNextPage`(有登录态 1s/无 2s)→ `toNextPage`:有 `loginEntity` → `requestAnchorInfo`(userType==9 非代理拒绝;非主播/封禁 → `AuditStatusMainActivity`;正常 → `MainActivity`),无 → `LoginActivity`。
**首页框架**(`MainActivity`+`HomeHomeFragment`,重点):`MainActivity`(singleTask)= 底部 Tab 主壳(BottomNavigationView+不可滑 ViewPager2)。**普通渠道**:首页/消息/派对/工作台/我的,**默认落工作台**;**代理渠道**:首页换 `ProxyChargeFragment`、**移除派对 Tab**,多项调度短路。`HomeHomeFragment` 首页内顶部 Tab 按等级排布(`levelNum>5`即 S/SS 为 highLevel:直播→列表→匹配→圈子;否则 列表→匹配→直播→圈子),与 Web S/A 差异语义一致。`MainActivity` 集中调度:WebSocket、未读红点、每秒主循环(无操作降级离线 `LongTimeNoUseAppActivity`、未接来电引导 `MatchLeadDialog`、新手任务倒计时)、Token 续期(提前 7 天)。
**H5 容器**:banner 进 `H5Activity`,充值 H5 经 `hily://pay` 回跳。
**版本更新**(`MainActivity.appVersionCheck`→`UpdateAppDialog`):延迟 2s `requestVersionInfo`(osType=AOS),`updateType==1` 强更(隐藏取消/不可取消),点升级 `ACTION_VIEW` 拉系统浏览器下载 APK。
**前台保活**(`StayService`,`foregroundServiceType=microphone|camera|mediaPlayback`):IdleHandler 中 `startForegroundService`,无声通知渠道 + `startForeground` 常驻通知("App is running");来电用 `CATEGORY_CALL`+`setFullScreenIntent` 全屏通知。

## 4. 状态与数据流
- **首页 Tab 配置来源**:Web 静态常量 `homeConfig.ts`(等级来自 `isSLevelAnchor`);安卓 `HomeHomeFragment` 等级 map 硬编码两套顺序(等级来自 `loginEntity.userLevel`)。
- **登录态守卫**:Web **无全局 beforeEach 守卫**(已注释),判定集中在 `App.vue` checkLogin(白名单+token);安卓 `WelcomeActivity.toNextPage` 单点判定 + `MainActivity.onResume` token 续期。
- **保活生命周期**:安卓 `StayService` 前台通知常驻,在线态经 `NIMEventPublishHelper`(publishForeground/Background/Calling)+`updateOnlineStatus` 推后端,隐身超 20 分钟自动恢复。Web 无 Service,靠 `visibilitychange`+活动检测计时器近似"在线降级"。

## 5. 边界与异常
- **深链兜底**:安卓 `WelcomeActivity` 仅声明 scheme,**当前未显式解析 `intent.data` 落点分发**(依赖推送/H5 层);Web `iframePage` 的 CLOSE 在 history≤1 时兜底回首页。
- **H5 通信异常**:握手 3500ms 超时兜底+重试;payload 缺失/未知 type/非法 origin 全 `c_log` 留痕;token 严禁 `*` origin 下发。
- **保活被杀**:安卓前台 Service+高优先级通知+`setOngoing` 降低被杀概率,被杀后下次从 Welcome 恢复。
- **版本强更**:`updateType==1` 隐藏取消,但仍是"引导浏览器下载"而非强制阻断。
- **无操作降级**:两端都"长时间无操作→置离线→弹回工作台/对话框",防挂机刷在线时长。

## 6. Web vs 安卓差异提示
| 维度 | Web | 安卓 |
|---|---|---|
| 首页框架 | 单页路由+v-swiper,顶部 4 Tab(S/A 顺序差异),底部由原生壳/路由 | 底部 5 Tab 主壳(代理换首页 Tab、删派对)+ 首页内顶部 4 Tab |
| 保活 | 无原生 Service,靠 visibilitychange+NIM 重连+活动计时器 | 原生前台 `StayService`(mic\|camera\|mediaPlayback)+常驻通知 |
| 版本更新 | 原生壳处理 | `requestVersionInfo`+`UpdateAppDialog`,系统浏览器下载 APK |
| 路由守卫 | **无 beforeEach**,App.vue checkLogin 兜底 | WelcomeActivity 单点+MainActivity token 续期 |
| 深链 | webview URL+postMessage | `anchorapp://`/`hily://pay`/Adjust |

## 7. iOS 实现注意点(关键约束)
1. **启动初始化**:复刻 `Initialization.init()` 有序 SDK 序列;NIM 在安卓是 `:core` 独立进程,iOS 无多进程,统一为单进程逻辑;**禁止自动登录**(保证踢人语义)。
2. **首页框架**:底部 Tab(首页/消息/派对/工作台/我的)+ 首页内顶部 Tab,实现两套等级排布(S/SS 优先直播,A 及以下优先列表)+ 代理渠道差异(换首页 Tab、隐藏派对);**默认落点是工作台**而非首页。
3. **深链/Universal Links**:`anchorapp://` 在 iOS 需 URL Scheme + Universal Links(apple-app-site-association)双通道;Adjust 归因接 iOS SDK;充值回跳 `hily://pay`。**安卓未在 Welcome 显式解析落点,iOS 需自建统一 deeplink router。**
4. **后台保活策略**:iOS **无等价前台 Service**。改用 **VoIP Push(PushKit)+ CallKit** 接听来电(替代 StayService 全屏来电通知);后台音视频依赖 `UIBackgroundModes`(audio/voip)。"主播在线接单"在 iOS 必须以 PushKit 唤醒为核心,不能依赖常驻前台服务。
5. **App Store 审核约束(重点)**:
   - 后台音频/麦克风/相机 `UIBackgroundModes` 与 VoIP 必须有真实通话场景支撑,否则拒审;不可像安卓长期挂常驻通知刷在线。
   - 版本更新**不得引导外部浏览器下载安装包**(安卓 `ACTION_VIEW` 下载 APK 在 iOS 违规),强更只能跳 App Store。
   - 活动 H5 容器(WKWebView)postMessage 鉴权保留 origin 校验;涉虚拟商品/充值的活动页须走 IAP 或符合外链政策。
   - 抽奖/折扣池等运营活动需符合 App Store 抽奖与促销规范。
