# 直播核心业务域 — 模块级业务逻辑梳理(Web / 安卓双端)

> **需求** DM-20260616-004 · **阶段二交付物**(对应需求步骤2)· 业务域 T0-1
> 平台:微斗/HoChat 主播端。RTC 统一用 Agora;聊天室/IM 统一用网易云信 NIM。本梳理覆盖开播前配置 → 开播建房推流 → 直播间运行态 → 下播结算的完整生命周期,并标注双端差异与 iOS 补齐要点。

---

## 1. 业务目标与定位

主播端直播核心,让主播完成"配置 → 开播 → 互动运营 → 下播复盘"闭环。核心能力:实时视频推流(主播单向推流,观众拉流)、公屏聊天、收礼与榜单、心愿单、转盘/活动、私 call(直播转 1v1)、主播 PK,以及合规/弱网下的强制下播保护。

- **Web(h5-anchor)**:Vue3 webview 内嵌,定位"全功能主播端",直播与通话深度耦合在 `useCallApi.js` 一个 composable 内(直播复用通话的 Agora CallApi 实例)。
- **安卓(android-anchor)**:原生 Kotlin,`call` 模块承载直播间核心。直播与通话同样耦合(共用 `CallServiceManager.callApi`),但页面以独立 Activity/Fragment 拆分,职责更分明。

## 2. 核心业务流程(分步)

### 2.1 开播前配置

**Web**:`src/views/liveSetting/index.vue`
1. `onMounted` → `getMyLiveRoom()`(接口 `getMyLiveRoomV2`)拉取上次房间信息(简介、封面、私call礼物、价格区间),失败则回首页;同时 `initMyLiveClient()` 预初始化 Agora 直播客户端。
2. 配置项:直播简介(必填)、封面图(必填,上传 OSS)、私call免费5分钟礼物(单选,价格受 `minGiftPrice/maxGiftPrice` 约束)、心愿单礼物(多选带数量,缓存在 localStorage)、美颜入口。
3. 点击开播 → `checkCanLive()` 校验:简介/封面非空、距上次下播≥60秒、IM 在线(`checkIMOnline`)。组装参数含 `privateCallOpen`(选了礼物即为1)。

**安卓**:`LiveSettingActivity.kt`
1. `loadData` → `getMyLiveRoom()` + `wishGiftMaxNum()`(心愿单上限,默认3)。封面、礼物、心愿单配置同 Web。
2. 点击开播 `tvConfirm` → 校验 NIM `LOGINED`、简介/封面非空 → `picCheck`(封面鉴黄接口)→ `setSSettingBean` → `beginLiveRoom`。
3. 保留了 `checkNetworkQuality()`(Agora `startLastmileProbeTest` 上行/下行探测,质量5/6弹"网络太差"弹窗阻断开播),但**当前已注释跳过**,改为直接开播,有5秒探测回调兜底定时器。

### 2.2 开播(建房 / 推流 / 心跳)

**Web**:
1. `handleStartLive()` → `openLocalCameraAndeMic('live')` 开启美颜相机(创建本地音视频轨道)。若美颜未初始化完成,`watch` 监听 `beautyStore.inited` 后再继续。
2. `beginLiveRoom(params)`(接口)成功后:立即启动**心跳定时器 `setInterval(keepLiving, 6000)`(每 6 秒)**,重置 `heartBeatErrorCount`;合并返回的 `id / agoraChannelId / yxRoomId / hotScore` 到 `settingData`,缓存心愿单到 localStorage。
3. `beginLive()` → `beginLiveOpen(settingData)`(`useCallApi.js`):`appStore.setLiveState('living')`;`callApi.prepareForCall({roomId: agoraChannelId})` → `callApi._startLive()`(加入 Agora 频道并发布本地音视频);写入 `liveStore.currentLiveInfo`;`joinChatRoom(yxRoomId)` 进入 NIM 聊天室;启动 `networkMonitorStore.startMonitoring()` 并监听 `networkQualityChanged`。
4. `showLiveRoom=true` 挂载 `liveRoom.vue`。

**安卓**:
1. `beginLiveRoom` 成功 → `LiveCallActivity.start(liveSettingBean)`。
2. `createLiveRoom()`:`RtcEngineEx.create` 创建引擎并注册 `IRtcEngineEventHandler`(网络质量/连接丢失/连接状态/本地视频状态回调)→ `initBeautyApi()`(FaceUnity)→ `initRtc()`:`setClientRole(BROADCASTER)`、`ChannelMediaOptions(publishCamera/Mic=true, autoSubscribe=false)`、`joinChannelEx`,并把自己注册为 `callApi` 监听器(处理私call打入)。
3. `beginTimestamp = now`;`startTiming()` 用 `Flowable.interval(0,1,秒)` 计时,**每 10 秒 `aLong % 10 == 0` 触发 `liveHeartBeat()`**。
4. 聊天室进入在 `LiveRoomMsgFragment.createImRoom()`:`enterChatRoomEx(EnterChatRoomData, 3)`(带 nick/avatar 扩展)成功后 `fetchRoomInfo` + `registerRoomChatObservers(true)` + 进房公告补发。

### 2.3 直播间运行态

**公屏消息**
- Web:`live.js#chatroomLiveChatRecordMsg` 是聊天室消息总入口,按 `type`(text/custom/notification)分发;公屏数据存 `liveChatRecords`(头插,**裁尾保留最近50条**),由 `messageScroller.vue` 渲染。进场/高等级用户进房动画走 `executeTasks` 队列。
- 安卓:`LiveRoomMsgFragment#incomingChatRoomMsg`(`observeReceiveMessage`)按 `attachType` switch 分发,公屏走 `LiveRoomMsgAdapter`。

**收礼**(双端均由 NIM custom 消息 `attachType=50`/`LIVE_ROOM_RECEIVE_GIFT` 驱动)
- Web:`handleLiveGiftMessage` → 飘窗(`setGfitModalTimeout` 5秒)→ SVGA/MP4 动画入队(`giftStore.addGiftToQueue`,PK 期间按价格排序)→ 公屏插入 → 刷新礼物任务/当前收入/心愿单进度;幸运礼物中奖额外推全服公告。
- 安卓:`LiveEventBus.post(LIVE_ROOM_RECEIVEGIFT, ReceiveGift)` → `LiveCallActivity.receiveGift()` 播动画 + `setHotScore`。

**榜单 / 热度**:`attachType=56`(榜单变更)、`50` 带 hotScore、`71`(热度衰减)更新 `topRankList` 与 `currentLiveInfo.hotScore`;贡献榜 `contributionRank.vue`/`LiveContributionDialog`;收礼周榜 `receiveRankV3`、观众榜 `viewers`。

**心愿单**:开播配置后由 `getAnchorWishlist` 拉取,收礼时按 `giftId` 匹配更新 `compelteGiftNum/ratio/completed`(`wishlist.vue`)。

**转盘/活动**:Web `liveRoulettePopup.vue` + `api/roulette`;安卓 `WheelShowDialog`(首次点击需先看 `InteractionGameRulesDialog` 三页规则)。活动入口 Web `liveActivitySwiper`(当前注释)、安卓 `LiveActivityIconComponent`。

**私call(直播转1v1)**:`liveRoom.vue` 私call开关 `updatePrivateCall`;来电时 Web 经 `callInEnter` 暂停直播(`livingEnd(false)` 不清直播信息)接听,通话结束进 `waitingReturnLive` 状态、15秒倒计时 `returnLivePopup` 自动 `returnLive`(重新 `beginLiveOpen`)。安卓由 `callApi` 监听 `Calling` → `queryCall`(`callerType==4` 才自动接)→ 通话结束 `ContinueLiveDialog` 让主播确认继续直播再 `publishMedia(true)` 重推流。

### 2.4 下播(结算 / 数据)

**Web**:`handleLiveEnd()` → 清心跳定时器 → `livingEnd()`(离开频道/销毁/关相机)→ `endLiveRoom(params)`(携带强制结束类型)→ `router.replace('/liveEnds')` 带 `forceEndReason`。`liveEnds/index.vue` 调 `queryLiveStat` 拉本场数据(时长、收益、Top 送礼者)。
**安卓**:`showLiveStatisticsDia(reason, banTime, endType)` → ARouter 跳 `LiveEndActivity`(传 begin/endTimestamp + endType)→ `recycleAll`(停推流/离频道/释放美颜)。`LiveEndActivity` 用 `queryLiveStat` 拉数据,展示 Top 送礼者(`LiveEndGiftersActivity`)与私call列表,支持一键关注。后台时走 `endLiveRoomV2` 兜底上报。

## 3. 关键接口 / SDK

### 接口分组(`src/api/live/index.ts`,安卓 `HttpHelper` 同名)
| 接口 | 用途 |
|---|---|
| `getMyLiveRoomV2` | 拉取我的房间(上次开播配置) |
| `beginLiveRoom` | 开播建房,返回 id/agoraChannelId/yxRoomId/hotScore |
| `endLiveRoom` / `endLiveRoomV2` | 下播(V2 为后台兜底) |
| `liveHeartBeatV2`(Web)/`liveHeartBeat`(安卓) | 直播间心跳,带 `roomId`+`callState` |
| `updatePrivateCall` | 私call开关 |
| `getAnchorWishlist` | 心愿单进度 |
| `getChatRoomAddress` | 聊天室服务器地址(Web 进房用) |
| `userJoinRoom`/`getRoomAndJoinRoom` | 加入房间/取当前收入 |
| `queryLiveStat` | 下播后本场数据 |
| `contributionRank`/`receiveRankV3`/`viewers` | 贡献榜/收礼周榜/观众榜 |
| `getThisLiveSendGiftRecord`/`getGiftListByWeight` | 礼物记录/关注礼物列表 |
| `editLiveAnnouncement`/`getLiveAnnouncement` | 公告读写(敏感词1070) |
| `openEffect`(`apiGetLiveAnimation`) | 进场座驾动画 |

### SDK 关键调用
- **Agora 推流(主播)**:Web `callApi._startLive()`(`mode:'live', role:'host'`);安卓 `joinChannelEx` + `CLIENT_ROLE_BROADCASTER` + `ChannelMediaOptions(publishCamera/Mic)`。编码:安卓 `Const.AGORA_WIDTH/HEIGHT` @15fps;Web `720p_3`(Safari `720p_auto`)。
- **Agora 网络质量**:Web `networkQualityChanged`;安卓 `onNetworkQuality(tx/rxQuality)`。
- **NIM 聊天室进**:Web `joinChatRoom` → `getChatRoomAddress` → `ChatRoomBrowser.connect()` + 监听 `logined`/`chatroomMsg`;安卓 `enterChatRoomEx` + `observeReceiveMessage`。
- **NIM 聊天室出**:Web `liveChatRooms.destroy()`;安卓离开聊天室随 Activity 回收。
- **美颜**:Web NamaSDK + MediaPipe;安卓 FaceUnity `FaceUnityBeautyAPI`(`CaptureMode.Agora`)。

## 4. 状态与数据流

**直播状态机**(Web `appStore.liveState`):`''` → `living`(直播中)→ `liveCalling`(私call通话中)→ `waitingReturnLive`(待回直播)→ `living` / `''`。安卓用 `LibApp.isLiveing`/`isCalling` 布尔标志 + `ContinueLiveDialog` 表达同等流转。

**心跳 callState**(双端一致):`0`直播中 / `1`通话中 / `2`匹配中 / `3`PK中。Web `getCallState()` 计算,安卓由 `LibApp.isCalling` + `mPkStatus` 计算。

**心跳频率**:Web **6 秒/次**;安卓 **10 秒/次**。这是双端的明确差异。

**礼物/消息驱动 UI**:NIM custom 消息 → 解析 `attachType` → 更新 Pinia store(`liveChatRecords`/`topRankList`/`hotScore`/`giftTask`)/LiveEventBus → 响应式刷新公屏、飘窗、榜单、动画队列、心愿单进度。观众数:Web 由进退场通知增减 + 30秒 `queryMembers` 定时校准。

## 5. 边界与异常

**被强制下播**(Web `liveStore.isCompelLiveEnd` 触发 `watch`,带错误码):
- `3` 后台手动关闭 / `4` 心跳断链 / `5` 网络质量过差 / `61` 鉴黄警告(仅弹窗不下播) / `62` 鉴黄封禁 / `99` 摄像头错误 / `1992`主播封禁 / `1006`账号封禁。
- 安卓对应 `STOP_LIVE` / `LIVE_BE_BANNED` / `LIVE_RULE_WARNING` LiveEventBus 事件 + 心跳 `onFail` 错误码(`1992`封禁/`2001`无权限),`endType` 1-7 区分(1正常/2封禁/3后台/4心跳/5采集失败/6无权限/7网络差)。

**断网重连 / 心跳超时**:Web 心跳连续失败 `>6` 次 → `isCompelLiveEnd='4'` 下播;安卓心跳失败 `>3` 次 → endType=4 下播。安卓额外 `onConnectionLost` 弹窗、`onConnectionStateChanged` 服务器禁止(被踢)→ endType=3。Web 通话侧 RTM 由 `useRtmReconnect` 接管退避重连。

**弱网强制下播**:`networkMonitor.js` 连续极差(质量5/6)计数,`maxCriticalCount=30` 次触发 `forceCloseLive`;`>=10` 次上报日志 + UI 提示。安卓 `networkQualityPoor>=10` 直接下播(endType=7)。**PK/惩罚期间双端均暂停网络监控**,避免弱网导致输PK。

**视频采集失败**:安卓 `onLocalVideoStateChanged` 失败计时,持续 `>20秒` 强制下播(endType=5);Web 摄像头错误置 `isCompelLiveEnd='99'`。

**并发收礼**:礼物动画走队列(Web `giftStore` 队列 + PK 期按价格排序;飘窗 5 秒节流刷新),避免动画叠加丢失。

## 6. Web vs 安卓 差异提示

| 维度 | Web(h5-anchor) | 安卓(android-anchor) |
|---|---|---|
| 心跳频率 | **6 秒** | **10 秒** |
| 心跳接口 | `liveHeartBeatV2` | `liveHeartBeat` |
| 心跳失败阈值 | `>6` 次下播 | `>3` 次下播 |
| 页面边界 | 单页 `liveSetting/index.vue` 内 `v-if` 切换设置↔直播间,**不换路由** | 设置/直播间/结束为**独立 Activity**,ARouter 跳转 |
| 开播前网络探测 | 无 | 有 `startLastmileProbeTest`(当前注释) |
| 封面鉴黄 | 无独立前置 | `picCheck` 前置校验 |
| 私call回直播 | 自动接听 + 15秒倒计时自动回 | `queryCall` 判断 + `ContinueLiveDialog` 手动确认重推流 |
| 美颜 SDK | NamaSDK/MediaPipe | FaceUnity |
| 弱网下播阈值 | 连续30次(可配) | 连续10次 |

## 7. iOS 原生实现注意点

1. **状态机与心跳**:实现 `living/liveCalling/waitingReturnLive` 流转;心跳建议对齐安卓 10 秒(或与后端确认统一值),必带 `roomId`+`callState`(0/1/2/3),失败计数兜底下播。
2. **Agora 推流**:`CLIENT_ROLE_BROADCASTER`,发布摄像头+麦克风、`autoSubscribe=false`(主播不订阅观众),房间 id 用后端返回 `agoraChannelId`;美颜接 FaceUnity(对齐安卓)。
3. **NIM 聊天室**:`enterChatRoomEx` 带 nick/avatar 扩展;消息按 `attachType` 全量分发(收礼50、榜单56、热度71、PK 97-100、公告195/`LIVE_ROOM_ANNOUNCEMENT`、座驾80、活动140、钻石盲盒1030-1033、猜拳144),字段需与双端协议严格对齐。
4. **强制下播全场景**:鉴黄(61警告/62封禁)、后台关闭(3)、心跳断链(4)、弱网(5/7)、采集失败、封禁(1992/1006)、被踢,并把 `endType`/`forceEndReason` 透传到结束页。
5. **弱网保护**:接 `onNetworkQuality`,连续极差计数下播;PK/惩罚期间暂停监控。
6. **私call闭环**:直播暂停(不销毁直播信息)→ 接听 → 结束 → 确认/倒计时回直播重推流;来电校验 `callerType==4` 才自动接。
7. **下播结算**:下播后 `queryLiveStat` 拉时长/收益/Top送礼者;后台兜底 `endLiveRoomV2`。
8. **并发与动画**:礼物 SVGA/MP4 队列化,飘窗节流;观众数定时校准 + 进退场增减双保险。
9. **开播校验**:简介/封面必填、距上次下播间隔、IM 在线、封面鉴黄(对齐安卓 `picCheck`)。
