## §3 状态机（v2 大改，覆盖红队 A1/A2/A3/B1/B4/F3/F4）

美颜设置页 UI 层不复杂，真状态机在 **BeautyPipelineSharer** 内。

### §3.1 Sharer 复合状态机

分**初始化态** + **数据态** + **降级态** + **渲染订阅态** 4 类同步维度：

```
initialization:
   [notStarted] ──setup Task── [inProgress(Task)] ──ok── [ready]
                                                     └──fail── [failed(BeautyError)]

data:
   [unloaded]
      │  Sharer.init readFromDisk
      ├─ ok ────────────→ [ready(cached)]
      └─ decode 失败 ────→ [error(decodeFailed)] → 兜底 default → [ready(default)]

   [ready(*)]
      │ 用户在设置页调滑块
      ↓
   [ready(dirty)]
      │ scenePhase→.background 强制触发 flush（红队 A1）
      │ or onDisappear 触发 flush（`.claude/rules/swiftui-camera-preview.md` §6）
      │ 双路径必经 flushIfDirty() 幂等锁
      ↓
   [ready(persisted)] ──writeToDisk ok─┐
                                       │
                                    [ready(cached)]

degraded:
   相芯 setup 失败 → [degraded(passthrough)]
      Store 参数照写盘、UI 照显示，但渲染路径不走 FUBeauty
      渲染层挂"美颜不可用"横幅（跨 LivePrepare/LiveRoom/CallView/Party 4 处一致）
      recover 时机：下次冷启动 setup 再试；成功回 [ready]

subscriber:
   activeSubscriber 优先级栈 (Live>Call>Party>Preview)
   push(owner)/pop(owner)  仅栈顶 owner 触发 renderer.apply
```

### §3.2 关键不变量

- **禁止 loading dead-state**（`.claude/rules/async-state-fallback.md`）：进设置页立即渲染 UI initValue（首帧一致契约，红队 F2/F5）；Sharer 未就绪时 preview 走 PassthroughRenderer（相机原始画面）不是黑屏
- **flush 双路径幂等**（红队 A1）：`scenePhase→.background` 与 `onDisappear` 会同时触发，Sharer 内部 `flushIfDirty()` 用 NSLock + isFlushInProgress guard
- **磨皮时序前置**（红队 A2）：`applyBeautySettings` 内**每次 apply** 都强制 `beauty.heavyBlur=0; beauty.blurType=<settings.blurType>` 前置，不做 dirty check
- **首帧缓存主导**（红队 F5）：Sharer.setup 完成后**先 readFromDisk**，参数就位再 setup FUBeauty 首次 apply；不给"默认档闪一下"的窗口
- **activeSubscriber 单一 apply**（红队 B1）：Sharer 内维护栈 `activeSubscriber: [OwnerToken]`（Live>Call>Party>Preview），仅栈顶变化时才广播到 renderer；Store 参数改动路径为 `settings 改 → all subscribers observe → 唯栈顶 apply 到 renderer`
- **降级态双写解耦**（红队 A5/B4）：Passthrough 模式下 Store 照写盘、UI 照显示，横幅告知；Setup 恢复后 Sharer.setup 就绪 → Store 已经有值 → 直接 apply（不丢参）
- **中断态阻断 SDK**（红队 F4）：`AVCaptureSessionInterruptionEnded` 前，Sharer.applyToRenderer 必 `guard CameraManager.isRunning`；中断期间只写 Store 不写 SDK
- **恢复默认串行**（红队 A4）：Store 内单点 `Task { @MainActor in ... }` 或 `AsyncStream` 序列化 flush 请求，避免 dirty 中点 reset 的双写竞态
- **多 view 并发首次访问**（红队 A3）：Sharer setup 是 `.notStarted / .inProgress(Task) / .ready / .failed` 状态机，并发访问返回同一 Task 而非重跑；单例 `@MainActor` + `lazy var` 保证

## §4 数据契约

### §4.1 反射映射（1:1 复刻 H5）

```swift
enum ReflexType: Int, Sendable {
    case type1 = 1  // 0~100  ↔ 0~1     (vtr: v/100,        rtv: 100*v)
    case type2 = 2  // -50~50 ↔ 0~1     (vtr: (v+50)/100,   rtv: 100*v-50)
    case type3 = 3  // 0~100  ↔ 0~6     (vtr: v*6/100,      rtv: 100*v/6)

    func toRaw(_ uiValue: Double) -> Double {
        switch self {
        case .type1: return uiValue / 100.0
        case .type2: return (uiValue + 50.0) / 100.0
        case .type3: return uiValue * 6.0 / 100.0
        }
    }
    func toUI(_ rawValue: Double) -> Double {
        switch self {
        case .type1: return 100.0 * rawValue
        case .type2: return 100.0 * rawValue - 50.0
        case .type3: return 100.0 * rawValue / 6.0
        }
    }
}
```

**单测覆盖**：3 类 × (0/mid/max/负/边界) × 双向 = 30 case，含 round-trip 精度 + NaN/Inf 输入拒绝（红队 C 补）。

```swift
    var blurType: Int = 2  // 红队 D3 存字段

    var blur: Double = 55
    var whiten: Double = 40
    var red: Double = 30
    var clarity: Double = 0
    var sharpen: Double = 60
    var faceThreed: Double = 40

    var toothWhiten: Double = 0

    var removeNasolabialFolds: Double = 80
```

**前向兼容**（红队 C2）：
- **所有字段有默认值**：Swift Codable 默认 decode 时对缺失字段抛错；用 `KeyedDecodingContainer.decodeIfPresent` 兜底默认值

**版本迁移**：本期 v1 是首版；Key 里含 `.v1` 便于未来 `.v2` 迁移。

```swift
    /// v2 核心 API：全量应用 BeautySettings 到 FUBeauty，一次调用替代 25+ property writes
    func apply(_ settings: BeautySettings) {
        guard let beauty = FURenderKit.shareRenderKit().beauty else { return }

        // 红队 A2：磨皮时序前置（每次 apply 都强制归零，不做 dirty check）
        beauty.heavyBlur = 0
        beauty.blurType = Int32(settings.blurType)

        // 美肤 10 项
        beauty.blurLevel = ReflexType.type3.toRaw(settings.blur)
        beauty.colorLevel = ReflexType.type1.toRaw(settings.whiten)
        beauty.redLevel = ReflexType.type1.toRaw(settings.red)
        beauty.clarity = ReflexType.type1.toRaw(settings.clarity)
        beauty.sharpen = ReflexType.type1.toRaw(settings.sharpen)
        beauty.faceThreed = ReflexType.type1.toRaw(settings.faceThreed)
        beauty.eyeBright = ReflexType.type1.toRaw(settings.eyeBright)
        beauty.toothWhiten = ReflexType.type1.toRaw(settings.toothWhiten)
        beauty.removePouchStrength = ReflexType.type1.toRaw(settings.removePouch)
        beauty.removeNasolabialFoldsStrength = ReflexType.type1.toRaw(settings.removeNasolabialFolds)

        // 美型 15 项（type1/2 混）
        beauty.cheekV = ReflexType.type1.toRaw(settings.cheekV)
        // ...省略 14 项

        // 滤镜（红队 C1：白名单已在 Store 校验，此处不再判）
        beauty.filterName = settings.filterName as NSString
        beauty.filterLevel = settings.filterLevel / 100.0

        // 全局开关
        FUManager.shared().setBeautyEnabled(settings.enabled)  // 需在 FUManager 加 setBeautyEnabled: 方法
    }
}
```

### §8.4 Actor 归属（红队 C3）

| 类 | Actor 归属 | 说明 |
|---|---|---|
| `BeautyPipelineSharer` | `@MainActor` 单例 | SwiftUI 消费 + FURenderKit 挂载都在 main |
| `BeautySettingsStore` | `@MainActor` | Publisher 面向 SwiftUI |
| `BeautySettings` struct | `Sendable`（Codable 值类型天然）| 跨 actor 传递安全 |
| `ReflexType` enum | `Sendable` | 纯值类型 |
| `FUBeautyRenderer` | `@MainActor` | `apply(_:)` 只在 main |
| `FUManager` (OC) | 无 actor 声明 | Swift 侧 wrapper 保证从 main 调用 |
| `CameraManager.captureOutput` | nonisolated（background queue） | `pushExternalVideoFrame` 前先 `[weak self]` guard，不读 renderer 内部状态；参数 apply 走 Store observer 路径（`.claude/rules/swiftui-camera-preview.md` §9 同款） |
