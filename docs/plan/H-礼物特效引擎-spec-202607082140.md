## §0 引子 · 范围三圈 · H5 / 安卓二次校验

### 0.1 一句话定位

- 队列上限 30 / 场景切换硬 clear —— 用户明示改进，非 H5 蓝本
- PK 排序 —— 留后续 spec（本 spec 用 FIFO + me 插队）
- 派对房 me 插队 —— H5/安卓无此逻辑；用户明示（未来主播送礼开放时预留）

## §1 业务契约 · attachType 与 payload

### 1.1 4 场景 IM 消息 → 引擎输入映射

| 场景 | 消息通道 | attachType | payload 结构（关键字段） | mapping 结果 |
|---|---|---|---|---|
| Live | NIM 聊天室 | `50`（scene=LIVE） | `{giftId, giftName, giftIcon, giftNum, giftSmallImg, senderYxAccid, senderNickname, senderAvatar, giftPrice}` | animationUrl = giftIcon；staticImgUrl = giftSmallImg |
| Call | NIM P2P 系统消息 | `4` | `{giftId, giftImg, giftNum, giftId, giftName, senderInfo:{yxAccid, nickname, avatar}, giftPrice}` | animationUrl = giftImg（若含 .svga/.mp4）；否则 staticImgUrl = giftImg，走 MicroToast |
| Party | NIM 聊天室（Party 独立 attachType，待 E 期确认） | `partyGiftCompressed`（gzip 后需先解压，见 [`Sources/Party/Utils/GzipDecompressor.swift`](Sources/Party/Utils/GzipDecompressor.swift)） | `{gifts:[{...}]}` gzip 数组 | 循环入队，每条独立 item |
| Chat | NIM P2P 自定义消息 | `'SEND_GIFT'`（**字符串**）| `{giftId, giftName, giftIcon, giftNum}` + msg.fromAccid | animationUrl = giftIcon；staticImgUrl = null 时中央播放，否则微飘窗 |

### 1.2 字段兼容规则（对齐 [ios-decode-userid-compat.md](/.claude/rules/ios-decode-userid-compat.md)）

- `giftId`：String / Int64 双兼容 decode
- `giftNum` / `giftCount`：Int（后端可能给 String，走同款兼容）
- `giftPrice`：Int64 双兼容
- `senderYxAccid`：String only（IM 层原生就是 String）
- URL 字段（giftIcon / giftImg / giftSmallImg）：可能 nil / 空字符串，走 `.trimmed.isEmpty` 归一为 nil

### 1.3 判定"走中央大动画 vs 微飘窗"

```
let ext = URL(string: animationUrl ?? "")?.pathExtension.lowercased()
switch ext {
case "svga", "mp4":
    → GiftEffectCenter.shared.enqueue(item)  // 中央大动画
default:
    → GiftEffectCenter.shared.showMicroToast(fromItem: item)  // 3s 底部飘窗
}
```

**特例**：私聊场景（`.chat`）**不启用**微飘窗（无动画资源时**只**显示消息气泡，气泡由 [`SystemGiftBubbleView`](Sources/Message/Chat/UI/Bubbles/SystemGiftBubbleView.swift) 已完成）。

## §3 GiftEffectCenter 状态机与生命周期

**文件**：`Sources/GiftEffect/Center/GiftEffectCenter.swift`

### 3.1 状态机

```swift
@MainActor
public final class GiftEffectCenter: ObservableObject {
    public static let shared = GiftEffectCenter()

    @Published private(set) var current: GiftEffectItem?      // 中央播放中
    @Published private(set) var microToasts: [MicroToastItem] // 底部飘窗队列（最多同显 1 条）

    private var pending: Deque<GiftEffectItem> = []            // 未播队列 max 30
    private var activeKey: GiftEffectSceneKey?
    private let playerRouter: GiftPlayerRouter
    private let mineYxAccidProvider: () -> String              // 注入 SessionStore

    private static let queueLimit = 30

    // MARK: - Public API

    public func setActiveScene(_ key: GiftEffectSceneKey)
    public func leaveScene(_ key: GiftEffectSceneKey)
    public func enqueue(_ item: GiftEffectItem)
    public func showMicroToast(_ toast: MicroToastItem)
    public func handleMemoryWarning()
    public func reset()  // logout
}
```

### 3.2 setActiveScene 语义

```
setActiveScene(newKey):
    if activeKey == newKey: return  // 幂等
    if activeKey != nil:
        // 场景切换硬中断（用户明示）
        stopCurrentImmediately()
        pending.removeAll()
        microToasts.removeAll()
    activeKey = newKey
    logger.info("setActiveScene → \(newKey)")
```

**硬中断实现**：
```
stopCurrentImmediately():
    playerRouter.stopAll()   // SVGA stop + YYEVA stop
    current = nil
```

### 3.3 leaveScene 语义

```
leaveScene(key):
    guard activeKey == key: return  // 别的场景已接管则不动
    stopCurrentImmediately()
    pending.removeAll()
    microToasts.removeAll()
    activeKey = nil
    logger.info("leaveScene ← \(key)")
```

### 3.4 enqueue 语义

```
enqueue(item):
    // 1. 场景 tag 过滤（防 IM backlog 泄漏）
    guard let active = activeKey, active == item.sceneKey else {
        logger.warning("enqueue rejected: item.sceneKey=\(item.sceneKey) active=\(activeKey?)")
        return
    }

    // 2. 派对房 me 插队分支
    if item.sceneKey.scene == .party && item.isSelfSent {
        pending.prepend(item)    // 队首插入（不抢占正在播）
        logger.info("Party me-sent gift inserted at head")
    } else {
        pending.append(item)
    }

    // 3. 上限 30 FIFO 淘汰
    while pending.count > Self.queueLimit {
        let dropped = pending.removeFirst()
        logger.info("Queue overflow, dropped oldest: gift=\(dropped.giftName)")
    }

    // 4. 触发播放
    playNextIfIdle()
```

### 3.5 playNextIfIdle

```
playNextIfIdle():
    guard current == nil, !pending.isEmpty else { return }
    let next = pending.removeFirst()
    current = next
    playerRouter.play(item: next, in: hostView) { [weak self] in
        Task { @MainActor in
            self?.current = nil
            self?.playNextIfIdle()
        }
    }
```

### 3.6 showMicroToast

```
showMicroToast(toast):
    guard let active = activeKey, active == toast.sceneKey else { return }
    guard active.scene != .chat else { return }  // 私聊不启用微飘窗

    microToasts.append(toast)
    Task { @MainActor in
        try? await Task.sleep(nanoseconds: UInt64(toast.duration * 1e9))
        microToasts.removeAll { $0.id == toast.id }
    }
```

**决策**：微飘窗队列同一时刻只显示最新一条（简化 UI）；append 时不清旧，让 timer 自然消退 —— UI 层用 `microToasts.last` 单条渲染。

### 3.7 handleMemoryWarning

```
handleMemoryWarning():
    stopCurrentImmediately()
    pending.removeAll()
    microToasts.removeAll()
    // 保留 activeKey，允许后续新入队
    logger.warning("Memory warning: cleared all in-flight effects")
```

监听 `UIApplication.didReceiveMemoryWarningNotification`。

### 3.8 reset（logout）

```
reset():
    stopCurrentImmediately()
    pending.removeAll()
    microToasts.removeAll()
    activeKey = nil
    playerRouter.tearDownPlayers()   // SVGA/YYEVA instance 销毁
    GiftEffectOverlayWindow.shared.hide()
```

在 [`SessionStore.logout`](Sources/Auth/SessionStore.swift) 内调用（对齐 [session-scoped-store-refresh.md](/.claude/rules/session-scoped-store-refresh.md)）。

### 5.2 GiftPlayerRouter

**文件**：`Sources/GiftEffect/Players/GiftPlayerRouter.swift`

```swift
@MainActor
final class GiftPlayerRouter {
    private let svga = SVGAAnimationPlayer()
    private lazy var yyeva = YYEVAAnimationPlayer()  // lazy：首次遇 .mp4 时才 init

    private var activePlayer: GiftAnimationPlayer?

    func play(item: GiftEffectItem, in host: UIView, onFinish: @escaping () -> Void) {
        guard let url = item.animationUrl else { onFinish(); return }
        let ext = URL(string: url)?.pathExtension.lowercased() ?? ""
        let player: GiftAnimationPlayer? = {
            switch ext {
            case "svga": return svga
            case "mp4": return yyeva
            default: return nil
            }
        }()

        guard let p = player else {
            logger.warning("Unsupported ext: \(ext), skip")
            onFinish()
            return
        }
        activePlayer = p
        p.play(item: item, in: host, onFinish: { [weak self] in
            self?.activePlayer = nil
            onFinish()
        })
    }

    func stopAll() {
        activePlayer?.stop()
        activePlayer = nil
    }

    func tearDownPlayers() {
        svga.tearDown()
        yyeva.tearDown()
        activePlayer = nil
    }

    func warmupSVGA() {
        svga.warmup()  // 冷启 5s 后调
    }
}
```

### 5.3 SVGAAnimationPlayer

**文件**：`Sources/GiftEffect/Players/SVGAAnimationPlayer.swift`

```swift
import SVGAPlayer

@MainActor
final class SVGAAnimationPlayer: NSObject, GiftAnimationPlayer, SVGAPlayerDelegate {
    private var player: SVGAPlayer?
    private var parser: SVGAParser?
    private var currentFinish: (() -> Void)?

    func warmup() {
        // 预初始化 parser（内部有 caches 预建）
        parser = SVGAParser()
        logger.info("SVGA warmed up")
    }

    func play(item: GiftEffectItem, in host: UIView, onFinish: @escaping () -> Void) {
        guard let url = item.animationUrl.flatMap(URL.init(string:)) else {
            onFinish(); return
        }
        currentFinish = onFinish
        let p = ensurePlayer(in: host)
        (parser ?? {
            let p = SVGAParser()
            self.parser = p
            return p
        }()).parse(with: url) { [weak self, weak p] videoItem in
            guard let self, let p = p, let videoItem = videoItem else {
                self?.finishOnce(); return
            }
            p.videoItem = videoItem
            p.loops = 1
            p.startAnimation()
        } failureBlock: { [weak self] err in
            logger.warning("SVGA parse fail: \(err?.localizedDescription ?? "nil")")
            self?.finishOnce()
        }
    }

    private func ensurePlayer(in host: UIView) -> SVGAPlayer {
        if let p = player, p.superview === host { return p }
        player?.removeFromSuperview()
        let p = SVGAPlayer(frame: host.bounds)
        p.contentMode = .scaleAspectFit
        p.delegate = self
        p.autoresizingMask = [.flexibleWidth, .flexibleHeight]
        host.addSubview(p)
        player = p
        return p
    }

    func stop() {
        player?.stopAnimation()
        player?.clear()
        finishOnce()  // 硬停也要 fire onFinish 让 Center 队列继续
    }

    func tearDown() {
        player?.stopAnimation()
        player?.removeFromSuperview()
        player = nil
        parser = nil
    }

    private func finishOnce() {
        let f = currentFinish
        currentFinish = nil
        f?()
    }

    // MARK: SVGAPlayerDelegate
    func svgaPlayerDidFinishedAnimation(_ player: SVGAPlayer!) {
        finishOnce()
    }
}
```

**关键点**：
- `player` 单例复用 —— 挂在 host UIView 的 subview，item 切换时 videoItem 替换不重建 player
- `stop()` 也 fire onFinish 一次 —— Center 需要感知才能推 next（**特别对齐硬中断语义**：stop 后 current=nil，此时不需要 next，但为将来场景切换后立即入新 item 不阻塞留下钩子）
  - 实际上 stop 由 setActiveScene 调，Center 会自己清 current；此处 finishOnce 是**幂等无害**的（Center.current 已被 setActiveScene 清为 nil，onFinish 内 `self?.current = nil` 是 no-op）

import YYEVA

@MainActor
final class YYEVAAnimationPlayer: NSObject, GiftAnimationPlayer, YYEasyMetalPlayerDelegate {
    private var player: YYEasyMetalPlayer?
    private var currentFinish: (() -> Void)?

    }

        finishOnce()
    }

    func tearDown() {
        player?.stop()
        player?.removeFromSuperview()
        player = nil
    }

    private func finishOnce() {
        let f = currentFinish
        currentFinish = nil
        f?()
    }

    // MARK: YYEasyMetalPlayerDelegate

public extension View {
    /// 声明本 view 属于某个礼物特效场景
    /// onAppear 调 setActiveScene；onDisappear 调 leaveScene（scenePhase != .background 守卫）

    }
}

private struct GiftEffectSceneModifier: ViewModifier {
    let scene: GiftEffectScene
    let scopeId: String
    @Environment(\.scenePhase) private var scenePhase

    func body(content: Content) -> some View {
        content
            .onAppear {
                GiftEffectCenter.shared.setActiveScene(
                    GiftEffectSceneKey(scene: scene, scopeId: scopeId)
                )
            }
            .onDisappear {
                guard scenePhase != .background else { return }
                GiftEffectCenter.shared.leaveScene(
                    GiftEffectSceneKey(scene: scene, scopeId: scopeId)
                )
            }
    }
}

### 6.3 GiftEffectIntake

**文件**：`Sources/GiftEffect/IM/GiftEffectIntake.swift`

```swift
@MainActor
public enum GiftEffectIntake {
    /// 解析 IM payload 构造 item 并入队；返回是否成功识别为礼物消息
    @discardableResult
    public static func ingest(
        scene: GiftEffectScene,
        scopeId: String,
        attachType: AttachType,
        payload: [String: Any],
        mineYxAccid: String,
        into center: GiftEffectCenter = .shared
    ) -> Bool {
        let key = GiftEffectSceneKey(scene: scene, scopeId: scopeId)
        guard let item = parseItem(
            sceneKey: key, attachType: attachType,
            payload: payload, mineYxAccid: mineYxAccid
        ) else { return false }

        // 判定：中央大动画 vs 微飘窗
        if let url = item.animationUrl,
           let ext = URL(string: url)?.pathExtension.lowercased(),
           ["svga", "mp4"].contains(ext) {
            center.enqueue(item)
        } else if scene != .chat {  // Chat 无动画时不走微飘窗
            let toast = MicroToastItem(
                id: UUID(), sceneKey: key,
                imgUrl: item.staticImgUrl ?? item.animationUrl,
                giftName: item.giftName,
                count: item.giftCount, duration: 3.0
            )
            center.showMicroToast(toast)
        }
        return true
    }

    private static func parseItem(
        sceneKey: GiftEffectSceneKey,
        attachType: AttachType,
        payload: [String: Any],
        mineYxAccid: String
    ) -> GiftEffectItem? {
        // giftId：String / Int64 双兼容
        let giftId: Int64 = decodeInt64(payload["giftId"]) ?? 0
        let giftCount: Int = decodeInt(payload["giftNum"] ?? payload["giftCount"]) ?? 1
        let giftPrice: Int64 = decodeInt64(payload["giftPrice"]) ?? 0

        // sender 字段可能在 payload 顶层或 senderInfo 嵌套
        let senderYxAccid = decodeSenderYxAccid(payload) ?? ""
        let senderNickname = decodeString(payload["senderNickname"] ?? payload["nickname"]) ?? ""
        let senderAvatar = decodeString(payload["senderAvatar"] ?? payload["avatar"])

        let giftName = decodeString(payload["giftName"]) ?? ""
        let animationUrl = decodeString(payload["giftIcon"] ?? payload["giftImg"])?
            .trimmingCharacters(in: .whitespaces)
            .nilIfEmpty
        let staticImgUrl = decodeString(payload["giftSmallImg"] ?? payload["giftImg"])?
            .trimmingCharacters(in: .whitespaces)
            .nilIfEmpty

        return GiftEffectItem(
            id: UUID(),
            sceneKey: sceneKey,
            senderYxAccid: senderYxAccid,
            senderNickname: senderNickname,
            senderAvatarUrl: senderAvatar,
            giftId: giftId,
            giftName: giftName,
            giftCount: giftCount,
            giftPrice: giftPrice,
            animationUrl: animationUrl,
            staticImgUrl: staticImgUrl,
            timestamp: Int64(Date().timeIntervalSince1970 * 1000),
            isSelfSent: senderYxAccid == mineYxAccid
        )
    }
}
```

`decodeInt64` / `decodeInt` / `decodeString` 复用现有 [`GiftModel.swift`](Sources/Gift/GiftModel.swift) 的兼容 decoder。

## §7 性能指标 · 验收基线

| 指标 | 目标 | 验证方式 |
|---|---|---|
| 首次入队到首帧渲染（资源已缓存） | P95 ≤ 200ms | Instruments Timeline + os_signpost |
| 首次入队到首帧渲染（首次下载） | P95 ≤ 800ms（正常 4G），≤ 2000ms（弱网 3G） | 同上 |
| SVGA 播放 fps | ≥ 55 fps（60Hz 屏），掉帧率 < 5% | Instruments Core Animation |
| YYEVA 播放 fps | ≥ 55 fps | 同上 |
| 单条 SVGA 播放峰值内存 | < 30MB | Instruments Allocations |
| 单条 YYEVA 播放峰值内存 | < 50MB | 同上 |
| App 冷启到 SVGA warmup 完成 | < 6s（5s idle + 1s parse init） | 冷启 log 时间戳 |
| enqueue 全链路（IM 收到→pending 加入） | < 5ms | os_signpost |
| 场景切换硬中断到 stop 完成 | < 50ms | os_signpost |
| 30 条队列积压时内存增量 | < 5MB（不含播放中） | Instruments Allocations |

**明确降级线**：任一指标持续 3 帧超阈值 → 记录 os_signpost 触发 log，不做自动降级（本 spec 内）；后续 spec 评估。

## §8 错误处理与边界

| # | 场景 | 处理 |
|---|---|---|
| 1 | 动画 URL 无效 / 网络失败 | Player onError → onFinish → next；log warning，不阻塞 |
| 2 | URL 后缀既非 .svga 也非 .mp4 | GiftPlayerRouter 直接 onFinish；log warning |
| 3 | SVGA parse 失败 | 同 #1 |
| 4 | YYEVA 首次 lazy init 失败（Metal 不可用 / iOS < 目标） | 降级为该 item skip；后续 .mp4 全 skip；log |
| 5 | App 切后台 | 不 stopCurrent（保 Player 内部状态）；播放器 SDK 自然暂停（SVGA CADisplayLink 暂停）；scenePhase=.background 时 modifier onDisappear 被守卫拦截，不清队列 |
| 6 | App 回前台 | Player SDK 自然 resume（不需要额外调）；若因 App 内存告警导致队列被清则 no-op |
| 7 | 内存告警 didReceiveMemoryWarning | Center.handleMemoryWarning：stop + clear pending + clear microToasts；activeKey 保留 |
| 8 | logout | Center.reset：stop + clear + tearDownPlayers + Window hide |
| 9 | 场景 view 因 sheet 覆盖变 background 但未 onDisappear | 无副作用（activeKey 保持，UIWindow 层在 sheet 上方仍可见） |
| 10 | 快速切换场景（Live→Call→Live 在 200ms 内） | setActiveScene 幂等 key 相同 return；不同 key 硬中断—如快速抖动会造成动画瞬间起停 —— 可接受，非常规场景 |
| 11 | IM 消息 payload 缺关键字段（无 giftIcon 也无 giftImg） | parseItem 返回 nil；intake 返回 false；调用方 log |
| 12 | 派对房 gzip 数组解压失败 | PartyMessageRouter 已有兜底，log；不影响本引擎 |

## §12 红队评审预期（B 档降档：只挖未覆盖 case）

- **UIWindow.windowLevel 冲突**：alert-1 是否与系统 alert / call kit UI 冲突 → **需真机验证**（本 spec 假设无冲突，若冲突降到 statusBar + 0.5）
- **iOS 15 UIWindow(windowScene:) API**：`connectedScenes.first` 可能是错的 activeScene → **需在多 scene（iPad 分屏）真机测**（本 spec 假设 iPhone 单 scene，路线图已锁"仅 iPhone 竖屏"）
- **SVGA/YYEVA player 单例复用 + stop 立即 replay** 是否稳定 → SDK 层可能有内部状态残留导致 replay 空 / 崩 → 真机压测（连续 30 次不同资源播放）
- **场景切换极端时序**：`leaveScene` 与 `playNextIfIdle` 交错 → 若 leaveScene 触发 stop 但 SDK 异步回调 onFinish 在 stop 之后到达 → **finishOnce 幂等保护**（§5.3 已实现）
- **YYEVA 首次 lazy init 阻塞主线程**：若 Metal shader 编译需要 100ms+ → 首条 .mp4 卡顿 → 考虑在 SVGA warmup 后 5s（App 冷启 10s）也预热 YYEVA
- **派对房 gzip 数组 40 条**：一次 enqueue 40 条会立刻 dequeue 10 条（30 上限） → 前 10 条永远看不到 → 可接受，非常规场景
