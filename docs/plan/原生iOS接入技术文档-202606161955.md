| AES Key | 本地 xcconfig 注入（16 字节，AES-128） |
| AES IV | 本地 xcconfig 注入（16 字节） |

### 加解密（与 H5 crypto.js 对齐）
- **请求体**：JSON 字符串 → AES-128-CBC/PKCS7 → **Base64**，作为原始 body 发送。
- **响应体 `result`**：**Hex 密文** → AES 解密 → JSON。
- **登录密码**：`MD5(MD5(password + appId))`，两次均**大写**十六进制。

### 公共请求头
`loginToken` / `anchorToken`（均为登录 token）、`appid`、`Ocp-Apim-Subscription-Key`、`deviceId` / `deviceNo`（本地 UUID 持久化）、`deviceType=iPhone`、`osType=iOS`、`osVersion`、`appVersion` / `version`、`Accept-Language=en`、`isProxy=false`。

### 响应处理约定
- 顶层 `{ code, message, result }`，`code == "0000"` 为成功，否则抛 `APIError`。
- `result` 为 `null` / 非 JSON 顶层对象时按"无数据"处理（避免 `JSONSerialization` 对 NSNull 抛 OC 异常导致崩溃 —— 这是早期"开播 5 秒闪退"的根因）。

### 3.3 引擎初始化 `AgoraRtcEngineConfig`
```swift
config.appId = "4af61c7a92f447d3a582308b5817dbd2"
config.channelProfile = .liveBroadcasting   // 直播；1v1 通话用 .communication
kit.enableVideo(); kit.enableAudio()
kit.setDefaultAudioRouteToSpeakerphone(true)
```

### 3.4 外部视频源（画面先过相芯美颜，再推给声网）
```swift

```
- 本地预览用自有 Metal 视图（推外部帧时声网 `setupLocalVideo` 不生效）。
- 音频用声网自采集麦克风。

### 3.5 视频编码 `AgoraVideoEncoderConfiguration`
| 参数 | 当前值 | 备注 |
|---|---|---|
| size | **720 × 1280** | H5 直播为 540 × 960，可考虑对齐降负 |
| frameRate | 30 | H5 为 24（LOW 档 15） |
| bitrate | `AgoraVideoBitrateStandard` | 标准自适应 |
| orientationMode | `.fixedPortrait` | 固定竖屏 |
| mirrorMode | `.disabled` | 远端看到非镜像 |

### 3.6 频道媒体选项 `AgoraRtcChannelMediaOptions`
```swift
option.clientRoleType = .broadcaster      // 对应 web role:'host'；观众 .audience
option.publishCustomVideoTrack = true     // 推外部(美颜后)视频帧
option.publishMicrophoneTrack = true
option.autoSubscribeAudio = true
option.autoSubscribeVideo = true
```

### 3.7 加入频道
```swift
kit.joinChannel(byToken: rtcToken, channelId: agoraChannelId, uid: userId, mediaOptions: option)
```

### 3.8 推帧 `AgoraVideoFrame`
```swift
frame.format = AgoraVideoFormat.cvPixelBGRA.rawValue   // 相机 BGRA
frame.textureBuf = pixelBuffer
frame.rotation = 0
kit.pushExternalVideoFrame(frame, videoTrackId: 0)
```

### 3.9 关键回调（`AgoraRtcEngineDelegate`）
- `didJoinChannel`：本地加入成功。
- `didJoinedOfUid`：远端用户加入 → `setupRemoteVideo`（用于通话/连麦远端画面）。
- `didOfflineOfUid`：远端离开 → 解绑画面。
- `didOccurError`：**110=token 无效，109=token 过期**（早期"开播失败"即 token 用错来源所致）。
- `tokenPrivilegeWillExpire`：token 即将过期，需重新取。

### 3.10 codec 说明（重点）
- 原生 4.x **默认视频编码即 H.264**（移动端硬编），与 H5 通话端 `codec:'h264'` 一致，**无需额外设置**。
- 原生**没有** web SDK 的 `createClient({mode,codec,role})` 入口；mode→`channelProfile`，role→`clientRoleType`，codec 由引擎协商。
- 如需强制 codec，只能走私有参数 `setParameters`（键名需向官方确认）。
- ⚠️ H5 主播推流用 **vp9**，但原生 iOS **无 vp9 编码器**，只能 H.264 —— 需确认混编互通。

### 3.11 H5 web SDK 配置对照
| 客户端 | web 参数 | 原生等价 |
|---|---|---|
| 通话 | `{mode:'rtc', codec:'h264'}` | `.communication` + 默认 h264 |
| 主播直播 | `{mode:'live', codec:'vp9', role:'host'}` | `.liveBroadcasting` + `.broadcaster` + h264 |
| 观众 | `{mode:'live', codec:'h264', role:'audience'}` | `.liveBroadcasting` + `.audience` |

H5 版本：`agora-rtc-sdk-ng 4.23.2`、`agora-rtm 2.1.10`（与原生版本号不同体系，AppID/token 体系一致即可互通）。

### 4.3 进房模型（⚠️ 关键经验）
**采用「先 IM 登录 → 普通模式进聊天室」，与 H5 一致；不用独立模式。**

H5 流程：`await nim.connect()`（IM 登录，token 即"云信密码"）→ 复用 IM 长连接进各聊天室。

iOS 对齐：
```swift
// 1) 注册 appKey（一次）
NIMSDK.shared().register(with: NIMSDKOption(appKey: nimAppKey))
// 2) IM 登录（account=yxAccid, token=imToken，静态 token 鉴权 authType=0）
NIMSDK.shared().loginManager.login(account, token: token) { error in ... }
// 3) 登录成功后进聊天室（mode=nil，SDK 经 IM 通道自动取地址）
let req = NIMChatroomEnterRequest()
req.roomId = yxRoomId; req.roomNickname = nickname; req.retryCount = 3
NIMSDK.shared().chatroomManager.enterChatroom(req) { error, chatroom, _ in ... }
```

| 进房参数 | 来源 |
|---|---|
| account | `yxAccid`（登录返回，32 位 hex） |
| token | `imToken`（登录返回，32 位） |
| 鉴权方式 | authType = 0（静态 token 鉴权） |
| 聊天室 ID | 开播接口返回的 `yxRoomId`（如 `11242770959`） |

### 4.4 踩坑记录：415 错误
- **现象**：用 `NIMChatroomIndependentMode` 独立模式直连聊天室 link server（`chatwl0x.yunxinfw.com:443`），地址正确但 TCP 被 RST，报 `415 NIMRemoteErrorCodeConnectionError`。
- **根因**：该云信账号体系的聊天室**依赖 IM 登录态**，独立模式绕过 IM 通道直连，鉴权不通过被服务端断开。
- **修复**：改为先 `loginManager.login`（IM 登录），再普通模式 `enterChatroom(mode=nil)`。IM 登录通过后聊天室即正常。
- 独立模式备用代码（`getChatRoomAddress` 等）已保留但当前不使用。

### 4.5 消息接收（`NIMChatManagerDelegate.onRecvMessages`）
按 `session.sessionType == .chatroom` 过滤，分类型处理：
- `.text`：公屏文本（`senderName`：`text`）。
- `.custom`：礼物/自定义消息 —— **当前占位** `[收到礼物/自定义消息]`，待按 `attachType=50` 规则解析。
- `.notification`：进出房通知（`NIMChatroomNotificationContent.eventType` enter/exit）→ 在线人数增减。

### 4.6 H5 web SDK 对照
H5 用 `nim-web-sdk-ng 10.7` 的 `CHATROOM_BROWSER_SDK`，`new CHATROOM_BROWSER({appkey, account, token, chatroomId, chatroomAddresses})` + `connect()`。原生与 web 版本号不同体系，账号/appKey 体系一致即可。

## 7. 开播相关接口（`LiveService`）

| 接口 | 说明 |
|---|---|
| `POST /api/agora/live/getMyLiveRoomV2` | 取直播间配置（封面/简介），原样回传 beginLiveRoom |
| `POST /api/agora/live/beginLiveRoom` | 建房（回传配置 + 礼物/愿望单字段） |
| `POST /api/index/getAgoraRtmToken` | 取声网 join 用 rtcToken |
| `POST /api/agora/liveHeartBeatV2` | 直播心跳，每 6s，`callState=0` |
| `POST /api/agora/live/endLiveRoom` | 下播 |
| `POST /api/agora/live/getChatRoomAddress` | 聊天室地址（独立模式备用，当前未用） |

**开播组装**：`getMyLiveRoom`（频道/roomId/uid） + `beginLiveRoom`（建房） + `getAgoraRtmToken`（join token）三者合并 → 频道用 `agoraChannelId`、token 用 `getAgoraRtmToken.rtcToken`、uid 用 `userId`。字段用手动取值（兼容数字/字符串/浮点），避免严格解码失败。
