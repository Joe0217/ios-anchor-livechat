## §1 数据契约 · State · Store 接口

### 1.1 无新接口
本轮 0 后端接口调用。

### 1.2 CallStore 新增暴露方法（UI-only side effect）

```swift
// CallStore.swift 新增（保持现有 State 不变，仅追加方法）
@Published private(set) var isMicMuted: Bool = false          // UI 反馈用
@Published private(set) var isUsingFrontCamera: Bool = true   // UI 反馈用

func toggleMic() { /* engine.muteLocalAudioStream(newValue) + isMicMuted = newValue */ }
func switchCamera() { /* CameraManager.switchDevice() 或 engine.switchCamera() + isUsingFrontCamera toggle */ }
```

**契约**：
- toggleMic：幂等，`ended`/`idle` 态调用 no-op
- switchCamera：只在 `connecting`/`connected` 有效；其他态 no-op；直播私 call 场景（`frontGameType == .live`）**禁用**（直播摄像头由 LiveStore 管，跨场景切换风险大 → 灰按钮）
- CallStore.State enum **不变**，不新增态

### 1.3 弱网 toast 触发源

- 复用 `Sources/Live/NetworkQualityMonitor`（下一轮 D 里程碑再抽 Core，本轮 import 直接用）
- 触发点：当 `NetworkQualityMonitor` 连续 30 次 quality ≥5 时，CallStore emit 1 次 toast 事件
- 冷却：**2 秒内不重复 toast**（防抖）
- toast 组件：复用 `Sources/Match/MatchToast`（已有轻量组件）

**不含**：弱网自动 forceEnd（那是 D 里程碑 endType=7 链路，本轮不做）

## §2 View 结构 & PreviewProvider

### 2.1 CallFaceTimeView.bottomBar 改造

现状（CallView.swift:187-195）：
```swift
private var bottomBar: some View {
    HStack { Spacer(); CircleButton(...) 挂断; Spacer() }
}
```

目标：
```swift
private var bottomBar: some View {
    HStack(spacing: 28) {
        CircleButton(mic ⇄ mic.slash, 灰底, action: toggleMic)
        CircleButton(camera.rotate, 灰底, action: switchCamera, disabled: frontGameType == .live)
        CircleButton(sparkles, 灰底, action: showBeautySheet)
        CircleButton(phone.down.fill, 红底, action: hangup)   // 保留原位置
    }.padding(.bottom, 36).padding(.horizontal, 24)
}
```

**布局约束**：
- 4 按钮居中平铺，间距 28pt（H5 视觉参考）
- 尺寸 sub-button（54x54）小于挂断（64x64）保持视觉主次
- SF Symbol 命名 preflight（按 sf-symbol-usage-preflight.md）：`mic.fill` / `mic.slash.fill` / `arrow.triangle.2.circlepath.camera.fill` / `sparkles`（均系统已知）
