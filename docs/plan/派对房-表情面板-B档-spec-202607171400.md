# 派对房 · 表情面板 · B档 spec

日期：2026-07-17 · 判档：B（1 接口 + 简单状态机 + 0 新 SDK + 单一入口）

## §0 范围三圈 · 判档

### 内圈（本轮做）
- HTTP list 端点 `getPartyRoomEmojis`
- IM 发送 attachType -10（静态 emojiStatic）/ -11（玩法 emojiPlay）自定义消息
- IM 接收 attachType -10/-11 分发到麦位播放队列
- 底部表情面板 UI（4×2 grid + 底部 tab bar）
- 麦位内 SVGA 播放器（URL 单段 · 播完停留末帧）
- `PartyRoomView.handleEmojiTap` 接线
- 上麦门槛（UI 层已就位 + IM send 前二重 guard）

### 外圈（占位 · 后续里程碑）
- 埋点（H5 有 b_emoji_panel_open / b_emoji_tab_switch / b_emoji_mic_play / b_sentEmoji_success / b_playEmoji_success 五类）—— 归 J 里程碑埋点收敛
- 长按预览 / 收藏 / 房主自定义上传 —— H5、Android 均无此能力，路线图未覆盖，不做

### 判档依据
- 接口 1 个（list） · IM 走既有 chatroom 通道
- 状态机 3 态（idle/loading/loaded[error]） + 麦位队列（[String: [EmojiPayload]] 单向 enqueue/dequeue）
- SDK：SVGAPlayer 2.5.7 已 pinned，PK/GiftEffect 已用
- 入口单一：底部工具栏 emoji 按钮

## §1 业务契约

### 1.1 HTTP list（后端接口）
- **端点**：POST `/sapi/weidou/v1/client/party/room/getPartyRoomEmojis`（无入参 body `{}`）
- **返回**：`[PartyEmojiClassification]`
- **H5 用 GET，iOS 用 POST**：`PartyAPIClient` 只有 `post()`；H5 `src/api/party/index.ts:139` 明确后端两 verb 都接（POST 别名 `apiPartyEmojis`）—— 沿用 party 域一致的 POST，不给 client 加 get()。参 [[api-http-method-strict]]。

### 1.2 Codable 模型（对齐 H5 `livechat-h5/src/api/pay/index.ts:4-20`）
```
struct PartyEmojiClassification: Decodable {
    let classType: String
    let coverImage: String?
    let emojisList: [PartyEmojiItem]
}
struct PartyEmojiItem: Decodable {
    let id: String           // String/Int 双兼容 decode · [[ios-decode-userid-compat]]
    let classType: String?
    let minImage: String?
    let gifImage: String?
    let playType: String?
    let resultImages: [PartyEmojiResultImage]?
}
struct PartyEmojiResultImage: Decodable {
    let key: String
    let image: String
}
```

### 1.3 判静态 vs 玩法（对齐 H5 `constant/party.ts:30-37`）
```swift
extension PartyEmojiItem {
    var isPlayEmoji: Bool {
        guard let p = playType else { return false }
        return !p.isEmpty && p != "normal"
    }
}
```

### 1.4 IM send · attachType -10（emojiStatic）
- 触发：面板点选 · `!item.isPlayEmoji`
- payload data：`{ id, minImage, playUrl: item.gifImage, sendUserId }`
- 走 `PartyRoomChatManager.sendCustomMessage(attachType: -10, data:)`（新增方法）

### 1.5 IM send · attachType -11（emojiPlay）
- 触发：面板点选 · `item.isPlayEmoji` · `store.isOnSeat`（观众 tap 走 toast 拦截 · UI 层已 disable，此处二重防御）
- **resultImages 空 guard**：数组 nil / 空 → 拒送 + `AppLogger.party.error` + toast "表情异常"
- **客户端随机抽**：`picked = item.resultImages!.randomElement()!`（收端不重抽 · 对齐 H5 `usePartyHooks.js:1810-1820`）
- payload data：`{ id, minImage, playUrl: picked.image, sendUserId, playType, resultKey: picked.key, timestamp: ms }`

### 1.6 IM receive
- `PartyMessageRouter.handle` 里 case `.emojiStatic / .emojiPlay` 从 placeholder 群组（L200-207）挪出加真分发
- payload 从 `NIMPayloadDecoder.unwrapDataField(from: ext)` 解出（已就绪基础设施）
- **self-echo skip**（对齐 H5 `party.js:744-761`）：`Int(payload["sendUserId"]) == SessionStore.shared.userId` 命中 return（云信 chatroom 回环去重）
- 分发到 `PartyStore.enqueueEmoji(seatUserId:, payload:)`

**字段名铁律**：`id / minImage / playUrl / sendUserId / playType / resultKey / timestamp` —— H5 注释明示与 Android EmojiEffectEvent 对齐。首次真机接入后按 log 复核（[[im-payload-real-log-over-code-assumption]]）。

## §2 状态机

### 2.1 面板 list 加载
```
expressionListState: idle → .loading → .loaded([classifications]) | .error(msg)
```
- 首次面板 onAppear 拉 · loadIfNeeded 短路（loaded 后不重拉）
- error 态：面板中央显示 retry 按钮

### 2.2 麦位队列（对齐 H5 `expressionMsgMap`）
```swift
@Published var emojiQueueMap: [String: [EmojiPayload]] = [:]  // key: sendUserId
```
- **enqueue**：IM 收到 → append 到 map[sendUserId]；队列长度 > 20 时 shift 队首（对齐 H5 `QUEUE_MAX_SIZE = 20`）
- **dequeue**：麦位 SVGA player onFinish 回调 → remove first
- **播放规则**：同一麦位串行（player 空闲 + 队列非空 → 播队首）· 跨麦位并行

### 2.3 EmojiPayload（麦位播放的最小结构）
```swift
struct EmojiPayload: Equatable, Identifiable {
    let id: String            // uuid，避免 SwiftUI ForEach 重复 id
    let emojiId: String
    let playUrl: String       // 直接播这个 URL，不做二次抽选
    let playType: String?
    let resultKey: String?
    let timestamp: Int64?
}
```

## §3 UI

### 3.1 底部面板 `PartyExpressionPanel`
- 呈现：`.sheet(isPresented:) + .presentationDetents([.fraction(0.5)])`（对齐 H5 min-h-50%）
- 顶部 `TabView(.page)`：分类 × 分页 拍平为单层 · 每页 4×2 grid · 每格 56×56 显示 `minImage`（CachedAsyncImage）
- 底部圆形 tab bar：`ScrollView(.horizontal)` · tab 24×24 图标（`coverImage`）· 激活底色 `Color.white.opacity(0.16)`
- 自绘小圆点 indicator：当前分类页数 > 1 才显示
- 空态：ProgressView；error 态：retry 按钮
- **preflight**（[[cross-scene-component-reuse-preflight]]）：无 CameraManager / ignoresSafeArea / shared store 自持依赖，可作 sheet 半屏

### 3.2 麦位内 `PartyEmojiSVGAPlayerView`
- **新建组件**（无公共组件可复用 · [[prefer-shared-component-over-adhoc]] preflight）：
  - `RemoteSVGAImageView` 是无限循环（头像装饰框）· 不合适
  - `SVGAAnimationPlayer` 是 GiftEffectCenter 独占 · 抢占礼物动画
  - `PKSVGAPlayerView` 是 bundle-local 资源 · URL 场景不适配
- 实现：UIViewRepresentable + `SVGAParser.parse(with: URL)` + `SVGAPlayer.loops = 1` + onFinish 幂等 fire（generation counter 防迟到）
- 挂载点：`Sources/Party/UI/Components/` 内三种 seat cell（大麦位 / 小麦位 / 主播位）· 观察 `store.emojiQueueMap[seatUserId]?.first`
- 队列驱动：非空 → 立即播队首（透明 overlay 覆盖头像上方 · size 与头像等高等宽） → onFinish → `store.dequeueEmoji(seatUserId:)` → next
- **播完停留**：SVGA 资源末尾自带定格帧（H5 侧确认）· 客户端不做停留计时
- 队列空：overlay 隐藏 · 释放 SVGAPlayer 视频源（防内存堆积）

### 3.3 emojiButton 接线
- `PartyRoomView.handleEmojiTap` 替换 log 为 `showExpressionPanel = true`
- 主 body 加 `.sheet(isPresented: $showExpressionPanel) { PartyExpressionPanel(store: store) }`
- panel 内点选：`store.sendEmoji(item)` → 按 `item.isPlayEmoji` 分流 -10 / -11

## §4 验收

### F 正向
- **F1** 观众进房 · tap emoji 按钮 · **按钮 disable 不响应**（现有 UI 层 opacity/hitTest 门控）
- **F2** 上麦者/主播 tap · panel 拉起 · list 拉成功 · 分类横滑 · 4×2 grid 显示 minImage
- **F3** 点静态表情（playType 空 / "normal"）· 发 -10 IM · 自己麦位 SVGA 播 `gifImage` 一次停留末帧
- **F4** 点玩法表情（playType 非空 · resultImages 非空）· 客户端随机抽 · 发 -11 IM · 自己麦位 SVGA 播 picked.image 一次停留末帧
- **F5** 收对方 -10 / -11 消息 · 对应 sendUserId 麦位 SVGA 播 playUrl · 播完停留末帧
- **F6** 面板反复开关 · list 已 loaded 时不重拉 · SVGA 队列不受面板开关影响

### R 反向（Critical）
- **R1** self-echo 云信回环 · 云信 push 自己发的消息回来 · IM 分发 `sendUserId == currentUserId` 命中 skip · 避免双入队（H5 已踩过坑）
- **R2** resultImages 空 -11 拒送 · 数组 nil / 空 · sendEmoji guard + AppLogger.error + toast "表情异常" · 不发消息不本地上屏
- **R3** 同一麦位多个 emoji 快速点 · 队列长度 > 20 时 shift 队首 · 单麦位串行播 · 跨麦位并行不阻塞
- **R4** 面板 list 拉失败 · error 态 + retry 按钮 · retry 时 loading UI · 不阻塞其他 party 功能
- **R5** 观众伪造直接调 `store.sendEmoji` · `ChatManager.sendCustomMessage` 前二重 guard `store.isOnSeat` · false 时 return 不发（防未来 UI refactor 门控失守）
- **R6** SVGA 加载 URL 失败 · onError 回调 · dequeue 该 payload · 播下一个 · 不卡队列

## §6 我按以下推进 · 如非此意请打断

1. **面板呈现**：`.sheet + presentationDetents([.fraction(0.5)])` 半屏底部 · 不 fullscreen · 不用 confirmationDialog
2. **播放位置**：麦位头像上方 SVGA overlay（等高等宽） · 不做全屏特效 · 不与礼物特效共队列
3. **API method**：POST（PartyAPIClient 只有 post · 后端两 verb 都接 · 对齐 party 域）
4. **埋点 v1 跳过**：等 J 里程碑埋点收敛
5. **id 字段类型**：String/Int 双 decode 兼容
6. **payload 字段名**：完全对齐 H5 · 无别名（首次真机接入后按 log 复核）
7. **上麦门槛**：UI 层 disable + IM send 前 store.isOnSeat guard 双保险
8. **队列策略**：同麦位串行 · 跨麦位并行 · 单麦位上限 20（超过 shift 队首）
9. **不做**：长按预览 / 收藏 / 房主上传 / 埋点
