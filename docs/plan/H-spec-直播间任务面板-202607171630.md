## §1 状态机 + Protocol

### 1.1 Store 分层(v2 修订)

按项目现有直播 store 惯例(与 contributionStore/topRankStore/wishlistStore 一致模式),LiveGiftTaskStore **不做 shared 单例**,而是由 NIMChatroomManager `let` 强所有:

```
NIMChatroomManager
├── let contributionStore = LiveContributionStore()  # 既有
├── let topRankStore = LiveTopRankStore()             # 既有
├── let wishlistStore = WishlistStore()                # 既有
└── let liveGiftTaskStore = LiveGiftTaskStore()       # 新增,同排

LiveGiftTaskStore (@MainActor, ObservableObject)
├── @Published giftTask: GiftTaskProgress?
├── @Published loadState: LoadState  # idle/loading/loaded/error(String)
├── private var currentTask: Task<Void, Never>?  # 竞态保护
├── loadInitial()                       # LiveRoomView.handleStoresInitialLoad 调
├── refreshOnGift()                     # NIMChatroomManager.liveGiftRankUpdate case 内触发
└── reset()                             # LiveRoomView.onDisappear 调

LiveGiftTaskSheet (SwiftUI view)
├── @ObservedObject store: LiveGiftTaskStore  # 外部注入
├── @StateObject sheetStore = LiveGiftTaskSheetStore()  # sheet 生命周期
├── @StateObject historyStore = LiveGiftTaskHistoryStore()  # sheet 生命周期
└── @StateObject tycoonStore = ActiveTycoonTaskStore()  # sheet 生命周期

LiveGiftTaskSheetStore
├── @Published activeTab: Tab (.liveGift/.activeTycoon)
├── @Published showRule: Bool
└── onPresent()                        # sheet .onAppear:强制 activeTab=.liveGift + 通知 history refresh

LiveGiftTaskHistoryStore (sheet 内 @StateObject)
├── @Published pagingState: PagingState
├── private var page: Int (起始 1)
├── private let pageSize: Int (20)
├── private var currentTask: Task<Void, Never>?
├── refreshAsync(anchorUserId:) async  # sheet onPresent + .refreshable
├── loadMoreIfNeeded(currentItem, anchorUserId:)
└── reset()

ActiveTycoonTaskStore (sheet 内 @StateObject)
├── @Published loadState: LoadState
├── private var currentTask: Task<Void, Never>?
├── loadAsync() async                  # sheet .onAppear 首次
├── firstTaskRuleText() -> String     # 供 sheet 外壳 rule overlay
└── reset()
```

**Store 生命周期决策**:
- **LiveGiftTaskStore**:随 NIMChatroomManager 存续(该 nim 实例本身随 LiveRoomView 生命周期),自动无跨账号残留 → **不需要挂 SessionStore.login/logout**(与 contribution/topRank 一致)。避免 [session-scoped-store-refresh](../.claude/rules/session-scoped-store-refresh.md) 冲突。
- **Sheet 内 3 store**:sheet 关闭时 @StateObject 自然回收,LiveGiftTaskStore 保持

### 1.2 状态迁移(采用 `.refreshing(items:)` pattern 对齐直播场景)

按 [PKRecordStore / PropsInventoryStore / PartyListStore] 一致命名:

**LiveGiftTaskStore.LoadState**:
```
enum LoadState {
    case idle
    case loading                // 首次(无 previous)
    case loaded(GiftTaskProgress)
    case refreshing(previous: GiftTaskProgress)  // 有旧数据的刷新
    case error(String)           // 首次失败
    case errorWithPrevious(GiftTaskProgress, String)  // 刷新失败保留旧
}
```
迁移:
```
idle → loadInitial → loading → loaded / error
loaded → refreshOnGift → refreshing(previous) → loaded(new) / errorWithPrevious(previous)
error → 重试 → loading → loaded / error
errorWithPrevious → 下次 IM → refreshing(previous) → loaded / errorWithPrevious
reset → idle
```
**竞态**:refreshOnGift 内先 `currentTask?.cancel()`,再 `currentTask = Task { ... }`

**LiveGiftTaskHistoryStore.PagingState**:
```
enum PagingState {
    case idle
    case loading                                  // 首次 refresh 无 previous
    case refreshing(items: [GiftHistoryItem])     // refresh 保留 items
    case loaded(items: [GiftHistoryItem], hasMore: Bool)
    case loadingMore(items: [GiftHistoryItem])
    case finished(items: [GiftHistoryItem])        // 无更多
    case error(items: [GiftHistoryItem], String)   // 保留 items(反悔 H5)
}
```
- 首次 refresh:idle → loading → loaded / finished(empty) / error
- 后续 refresh:任何 loaded/finished/error → refreshing(items) → loaded / finished / error
- loadMore:loaded → loadingMore(items) → loaded(items+new, hasMore) / finished / error(items)
- reset → idle

**竞态**:
- refresh 时 currentTask?.cancel() → 新 Task
- loadMore 期若又触发 refresh → 覆盖 currentTask,老 loadMore 结果丢弃

**ActiveTycoonTaskStore.LoadState**:同 LiveGiftTaskStore 命名,`.refreshing(previous:)` + `.errorWithPrevious`

**LiveGiftTaskSheetStore**:
```
initial: activeTab=.liveGift, showRule=false
onPresent(): activeTab=.liveGift, historyStore.refreshAsync()  # 强制重置 Tab
切 tab liveGift → activeTab=.liveGift, 视觉保留(不 refresh)
切 tab activeTycoon → activeTab=.activeTycoon;若 tycoonStore.loadState==.idle 触发 tycoonStore.loadAsync(),否则视觉保留
点问号 → showRule=true
点 OK / .accessibilityAction(.escape) → showRule=false
```

## §2 数据契约

### 2.1 getLiveGiftTask

- **path**:`POST /api/wallet/anchor/taskInfo/liveGiftTask`
- **body**:`{}`(空对象)
- **response 假设字段**(⚠️ [agent-recon-field-names-unverified](../.claude/rules/agent-recon-field-names-unverified.md) step 3 前真机 log 校对):
  ```json
  {
    "giftTotal": 1234,
    "taskAmount": 5000
  }
  ```
- **Codable model**:
  ```swift
  struct GiftTaskProgress: Decodable {
      let giftTotal: Int64
      let taskAmount: Int64?   // Optional:nil / 0 都视为"无任务",icon 隐藏
      init(from decoder: Decoder) throws {
          let c = try decoder.container(keyedBy: CodingKeys.self)
          giftTotal = c.decodeFlexibleInt(forKey: .giftTotal).map(Int64.init) ?? 0
          taskAmount = c.decodeFlexibleInt(forKey: .taskAmount).map(Int64.init)  // 可为 nil
      }
  }
  ```

  ```swift
  struct GiftHistoryItem: Decodable {
      let userId: String
      let icon: String
      let nickname: String
      let headFrame: String?      // 头像框 URL(参 SenderProfile.headFrame)
      let activeTycoon: Bool?
      let formattedTime: String
      let giftIcon: String
      let giftNum: Int
      init(from decoder: Decoder) throws {
          let c = try decoder.container(keyedBy: CodingKeys.self)
          // userId String/Int 双兼容
          if let s = try? c.decode(String.self, forKey: .userId) { userId = s }
          else if let i = c.decodeFlexibleInt(forKey: .userId) { userId = "\(i)" }
          else { userId = "" }
          icon = (try? c.decodeIfPresent(String.self, forKey: .icon)) ?? ""
          nickname = (try? c.decodeIfPresent(String.self, forKey: .nickname)) ?? ""
          headFrame = try? c.decodeIfPresent(String.self, forKey: .headFrame)
          activeTycoon = try? c.decodeIfPresent(Bool.self, forKey: .activeTycoon)
          formattedTime = (try? c.decodeIfPresent(String.self, forKey: .formattedTime)) ?? ""
          giftIcon = (try? c.decodeIfPresent(String.self, forKey: .giftIcon)) ?? ""
          giftNum = c.decodeFlexibleInt(forKey: .giftNum) ?? 0
      }
  }
  ```

struct LiveGiftProgressBar: View {
    let currentPoints: Int64
    let totalPoints: Int64
    @State private var displayRatio: CGFloat = 0

        GeometryReader { geo in

            .frame(height: 12)
