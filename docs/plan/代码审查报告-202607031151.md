### 建议-1 · LiveBanner autoplay Task 未托管，keep-alive 下可能累积僵尸 Task

- **文件**：[LiveBanner.swift:54-64](../../Sources/Home/LiveTab/Components/LiveBanner.swift#L54-L64)
- **维度**：Swift 并发 / 内存与资源（Workflow 中 P1-2/3/4 三个维度重复报同源问题，主流程复查合并）
- **finder 原始 severity**：P1
- **复查后判定**：**建议**
- **触发链路（复查证据）**：
  - Read line 54-64 属实：`Task { @MainActor in while !Task.isCancelled { ... } }` 未存 handle
  - Grep：LiveBanner 由 LiveTabView.liveStream 消费，唯一入口
  - **多数场景 items ≤ 1**（H5 后端 Banner 通常 1 张）→ `guard items.count > 1 else return` 兜住，Task 一次就退出
  - **items ≥ 2 时**（活动期多张 Banner）Task 无 cancel 触点永久跑；keep-alive 架构下 view 不 dismount，onAppear 重复触发累积多个 Task
- **实际影响**：能耗浪费（每 3s 唤醒 main actor 跑 modulo），不阻塞不崩溃
- **finder 建议修复**：`.task(id: items.count) { ... }` 修饰符替代 `.onAppear { startAutoplay() }`；SwiftUI 自动绑定 view 生命周期 + items 变化重启
