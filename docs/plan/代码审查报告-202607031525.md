### 🟡 P2（信息）：Save 按钮 600ms 延迟窗口内未防重复 tap

- 文件：[WishSettingView.saveBar:473-479](Sources/Live/WishSetting/WishSettingView.swift#L473-L479)
- 触发场景 + 概率：用户 tap Save 后**600ms 内**再 tap（用户操作快 / 手抖双击）→ `submitTapped()` 又走一遍 canSave（仍 true）→ 又启一个 dismiss Task + 再 showToast("Saved")
- 影响：`SharedStore.commit` 被调 2 次（**幂等无数据错误**）；`toast "Saved"` 会重复启 timer 但字段 assign 相同（2s 后清空一次）；两个 dismiss task 先后触发（第一次 pop 后第二次无效）
- 复查后判定：**信息级**——无崩溃、无数据错误、无 UI 卡死；仅极罕见极速双击场景视觉可能双 toast 闪烁
- 修复方向（可选）：view 加 `@State isSubmitting = false` + tap 前 `guard !isSubmitting` + dismiss 前 `isSubmitting = true`
