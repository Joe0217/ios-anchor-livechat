### R-1 · MatchStore.lastToast 8 处硬编码 key 字符串未走 L10n

- **文件**：[Sources/Match/MatchStore.swift:150,176,180,196,219,241,255,269](../../Sources/Match/MatchStore.swift#L150)
- **维度**：iOS 平台规范

## 三、🟠 建议（8 条）

### S-1 · CallStore.lastJoinCallSource 无归属守卫 race window

- **文件**：[Sources/Call/CallStore.swift:471,485,795,811](../../Sources/Call/CallStore.swift#L471)
- **维度**：Swift 并发
- **原始 severity**：P1 → **复查后建议**（verifier severity-calibration 也 downgrade）
- **理由**：race 窗口需要"joinCall 慢 3-10s + 用户挂断 + 立刻接新通话"三个条件同时满足 —— dev 生产网络下窗口极小；且 catch 分支 nil 覆盖对 MatchStore 判定只影响一次 UI 反馈。**建议**：v3 §3.5 已明示"两处 assign"，可补 `msg.callId` 局部快照守卫作为**加固**（非阻塞）
- **修复**：`let expectedCallId = msg.callId; ...; guard self.current.callId == expectedCallId else { return }; self.lastJoinCallSource = r.source` 用 callId 快照守卫 assign 时机

### S-2 · MatchTabView 未接入 isActive，keep-alive 下 .task 无门控

- **文件**：[Sources/Home/LiveTab/LiveTabView.swift:185](../../Sources/Home/LiveTab/LiveTabView.swift#L185) + [MatchTabView.swift:55](../../Sources/Home/LiveTab/Match/MatchTabView.swift#L55)
- **维度**：SwiftUI 性能
- **原始 severity**：P1 → **建议**（verifier severity-calibration downgrade）
- **理由**：违反 [swiftui-keepalive-publisher-isolation.md](../../.claude/rules/swiftui-keepalive-publisher-isolation.md) 语义，但仅 1 次冷启动接口调用 + 3s 低频跑马灯动画 —— 用户无感知
- **修复**：`MatchTabView(isActive: isHomeTabActive && current == .match)` + 内部 `.task(id: isActive) { guard isActive else { return }; await vm.loadIfNeeded() }`，同时透传 `MatchMarqueeView(records: vm.callList, isActive: isActive)`（对齐 LiveNoticeBar 模式）

### S-5 · CameraManager.interruptionUnrecoveredDuration @Published 触发 5 view 失效

- **文件**：[Sources/Camera/CameraManager.swift:56-58,287-302](../../Sources/Camera/CameraManager.swift#L56)
- **维度**：SwiftUI 性能
- **原始 severity**：P2 → **建议**
- **理由**：仅 interruption 期间（后台切前台/相机被占用/系统压力）才 1Hz tick；生产环境 interruption 事件稀少，1Hz 触发 5 view（LiveRoomView / LivePrepareView / CallPOCView / BeautySettingsView / BeautyPreviewPanel）重算的实际频次极低
- **修复**：改 `PassthroughSubject<TimeInterval, Never>` publisher（非 @Published 字段），只有主动订阅者才收 event；MatchStore 通过 subscribe 消费，其他 view 不受影响

### S-6 · CameraManager.targetFPS Int 跨线程无 memory barrier
