## 三、关键反悔纪录（4 方向归类）

| 反悔 | 4 方向 | 修复 |
|---|---|---|
| 图/视频 send 失败 code=3 NIMLocalErrorCodeInvalidPicture | **通用知识缺失** | NIMSDK 10.10.0 拒绝空 filepath → 下载到 tmp file + setUploadURL 复用外链 |
| 私密视频缩略图灰色 | **spec 漏 case** | fromPrivateMedia coverUrl=nil → AVAssetImageGenerator 后台首帧提取 + LRU cache（Batch 4） |
| 顶部通话按钮 canCall=false 用户投诉 | **通用知识缺失** | CallAuthBridge 只用 levelName; H5 用 userLevel（等价），iOS mine.level 数字返回时 levelName nil 走 tierName 数字 fallback |
| 弹窗被消息气泡遮挡 | **View 结构错** | RewardRecordsPopup / DiaReceivePopup 从 self overlay hoist 到 ChatDetailView 顶层 overlay + zIndex |
| 系统会话 unknown 消息显空 | **spec 漏 case** | parseCustom default 分支加 attach.content 文本兜底,对齐 H5 msgObj.body 语义 |
| 发消息后乱滚动（identity churn / loadMore prepend 误滚 / tips 混入误滚 / withAnimation 叠加）| **多点组合**：View 结构错 + 通用知识缺失 | ChatMessage.stableId (clientMsgId ??id) + bottomAnchor 从原 store 派生 + loadMore anchor scroll + 移除 withAnimation |
| RewardProgressView 500ms 后忽现挤压消息列表 | **View 结构错** | 无条件占位 76pt 稳定布局，isOpenPaidMessage=false 时容器保持透明占位（Layout shift 消除） |
| 消息列表 tab bar 视觉与设计稿不符 | **spec 漏 case** | 原下划线视觉换成彩色渐变胶囊 + 99+ overlay 右上 |
| Chat 详情页 Tap Records 按钮无弹窗 | **View 结构错** | onTapRecords no-op → hoist state 到 ChatDetailView + fetchMessageBoxRecords async 拉数据 |
| chatBubble 收发不一致（H5 蓝本发送带 remoteExt.chatBubble） | **spec 漏 case** | sendText 加 buildRegularRemoteExt + Mapper 接收侧 extractChatBubble + selfChatBubble 参数解决 nonisolated Mapper 隔离 |

**反悔次数总结**：本轮 10+ 次反悔中，**通用知识缺失（NIMSDK / SwiftUI layout 陷阱 / iOS 16 兼容）占 40%**，**View 结构错（overlay 层级、self-owned state hoist）占 30%**，**spec 漏 case（H5 蓝本细读不足）占 30%**。

**本轮新提出的候选 rule**（未沉淀，供未来 milestone 参考）：
- **NIMSDK 空 filepath 拒绝**：`NIMImageObject(filepath: "")` 触发 code=3 InvalidPicture → 已在 [NIMChatAdapter](../../Sources/Message/Chat/Services/NIMChatAdapter.swift) `downloadToTmp` helper 落地，未来其他消息类型（file / location）如遇同款 blocker 可参考
- **SwiftUI overlay 层级被消息列表遮挡**：view self.overlay 挂在 view 自身 size 内，弹窗需要屏幕居中时 hoist 到父层 overlay + zIndex —— 类似 DiaReceivePopup / RewardRecordsPopup 模式
- **Layout shift 用无条件占位取代 conditional show**：数据未到达前的 76pt 空占位（Batch 6.1）避免 500ms 后忽现挤压 —— 可作为"数据驱动 UI 元素避免 layout jump"通用建议
