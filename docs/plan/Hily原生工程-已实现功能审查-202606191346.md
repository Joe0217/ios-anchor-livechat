## 一、总体结论

**核心主链路已真机验证可跑**：登录(AES 加密 + 鉴权头) → 相机采集 → 相芯美颜(滑块真生效) → 本地 Metal 预览 + 声网外部源推流 → 真实开播(beginLiveRoom + 6s 心跳 + 下播) → 云信公屏 / 在线人数。用户端可见画面、可收发公屏。

**整体完成度约 60%**。缺口集中在四类：**容错**（心跳失败、断线重连、相机错误）、**续期**（登录态 / 声网 token 均无续期）、**安全**（token 存 UserDefaults 未上 Keychain）、**完整性**（礼物消息解析占位、强制下播未实现、userType 未分流）。即"happy path 通了，边界与异常基本是空的"。

## 三、各模块详情

### 登录 / 鉴权（`Auth/`、`Core/CryptoUtil`、`Networking/APIClient`）
- ✅ AES-128-CBC/PKCS7：请求体 → Base64、响应 result → Hex，已与 H5 一致并验证
- ✅ 公共头：`loginToken` / `anchorToken`（同值）、`appid`、`Ocp-Apim-Subscription-Key`、deviceId
- ✅ 密码两次大写 MD5、登录拿 `loginUuid` / token / userType
- ❌ token 存 **UserDefaults**（应上 Keychain）
- ❌ 无登录态续期、无声网 token 续期
- ❌ 错误码未分流（1004 挤下线 / 1005 失效登出 / 1992·1006 封禁 / 2001 权限等）
- ❌ `userType` 已解析但**未做分流路由**

### 媒体管线（`Camera/`、`Beauty/`、`Agora/`、`Vendor/FaceUnity/`）
- ✅ 相机 → 相芯美颜 → Metal 预览 → 声网外部源，整条链路真机通
- ✅ 美颜默认渲染器是真实 `FUBeautyRenderer`（非 PassthroughRenderer），滑块参数实时生效
- ❌ 相机无错误回调，异常无法联动 '99' 强制下播
- ❌ 美颜初始化 / 渲染失败无 fallback（应降级到 passthrough）
- ❌ 声网 `networkQuality` 回调未接网络监控
- ⚠️ 前置镜像 / 视频朝向待校准
- ⚠️ 相芯引擎当前取自 FULiveDemo 仓库，生产需换相芯后台正式 SDK

### 直播闭环（`Live/LiveService`、`Live/LiveRoomView`、`Live/LivePrepareView`）
- ✅ getMyLiveRoom + beginLiveRoom + getAgoraRtmToken 开播组装、join 推流
- ✅ 6s 心跳（注意：源码 6000ms，"10秒"是过时注释）、endLiveRoom 下播
- ❌ 心跳失败被 `try?` 吞掉，无连续失败计数（应 >6 次 → '4' 断连）
- ❌ 未解析心跳响应 code（1992 / 1006 → '3' 系统强制）
- ❌ **无强制下播处理**（'3' 系统 / '4' 断连 / '5' 网络差 / '99' 相机 + 正常结束 5 类）
- ❌ 无网络质量监控（连续 ≥30 次质量≥5 → '5'；≥10 次上报埋点）

### 云信公屏（`Live/NIMChatroomManager`）
- ✅ IM 登录 + 聊天室普通模式进房、公屏文本收发、在线人数
- ❌ 礼物 custom 消息 `attachType`（数字编码，如 50/61/63）**仅占位未解析**
- ❌ 断线不重连（未监听 `connectionStateChanged`）
- ❌ leave 未复位在线人数

### 1v1 通话（`Call/CallPOCView`）—— 非本期范围
- ⚠️ 仅 POC：频道硬编码 `test_call`、无呼叫信令、无通话状态机
