## §1 业务契约

### 1.1 API 契约（6 个新 endpoint）
| Endpoint | Method | Body/Query | 用途 |
|---|---|---|---|
| `/api/live/wish/template/list` | GET | - | 拉取公共模板列表（Common template dropdown 数据源） |
| `/api/live/wish/promise/pool?pageNo=1&pageSize=20` | GET | - | 拉取"我的私人承诺池"（已审核通过的自由文案；Private template dropdown 数据源） |
| `/api/live/wish/promise/pool/{id}` | DELETE | - | 删除私人承诺池条目 |
| `/api/live/wish/promise/free/submit` | POST | `{"content": "wishTheme"}` | 自由文案提交审核；错误码 `20004` = "承诺审核中"（用 toast 展示 message，不走通用 error banner）|
| `/api/agora/live/getNum` | POST | `{}` | 拉取 `wishGiftMaxNum`（心愿池礼物种类上限，默认 3；后端可下发不同值）|
| `/api/live/wish/setup` **假名**（H5 无独立 save endpoint，实际是 wishStore 持久化到 pinia + LiveSetting 开播时提交给 beginLiveRoomRaw 的 wishlist 字段） | - | wishStore 仅本地状态；开播时组装进 `beginLiveRoom` payload 的 `wishlistList` 字段 |

**重要**：**H5 wishSetting 页没有独立 save API**——`Save` 按钮仅把选择持久化到 wishStore（pinia persist），LiveSetting 开播时把 `wishStore.wishlist / promiseType / promiseTemplateId / promiseText` 组装到 `beginLiveRoom` 的 `wishlistList` 字段上传。iOS 同样：Save 只做 `LiveSettingsStore.setWishlist(...)` 中转，实际提交在 LiveSettings.startTapped → beginLiveRoomRaw。

### 1.2 promiseType 三档语义
| 值 | 名称 | 说明 |
|---|---|---|
| 0 | `NONE` (No text) | 不填承诺；`promiseTemplateId=0, promiseText=""` |
| 1 | `COMMON` (Common template) | 平台模板；`promiseTemplateId` 是模板 id，`promiseText` 是模板 content |
| 2 | `PRIVATE` (Private template) | 私人模板（已审核通过的自由文案）；`promiseTemplateId` 是池条目 id，`promiseText` 是 content |

### 1.3 submitEnabled 组合校验（对齐 H5 index.vue:69-80）
```
submitEnabled =
  ruleChecked                                    // 必须勾选合规规范
  && !wishlist.isEmpty                           // 至少 1 个礼物
  && (promiseType != COMMON || promiseTemplateId != 0)  // Common 必挑模板
  && (promiseType != PRIVATE || !promiseText.isEmpty)   // Private 必挑池条目
```

### 1.4 wishlist 礼物操作
- **上限**：`wishGiftMaxNum`（后端下发，默认 3；本页 onAppear 调 `getWishNum` 更新）
- **数量**：每个礼物 `giftNum` 1-99；`+/-` 步进；`min 1 max 99`
- **重复添加**：同 id 礼物再选 → 累加 giftNum（H5 index.vue:281-296）
- **排序**：`sortWeight = index`（左 0 → 右 N）在 beginLiveRoom 组装时按数组顺序赋值
- **礼物 scene**：GiftPicker 用 `scene: 'WISH'`（当前 GiftService.Scene 需加 `case wish = "WISH"`）
- **价格约束**：H5 无硬性 min（不像私 call 4999），最低价 1200 只是描述，无 UI 过滤——iOS 侧不加过滤

### 1.5 Wish theme 独立提交
- 独立于 promiseType/wishlist 选择流程
- 校验：非空 + `.count <= 15`
- 成功：清空 wishTheme + 弹 SubmitSuccess 弹窗
- 失败 code `20004`：toast 展示 backend message（不弹 error banner）
- 失败其他：通用 error 展示

## §2 状态机 + Store

### 2.1 WishSettingState
```swift
enum WishSettingState: Equatable {
    case loading                    // 首次拉 getWishNum + templates
    case editing                    // 常态
    case submittingTheme            // wishTheme 提交审核中
    case error(String)              // 通用错误
}
```

### 2.2 WishSettingStore（@MainActor final class）
```swift
// 与 H5 wishStore 一一对应
@Published private(set) var state: WishSettingState = .loading
@Published var wishlist: [WishGift]              // { id, giftId, name, giftPrice, giftSmallImg, giftNum, sortWeight }
@Published var promiseType: PromiseType = .none  // .none / .common / .private_
@Published var promiseTemplateId: Int64 = 0
@Published var promiseText: String = ""
@Published var wishTheme: String = ""
@Published var ruleChecked: Bool = false
@Published private(set) var wishGiftMaxNum: Int = 3
@Published private(set) var commonTemplates: [WishTemplate]
@Published private(set) var privateTemplates: [WishTemplate]
@Published var showSubmitSuccessAlert: Bool = false
```

### 2.3 关键 method
- `load()`：拉 `getWishNum` + 若 promiseType 已存在则拉对应模板列表
- `onTypeChange(_ type: PromiseType)`：切换时清空 `promiseText/promiseTemplateId`；懒加载对应 dropdown 数据
- `pickCommonTemplate(_)` / `pickPrivateTemplate(_)`：赋值 `promiseText/promiseTemplateId`
- `deletePrivateTemplate(_) async`：DELETE 接口 + 本地过滤（选中项也清）
- `submitWishTheme() async`：`submitWishFreePromise` + 错误分流（20004 特殊）
- `addGift(_:count:)` / `changeGiftCount(_:delta:)` / `removeGift(_:)`：wishlist 操作
- `save() async` / `save() -> Bool`：submitEnabled 校验 → 持久化到 `WishSettingSharedStore.shared`（跨 LiveSettings/WishSetting 中转 + UserDefaults 持久化）→ pop 返回

### 2.4 WishSettingSharedStore（对齐 H5 pinia persist）
```swift
/// 跨 LiveSettings ↔ WishSetting 页中转 + App 重启保留（对齐 H5 pinia persist paths）。
@MainActor
final class WishSettingSharedStore: ObservableObject {
    static let shared = WishSettingSharedStore()
    @Published var wishlist: [WishGift] = []
    @Published var promiseType: PromiseType = .none
    @Published var promiseTemplateId: Int64 = 0
    @Published var promiseText: String = ""
    @Published var ruleChecked: Bool = false
    // load/save from UserDefaults key "wishSetting.state.v1"
}
```

### 2.5 LiveSettingsStore 扩展
- `beginLiveRoom` 组装时读 `WishSettingSharedStore.shared.wishlist` 转成 payload 的 `wishlistList` 数组（含 sortWeight）+ `promiseType/promiseTemplateId/promiseText`
- LiveSettings 的 wishlistCard 显示当前已配置礼物预览（复用 §5 giftTile pattern）

## §3 验收

### 3.1 F 正向
- F1 LiveSettings → tap Wishlist 卡片 → push WishSettingView
- F2 首次进入 → loading → editing；显示 3 档 promiseType 选择器 + 空 wishlist + 勾选合规

- F4 切 Private → 拉私人池 dropdown → 选一个（含删除）
- F5 tap Add Gift → GiftPicker(scene: .wish, multiSelect: true, showCount: true) → 选中 → 回填 wishlist 带 giftNum
- F6 wishlist 已有礼物 → tile 显示图/名/价 + ±count + ✕ 删除
- F7 wishTheme 输入 → Submit → loading → 成功 → 清空 + 弹 SubmitSuccess Alert
- F8 勾选 rule + 3 项校验通过 → Save 按钮亮 → tap Save → 持久化 SharedStore → pop 回 LiveSettings

- F10 从 LiveSettings tap Start Live → beginLiveRoom payload `wishlistList` 数组含正确 giftId/giftNum/sortWeight + promiseType 等字段

### 3.2 R 反向
- R1 wishlist 空 tap Save → 按钮 disabled，无反应
- R2 Common 未选模板 tap Save → 按钮 disabled
- R3 Private 未选文案 tap Save → 按钮 disabled
- R4 rule 未勾 tap Save → 按钮 disabled
- R5 wishTheme 空 tap Submit → toast "Please enter theme"
- R6 wishTheme > 15 字 tap Submit → toast "Theme max 15 chars"
- R7 submitWishFreePromise code 20004 → toast backend message（不走 error banner）

- R9 Common template dropdown 空 → toast "No template available"（对齐 Android `wishlist_settings_no_templates`）
- R10 删除 Private template 当前选中 → 清空 selection

### 3.3 真机 only
- M1 关闭 App 后重开 → Wishlist 状态保留（UserDefaults 持久化）
