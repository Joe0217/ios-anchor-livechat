## §2 Model + 状态机

### `SessionStore` 新增

```swift
struct AuditAlertContext: Identifiable, Equatable {
    let id = UUID()
    let applyStatus: Int   // 0=passed, other=rejected
    let content: String    // 展示文案（passed 用固定 L10n，rejected 用后端 content 或 fallback）
}

@Published var auditAlert: AuditAlertContext?
@Published private(set) var auditDialogShowing: Bool = false
```

### `handleAuditStatus` 重写

```swift
func handleAuditStatus(applyStatus: Int, content: String) {
    lastAuditStatus = (applyStatus, content)  // 保留原字段（H M4 埋点用）
    AppLogger.auth.notice("[Session] audit status=\(applyStatus, privacy: .public) content=\(content, privacy: .public)")

    if applyStatus == -1 {
        AppLogger.auth.notice("[Session] audit payload missing applyStatus; skip alert")
        return
    }

    if applyStatus == 0 {
        auditAlert = AuditAlertContext(applyStatus: 0, content: L10n.auditPassedMessage)
        auditDialogShowing = true
    } else {
        let msg = content.isEmpty ? L10n.auditRejectedFallback : content
        auditAlert = AuditAlertContext(applyStatus: applyStatus, content: msg)
    }
}
```

### Alert dismiss handler（RootView 挂 .alert）

```swift
func confirmAuditAlert(_ ctx: AuditAlertContext) {
    auditAlert = nil
    if ctx.applyStatus == 0 {
        auditDialogShowing = false
        logout()
    }
}
```

## §3 UI

### 挂载位

`RootView` ZStack modifier 位（body 尾部 `.animation` 之前）：

```swift
.alert(item: $session.auditAlert) { ctx in
    Alert(
        title: Text(L10n.commonKindReminder),
        message: Text(ctx.content),
        dismissButton: .default(Text(L10n.commonConfirm)) {
            session.confirmAuditAlert(ctx)
        }
    )
}
```

**为什么挂 RootView 不挂 MainTabView**：
- 审核通过弹窗触发 logout → LoginView 首次挂载时 alert 已 dismiss，无残留
- 若挂 MainTabView，logout 后 `session.isLoggedIn=false` → MainTabView dismantle 时若 alert 仍显示会闪一下
- RootView 一直存活（登录前后都在），alert 生命周期与 SessionStore 一致

| key | en | 备注 |
|---|---|---|
| `common.kindReminder` | `Kind reminder` | 通用弹窗 title（H5 Vant showDialog 默认） |
| `common.confirm` | `Confirm` | 通用 Confirm 按钮（无现存 common key，`firstLiveRule.confirm` 是单场景） |
| `audit.passed.message` | `Congratulations, your review has been approved. Please log in to the APP again.` | H5 固定英文原文（i18n 化后 Ar/Tr 各自翻译） |
| `audit.rejected.fallback` | `Your review was rejected.` | payload.content 空时 fallback |
