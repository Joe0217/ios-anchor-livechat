#### T0-3 — PartyAPIClient（envelope code==200 解析 + 401 续 + AES 复用）（0.5d）

**文件**：`Sources/Networking/PartyAPIClient.swift`（新建，与 `APIClient` 并存）

**改动点**：
1. `final class PartyAPIClient` 单例
2. 公共方法 `func request<T: Decodable>(path: String, body: [String: Any]) async throws -> T`
3. 请求链路：
   - URL = `AppConfig.weidouBaseUrl + "sapi/weidou/v1/client/party/" + path`
   - Body = JSON → `CryptoUtil.aesEncrypt(...)` → Base64（复用主接口 AES）
   - Header：`auth_token: <SapiTokenStore.authToken>` + 主接口公共头（appid / Ocp-Apim-Subscription-Key / deviceId / osType / osVersion / appVersion / Accept-Language / isProxy）
4. 响应链路：
   - HTTP status 401 → 触发 `SapiTokenStore.exchangeToken()` → retry **一次**
   - HTTP status 200 → body 解 envelope `{ code, message, data }`
   - `code == 200` → AES 解密 body（整体解密，非 envelope.result Hex 模式）→ JSONDecoder 解 `T`
   - `code != 200` → 抛 `PartyAPIError.business(code, message)`
5. **关键**：envelope `code` 形态与直播 `'0000'`（字符串）**不同**，sapi 是 `200`（数字），解析时按 Int 判
6. 错误类型：`enum PartyAPIError: Error { case network(URLError) / case business(Int, String) / case decode(Error) / case tokenExchangeFailed }`

**自检点**：
- 单测：mock 一个 envelope `{"code":200,"message":"ok","data":"<AES Hex>"}` → 解出 T
- 单测：mock HTTP 401 → exchangeToken 被调一次 → retry 一次成功
- 真机：调一个不需鉴权的 weidou 接口（如 `room/getRoomTempList`）跑通

**估时**：0.5d

#### T0-4 — APILogger 增加 .party category（0.1d）

**文件**：`Sources/Core/AppLogger.swift`

**改动点**：
1. `extension AppLogger { static let party = Logger(subsystem: "com.anchor.livechat", category: "Party") }`
