## §1 业务概念词表

```
      │      │                 │ joinCall 完成
      │      │                 │
      │      │ IM 掉线          │       source=='matchV4'?
      │      │ NIMService       │   ┌────┴────┐
      │      │ .connectionState │   │yes      │no
      │      │ =.disconnected   ▼   ▼         ▼
      │      │              ┌─────────────────┐
      │      │              │.matchingCalling │  或强制→.ended
      │      │              └─────────────────┘
      │      │                       │
      │      │       CallStore.state=.ended
      │      │       && lastJoinCallSource=='matchV4'
      │      │                       │
      │      │                       ▼ 回 .matching + resubscribe
      │      │
      └──────┘ 用户点关 / IM 掉线 / source!=matchV4 强制
```

**态定义**：
- `.ended`：初始/关闭态；用户可点开启（可能是冷启动首次 or blocked 清后）
- `.matching`：已开启匹配池 + 摄像头预览中
- `.matchingCalling`：匹配命中后接通中/通话中（CallStore 主控）
- `.blocked`：被封禁；出口边"用户主动点击 + isOpen 返 1"才转 .matching

**独立维度 `isMatchBlocked`**：UserDefaults 持久化 bool，冷启动加载；toggleMatch(1) 返 1 时清 false；影响冷启动 matchState 初值

### §2.2 跨模块状态联动（v3 完整版）

| 触发点 | 影响 |
|---|---|
| App 冷启动 → UserDefaults 加载 | 若 `isMatchBlocked=true` → matchState=.blocked；否则 matchState=.ended |
| `matchState = .matching` | MatchCameraSession.start()（若未 running）+ subscribe；LiveListActionButton disable（via @EnvironmentObject）|
| **CallStore.state → .connecting**（无条件） | **MatchCameraPreview unsubscribe**（让 CallView 独占 camera；`matchState` 暂不变，等 joinCall 完成判定） |
| CallStore.$lastJoinCallSource → 'matchV4' | 若 matchState==.matching → matchState=.matchingCalling |
| CallStore.$lastJoinCallSource → 非 'matchV4' | 若 matchState==.matching → **强制 matchState=.ended**（关匹配 + 补发 toggleMatch(0)）|
| CallStore.state → .ended && lastJoinCallSource=='matchV4' | matchState=.matching（重新 subscribe + camera.start 兜底） |
| CallStore.state → .ended && lastJoinCallSource != 'matchV4' | 不影响 matchState（其他来源通话结束与 Match 无关） |
| `matchState = .ended`（用户主动关）| MatchCameraSession.unsubscribe；toggleMatch(status=0)；不 stop camera（可能其他 owner 用） |
| `matchState = .blocked`（isOpen 返 2/3）| MatchCameraSession.unsubscribe；isMatchBlocked=true 持久化；**不调 toggleMatch**（后端已明示拒绝）|
| **`NIMService.$connectionState = .disconnected/.idle` && matchState=.matching** | matchState=.ended + toast + camera unsubscribe；**不调 toggleMatch**（网络不可达；服务端 NIM 掉线自动踢出匹配池）|
| **LiveStore.state != .ended**（进入直播态时）| CGoMatchButton view **不 render**（return EmptyView）；MatchTabView 若已展示，Match tab 可切但按钮不显 |
| **matchState = .matchingCalling** | CGoMatchButton view **不 render**（return EmptyView，不依赖 CallView 遮盖） |

### §2.3 关键不变量

- `matchState = .matching` 时 MatchCameraSession 必 subscribe；反之必 unsubscribe
- `matchState = .matchingCalling` 期间 CGoMatchButton **不 render**
- 直播态（`LiveStore.state != .ended`）期间 CGoMatchButton **不 render**
- `.blocked` **不允许自动恢复到 .ended，仅在用户主动点击 + isOpen 返 1 时清除**
- **CameraManager.session 本 spec 可 `start`（subscribe 时若未 running），但不 `stop`**（多 owner 共享，交给 App 全局 owner）
- `lastJoinCallSource` **只在 CallStore 存**（single source of truth）；MatchStore 只读订阅
- 冷启动 UserDefaults `isMatchBlocked=true` → matchState=.blocked（非 .ended）
