## §2 状态机

### §2.1 `PropsInventoryStore.State`（v2 修订：加 phase-aware error + refreshing）

```swift
enum State {
    case idle
    case loading                                             // 首次拉取中（无 items）
    case loaded(items: [PropItem], hasMore: Bool)
    case loadingMore(items: [PropItem])                      // 触底分页
    case refreshing(items: [PropItem])                       // 下拉刷新（保 items 视觉 · list-refresh-preserve-items rule）
    case empty                                               // 无 items
    case error(items: [PropItem]?, phase: LoadPhase, message: String)
}

enum LoadPhase { case initial, loadMore, refresh }  // 红队 d2-2：error 需带 phase 供 retry 分派
```

**迁移图 v2**（红队 d2-1 加 selection · d1-9 loadingMore → refreshing）：

```
idle
 └─ loadFirst()                                       → loading

loading
 ├─ success(records, total)                           → loaded(records, hasMore) or empty
 └─ error(msg)                                        → error(nil, .initial, msg)

loaded(items, hasMore=true)
 ├─ loadMore()                                        → loadingMore(items)
 └─ refresh()                                         → refreshing(items)

loaded(items, hasMore=false)
 └─ refresh()                                         → refreshing(items)

loadingMore(items)
 ├─ success(new)                                      → loaded(items++new, hasMore)
 ├─ error(msg)                                        → error(items, .loadMore, msg)
 └─ refresh()                                         → refreshing(items) [loadSeq++ 丢弃 loadingMore 响应] · 红队 d1-9

refreshing(items)
 ├─ success(new, total)                               → loaded(new, hasMore) or empty
 └─ error(msg)                                        → error(items, .refresh, msg)

empty
 ├─ refresh()                                         → refreshing([]) → loaded / empty
 └─ changeTab                                         → loading

error(items?, phase, msg)
 ├─ retry(): phase=.initial → loading
 ├─ retry(): phase=.loadMore → loadingMore(items!)    · 红队 d2-2：保持原意图
 ├─ retry(): phase=.refresh → refreshing(items!)
 └─ changeTab                                         → loading

changeTab
 └─ 任何态                                            → loading (清 items + loadSeq++ + chooseItemId=nil · 红队 d2-1)
```

**不变量**：
- `changeTab`：clear items + `loadSeq++` + `chooseItemId=nil`
- `refresh`：走 refreshing (items) 保留视觉（list-refresh-preserve-items §规则 A）
- `refreshAsync() async`：`.refreshable { await store.refreshAsync() }` 使用（rule §规则 B）
- 任何时刻只有一个 in-flight 请求（loadSeq 递增作废过期响应）
- **view disappear 主动 cancel** in-flight fetch/ops Task（红队 d5-S3）

### §2.2 `PropsInventoryStore.OpsState`（v2 修订：加 snapshot 回滚契约）

```swift
enum OpsState {
    case idle
    case wearing(itemId: Int64, snapshot: OpsSnapshot)
    case removing(itemId: Int64, snapshot: OpsSnapshot)
}

struct OpsSnapshot {  // 红队 d2-4：乐观回滚必备
    let previouslyEquippedItemId: Int64?    // 同 itemType 内之前穿的那件（可能 nil）
    let previousMineURL: String?             // AnchorInfoStore.mine 里对应字段的旧值
    let loadSeq: Int                          // 若失败时 loadSeq 变化说明 refresh 已在途 → 不回滚（服务端为准）
}
```

**流程**：
1. Ops 开始前 snapshot（previouslyEquippedItemId + previousMineURL + loadSeq）
2. 本地乐观：items 同 itemType 全 wearStatus=0 → 当前置 1（or 全部置 0）；AnchorInfoStore rebuild mine
3. API 调用
4. 失败：
   - 若 `snapshot.loadSeq != current.loadSeq` → 丢弃回滚 + toast "Failed, refreshing..."（服务端为准）
   - 否则：items 恢复 previouslyEquippedItemId wearStatus=1 + AnchorInfoStore rebuild mine.field = previousMineURL + toast "Failed. Try again"

**并发约束**：OpsState != idle 时**同一 item 的**按钮 disabled（不是全局；其他 item 可正常操作）→ 需 `wearing(id)` / `removing(id)` 带 id

enum PropExpireTime: Decodable, Equatable {
    case permanent
    case timestamp(TimeInterval)      // 秒级 UNIX epoch

    init(from decoder: Decoder) throws {
        let c = try decoder.singleValueContainer()
        // 严格对齐 H5：只有 "-1" 或 -1 视为 permanent · 红队 d1-6
        if let s = try? c.decode(String.self) {
            if s == "-1" { self = .permanent; return }
            if let n = Int64(s) {
                self = Self.fromEpoch(n); return
            }
            self = .permanent; return  // 无法解析兜底 · 红队 d2-14 越界 fallback
        }
        if let n = try? c.decode(Int64.self) {
            if n == -1 { self = .permanent; return }
            self = Self.fromEpoch(n); return
        }
        self = .permanent
    }

    private static func fromEpoch(_ n: Int64) -> PropExpireTime {
        // 秒/毫秒/微秒边界 · 红队 d2-14 + D10
        if n < 10_000_000_000 { return .timestamp(TimeInterval(n)) }       // 秒
        if n < 10_000_000_000_000 { return .timestamp(TimeInterval(n) / 1000) }  // 毫秒
        return .permanent  // 越界兜底
    }

    var isPermanent: Bool { if case .permanent = self { true } else { false } }
    /// 返回从当前时间到到期的剩余秒数（负数 = 已过期）
    var remainingSecondsFromNow: TimeInterval? {
        switch self {
        case .permanent: return nil
        case .timestamp(let epochSec): return epochSec - Date().timeIntervalSince1970
        }
    }
    /// H5 格式 "xD:xxH:xxM"（无秒）· `remainingSecondsFromNow <= 0` → "0D:00H:00M"
    static func format(remaining seconds: TimeInterval) -> String {
        let s = max(0, Int(seconds))
        let d = s / 86400, h = (s % 86400) / 3600, m = (s % 3600) / 60
        return String(format: "%dD:%02dH:%02dM", d, h, m)
    }
}
