## §1 业务契约

### 1.1 API：queryLiveStat（H5 `api/live/index.ts:63`）

```
POST /api/agora/live/queryLiveStat
body: { beginTimestamp: Int64, endTimestamp: Int64 }   // 毫秒
resp: {
  viewNum: Int,               // 观众数
  followNum: Int,             // 关注数
  giftRanks: [GiftRankItem],  // 送礼排行榜（有序，前 3 为 top gifters 预览）
  giftRanksReview: [GiftRankItem]?,  // H5 前端切片得来；iOS 后端未返，直接切
  incomeDiamonds: Int,        // 收入钻石
  privateCalls: [PrivateCallItem]  // 私 call 列表
}

GiftRankItem: {
  userId: String/Int,   // ⚠️ iOS-decode-userid-compat：String/Int 双兼容
  icon: String?,        // 头像 URL
  nickname: String?,
  consumeDiamonds: Int, // 送礼总数
  followFlag: Int/Bool, // 关注标志 1=已关注
  yxAccid: String?      // 云信 IM ID（Message 按钮启用条件；H5 用之打通聊天）
}

PrivateCallItem: {
  userId / icon / nickname / followFlag / yxAccid,
  callDuration: Int     // 秒（H5 侧 formatTimestamp(callDuration * 1000) 转 HH:mm:ss）
}
```

### 1.2 forceEndReason 映射

H5 URL query `forceEndReason` 字符串 `'5'` = FORCE_LIVE_END_STATUS.NETWORK_QUALITY，触发红字提示。iOS 侧 `LiveStore.endType` 数字编码：`7 = weakNetwork`（对齐安卓）。

**iOS 映射**：`LiveResultView` 入参 `endType: Int?`；`endType == 7` 时显示网络红字提示。**只对齐"弱网提示"这一个场景**，其他 endType（1/2/4/5/6）不显示。

### 1.3 用户流程

```
LiveRoomView state=.ended → LiveStore 已存 begin/endTimestamp（attachLiving 记 begin，endLive/forceEnd 记 end）
  → LiveRoomView `.fullScreenCover(isPresented: $showResult)` 挂 LiveResultView
     LiveResultView 参数：range (Int64, Int64), endType Int?
  → LiveResultStore.load()：
      state = .loading → queryLiveStat → state = .loaded(data) / .error(msg)
  → 用户看数据 / follow / 点 gifter → 无跳转（H5 也是点头像无操作，仅关注 + message 交互）
  → back 图标 tap → env.terminationAction.perform()：切 MainTab.home + 清 homePath+workPath + LiveStore.reset()

失败：LiveResultState.error → 顶部红 banner + Retry 按钮 → 再次 load
```

**移除现状**：`LiveRoomView.onChange(store.state == .ended) { dismiss() }` 改为 `showResult = true`；结果页 back 时才 dismiss。

## §2 Model + 状态机

### 2.1 LiveResultState

```swift
enum LiveResultState: Equatable {
    case loading
    case loaded(LiveStatData)
    case error(String)
}
```

### 2.2 LiveResultStore（@MainActor final class ObservableObject）

```swift
@Published state: LiveResultState = .loading
let range: (Int64, Int64)   // beginTs, endTs（毫秒）
let endType: Int?           // 用于 UI 弱网提示

func load() async
func toggleFollow(userId: Int64, currentFollowed: Bool) async
```

**follow 更新策略**：调 UserProfileService.followUser（followType 0/1）后，就地更新 `state = .loaded(data)` 内对应 userId 的 followFlag（gifter/privateCall 两个列表都遍历一次，防同用户重复出现）。

```swift
struct LiveTerminationAction {

extension EnvironmentValues { var liveTermination: LiveTerminationAction { ... } }
```

## §3 验收

### 3.1 F 正向
- F1 直播中点 X → endLive → state=.ended → 结果页 fullScreenCover 立即上（不 dismiss LiveRoom）
- F2 结果页 loading → 显示 4 项数据 + Top Gifters 前 3 + Private Calls 列表
- F3 giftRanks/privateCalls 为空 → 相应卡片显示 "No data" 空态（对齐 H5 CEmpty）
- F4 点未关注用户 follow 按钮 → 接口成功 → follow 按钮消失（followFlag=1）
- F5 back 图标 → 切 MainTab 到 home + 清 workPath/homePath + LiveStore.reset()
- F6 forceEnd endType=7（弱网强制下播）→ 结果页顶部红字提示
- F7 Top Gifters 点 "More" → 全屏 sheet 显示完整 giftRanks

### 3.2 R 反向
- R1 queryLiveStat 失败 → 顶部红 banner + Retry 按钮，点 Retry 重新 load
- R2 GiftRankItem.userId 后端返 Number（非 String）→ iOS decode 兼容（`.claude/rules/ios-decode-userid-compat.md`）
- R3 结果页出现时 LiveStore.begin/endTimestamp 有一为 nil（异常路径）→ 显示"Failed to get data"（不发接口）
- R4 用户已关注 → follow 按钮不显示（对齐 H5 `v-if="item.followFlag * 1 !== 1"`）
- R5 Message 按钮：无 yxAccid 时不显示；有 yxAccid 时灰态 disabled + tap 弹 toast "Coming soon"（占位）
- R6 back 时若 LiveRoomView onDisappear 未被触发（fullScreenCover 覆盖不触发 onDisappear）→ `LiveStore.reset()` 内主动 teardown

### 3.3 真机 only
- M1 真接口 dev 环境 queryLiveStat 返回验证字段兼容（userId Number/String / followFlag Bool/Int）
- M2 弱网 forceEnd 场景真机跑一遍 → 结果页红字提示可见
- M3 back 后再次开播 → LiveStore 状态干净、beginTimestamp 重置
